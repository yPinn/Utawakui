# Impeccable Context Note

This file is a lightweight bridge for older project context.

`PRODUCT.md` and `DESIGN.md` are the canonical Impeccable context files for this
project and already exist:

- `PRODUCT.md` for strategic product context: users, purpose, register, platform, brand personality, anti-references, and design principles.
- `DESIGN.md` for visual system context: palette, typography, spacing, components, layout, motion, and do/don't rules.

For everything outside Impeccable's scope, use:

- `README.md` for the public project overview.
- `docs/spec.md` for product scope, feature classification, architecture, data model, gates, and roadmap.
- `AGENTS.md` / `CLAUDE.md` for implementation guidance and current engineering constraints.

Keep this file as a short pointer only; put design notes in `PRODUCT.md` or `DESIGN.md` instead.
