# 本機曲目影片

## 取得影片

曲目詳情 → 影片提供「匯入 MP4」及「YouTube 來源」。YouTube 預填曲目原始 ID，可貼上網址或 ID，並以來源摘要協助確認版本。有效網址會正規化成僅含影片 ID 的 HTTPS watch URL。貼入同一影片的其他分享網址時，保留畫質及下載確認。

原聲預覽按需載入官方 iframe，收合、換來源或離開分頁時釋放。控制台 CSP 只允許固定的 YouTube embed 路徑，Main 只為相符的子框架請求補 App 識別，並用影片 ID 建立外部開啟網址。

查看畫質後才提供容量、下載確認及進度。相容的 SDR H.264 MP4 優先預選 1080p，其次選 1080p 以下最高畫質。高於 1080p 的格式須手動選擇。Main 以短期 token 綁定允許的格式、曲目、曲庫世代及音源版本。下載重查設定中的外部來源功能（`provider-flow`）及逐次保存確認。受控 loopback 來源僅供未封裝測試。

## 影片對時

- 匯入及下載共用暫存、FFmpeg 驗檔與自動對時。估算先驗證單一偏移，再尋找穩定且順序一致的分段。分析限 10 分鐘，可取消。通過自動套用條件時，Main 直接發布影片及對時，通知播放器更新。
- 單一偏移先要求分布在歌曲各處的配對點一致。低分的 2 秒窗口以 0.5 秒重驗。自動套用時，非靜音的低分片段合計須在 5% 以內，連續低分最長 1.5 秒。低分合計在 10% 以內、且無可用分段時，預填固定偏移並標出最長的待確認區間。
- 分段須覆蓋至少 90% 的音源，且首尾與各段間未配對的連續區間最多 5 秒，才自動套用。
- 需要確認時保留暫存候選，顯示原因並展開「影片對時」。可返回選擇來源，或調整偏移後手動套用。返回選來源會捨棄候選。已安裝的影片保留至新影片發布成功。
- 已加入影片預設收合「影片對時」。展開後可微調、重新「自動對時」或「儲存對時」。優先使用檔內音軌，其次使用已記錄的來源。舊純畫面影片缺少來源時才顯示同版 MV 的網址欄。下載或重新對時所需的參考音軌受外部來源門檻約束，暫存限 16 MiB，工作結束後清理。
- 偏移為正表示同一段較晚出現在影片中。微調會一起移動各段，儲存的各段偏移同步平移，第一段等於整體偏移；任一段移出影片範圍時拒絕這次儲存。取消「使用分段對時」會採用單一偏移。重新估算只更新草稿，Main 核對目前曲庫、音源和影片修訂。分段結果以短期 token 確認，儲存成功才通知播放器。

Main 保留原始尺寸與幀率，在 `tracks/<trackId>/video.json` 原子儲存修訂、音源綁定及對時。媒體路由只提供暫存候選或目前有效修訂。取得失敗或取消時保留既有影片。音源換版需重新配對。影片空間獨立統計，可從曲目詳情移除單支影片，或在設定手動清理目前曲庫的影片。[曲庫空間管理](library-storage-management.md#僅清理歌曲影片)

## 播放與過場

- 播放資訊欄預設顯示封面，有可用 MV 時用同一顆按鈕切換音訊與影片。影片在 16:9 框內保留原片比例。演唱工具可切到歌詞影片版，畫幅與譯文在該版的顯示選單調整。歌詞影片版接手時，播放資訊欄釋放影片並顯示封面。OBS Output 沿用原投影。
- 共用桌面元件以本機音訊位置、播放狀態、實際倍率和監聽變調延遲同步無聲 MV。段間沿用上一段的偏移，到下一段開始才跳接。首段前使用首段偏移，超出影片實際時間時保留首幀或末幀。影片缺失或不可解碼時，歌曲與歌詞仍可使用。
- 連續播放跨對時段時，在定位完成後淡入。過場只變更影片透明度，沿用 `--ui-motion-duration-standard`（200 ms）、`--ui-motion-easing-standard` 及 `--ui-opacity-muted`。拉條、切換播放版面及套用新對時直接定位。減少動態沿用共用 token。
