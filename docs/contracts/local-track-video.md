# 本機曲目影片

曲目詳情的影片分頁接收本機 MP4 或使用者逐曲請求的來源下載。已有 YouTube 來源資訊時預填原始 ID，也可貼上網址或 ID。來源分類沿用匯入的 metadata 判斷，供人工確認版本。原聲預覽按需建立官方 YouTube iframe，收合、換來源或離開分頁時釋放。控制台 CSP 只新增固定的 YouTube embed 路徑，Main 只為對應子框架請求補 App 識別。瀏覽器 fallback 使用 Main 依 ID 建立的固定 YouTube URL。檢查來源與畫質為唯讀操作，下載時須由使用者確認可下載保存，Main 重查 `provider-flow`。來源與畫質清單透過短期 token 綁定曲目、曲庫世代和音源版本。下載只允許該 token 的格式，UI 顯示來源報告的容量或未知及實際下載進度。受控 loopback 來源僅限未封裝的開發測試。

首版驗證 SDR H.264 MP4，保留原始尺寸與幀率。若有相容 1080p 就預選，否則預選最高的 1080p 以下版本。高於 1080p 的相容格式由使用者選擇。只有高於 1080p 的版本時須明確選擇。兩種取得方式都經同一暫存及 FFmpeg 檢查。Renderer 用不透明候選 ID 預覽，確認偏移後由 Main 發布檔案和 manifest。候選取消、下載失敗或音源換版時，既有影片仍保留。套用、移除及曲庫切換會通知桌面播放器更新。

Main 在 `tracks/<trackId>/video.json` 記錄當前影片修訂、音源綁定、同步偏移和尺寸等資訊。影片以修訂命名，只有目前有效修訂可經 `utawakui-media:` 讀取。曲庫空間獨立統計影片，不進入分離清理候選。音源換版後必須重新確認配對。

桌面播放器顯示無聲影片，沿用本機 HTML audio 時鐘，對應媒體位置、播放狀態、實際倍率及目前監聽變調延遲。偏移以「影片對應段落比音源晚」為正值。影片缺失、不可解碼或時間超界時保留原有歌曲與歌詞。演唱工具的影片版將本機 MV 與目前及下一句歌詞組成獨立畫面，沿用原歌詞來源、時間、讀音與文字顯示設定。一般歌詞維持預設，原 reader 保留於切換期間。影片版取得同一解碼元件的使用權時，播放資訊欄釋放 MV。OBS Output 使用原有的投影契約。
