# 歌詞編輯波形

沿用逐行／逐字對時提案 R15–R17 與 [backend 預算驗證](../research/engineering/lyrics-waveform-backend-2026-10-28.md)。波形是原音訊振幅參考，不代表人聲活動、歌詞正確或人工確認；不建立第二個播放 owner。

## 按需摘要與信任邊界

只有使用者明確開啟才讀取。Main 接受 track id、請求 id 與 overview／固定 10 秒 detail tile index，原檔、內容綁定、解碼器與路徑均由 Main 推導。讀取及 cache hit 均重查既有 audio-processing-flow gate 及已準備 FFmpeg；不下載、不自動準備。取消與清除不受 gate 阻擋。

每次讀取捕捉曲庫 dir／epoch、track 目錄身分、原媒體 stat 與內容 SHA-256；排程開始、解碼完成、落盤及回傳前再次核對。來源變更、刪曲、曲庫 scope 改變、gate／解碼器不可用時拒絕舊結果。歌詞來源、offset、tempo 不進 cache key；同曲各歌詞來源共用原媒體摘要。

Ready 回應另帶 Main 推導的 `mediaRevision`，將 scope／generation、track、原媒體 binding／實體 stamp、解碼器身分及 producer 版本雜湊為固定 64 位 hex；不同 tile 及 cache hit 共用同一證據。這是唯讀的一致性識別，不接受 Renderer 回傳當作授權，也不公開原值或路徑。Renderer 只有在 overview 及相鄰 detail 證據完全相同時才組合；即使新舊媒體 duration／sample format 相同，版本不同仍丟棄整組、保留面板並提示重讀，不能拼接不同音檔。

Main 每次最多 8 個消費者，只保留一個可排程的摘要工作；同 key 合併，其他 key 回 busy，不建立無界 queue。解碼接既有 heavyJobScheduler；等待開始時可取消。最後一個消費者取消會等待 worker／FFmpeg 關閉。清除先失效、取消並等待，再刪除該 scope／track 的 cache；晚到結果不得重建。

原媒體 hash 與 metadata 也在同一排程的可取消 worker 讀取，Main 不完整解析音訊或 cover art；最多 128 份 stat 相符的前置證據。Main frame 以外的 sender、額外欄位、非固定 tile 或任意路徑意圖均拒絕；renderer 結束會取消其工作。解碼 stderr／私有路徑只進 Main 診斷，正常 gate-disabled／取消不記失敗。

刪曲沿既有 work organization owner 等待 reader 的 hold；worker／FFmpeg 關閉前不刪原檔，刪除成功或失敗均釋放 hold。取消若無法由 OS 確認 decoder 退出，回清理失敗，不把它當作已關閉而繼續刪曲。worker 終態必須等 IPC send callback 排空，再 disconnect；parent 同時等待 close，避免大摘要在程序退出時遺失。

## 預算與 cache

原媒體最多 1 GiB／30 分鐘、1–8 聲道、8–192 kHz；分塊 PCM 最多 256 KiB，30 秒 deadline。跨所有聲道取 signed min／max，並對每個樣本平方後跨聲道、跨桶內實際 frame 平均再開根號得到 RMS；不先 downmix，反相聲道不互相消去，也不保存完整 PCM。overview／detail 各最多 4096 桶，每桶 min／max／RMS 三個 float32，共 48 KiB，保留單份 64 KiB 上限；10 秒 detail 的桶寬約 2.5ms。累計平方和使用有界 float64 陣列，空桶為零、尾桶按實際 frame 數平均。這些是應用層輸入／輸出上限，不宣稱 OS 硬 RSS 限制。

專用 userData waveform cache 以 scope／track 分組，內容、producer 版本、已準備 decoder 身分及 tile 為 key。`channel-extrema-rms-v2` 與 cache schema 2 一起失效舊摘要，不能由既有 min／max 捏造 RMS；新 key 不命中舊檔，舊檔沿原 LRU 或明確清除淘汰。只操作自有命名檔案；每份含有界 metadata 與 base64 float32 摘要，檔案最多 96 KiB，總計最多 64 MiB／512 份，LRU 淘汰。壞資料當 miss，連結及超界資料拒絕；原子安裝前重查失效柵欄。清除不刪歌詞、對時、演唱設定或人工確認收據。

啟動下一次 cache 操作會清理自有 UUID 暫存檔；未知檔名保留，目錄掃描最多 2048 項。每曲清理期間拒絕新讀取，最多 8 個清理請求。切換來源或修改時間不改 cache key；tag bytes 改變保守失效並重建，不在這層推定等價遷移。

## 介面與驗收順序

先完成 Main 來源失效、取消、清理與封裝 worker 驗證，再接歌詞編輯次頁的明確入口。振幅沿原媒體毫秒，歌詞 canonical 時間減 offset 才是波形位置，tempo 不乘入。關閉、換曲及卸載取消消費者，晚到結果不改新頁；不自動播放、不變更 queue，也不自動建立人工確認。

唯讀原音訊概覽與細節顯示已保存句首及同曲實際 clock 游標，提供重讀與清 cache。Main 仍只讀固定 10 秒 tile；Renderer 可選 1×／2×／5×／10×，依原始 frame 座標裁切為 10／5／2／1 秒視窗。視窗可連續跨 tile，最多持有兩份相鄰 detail 摘要，同一組資料內縮放／移動不另解碼；缺少的 tile 沿原 owner 串行讀取；新視窗仍需要同一在途 tile 時重用該請求，不需要才取消，晚回不得替換目前資料。兩份細節合併為每條最多 640 欄的 path，不各自拉伸兩段音訊。前後箭頭移動目前視窗；全曲定位直接拖曳概覽，不另放重複滑桿。放大以視窗內的播放位置為中心，未在視窗內則以視窗中心。時間顯示 m:ss；普通波形拖曳不 seek，明確定位／播放各有獨立入口；已啟動草稿的起／迄／整句平移把手可預覽並在有效放開時寫回同一 editor，與普通檢視拖移分開。句級編輯、手勢取消與手動保存沿[同一草稿契約](lyrics-timing-review.md)。

跟隨播放採用[釘住播放頭](https://manual.audacityteam.org/man/timeline.html#Continuous_scrolling_-_pinned_play_head)的檢視方式：新開啟時啟用，播放中將實際位置置於局部視窗中央，媒體兩端依合法範圍限制；概覽另顯示全曲當前位置，局部時間尺位於波形上方，播放頭以實線及頂端旗標區別已存句首。當前時間持續可見，移出局部檢視也不消失；暫停仍保留指示，但不自動移動視窗。手動拖移跨過門檻、前後箭頭或概覽鍵盤導航會退出跟隨；定位按鈕回到當前位置並恢復，亦可固定檢視。暫停時的定位只移視窗，不播放。

`useLyricsWaveformClock` 只在面板開啟且同曲播放時，以 animation frame 最多約 30Hz 重新採樣既有 `usePlayer.samplePlaybackClock()`，不依 wall clock、tempo 或前一幀累加推算；暫停／關閉／卸載停止排程，換曲拒絕不相符的時鐘。Main Window 沿既有 owner 發出唯讀 `main-window:visibility` boolean，preload 保留最近狀態並在工具晚掛載時回放；最小化／隱藏停止這個波形的取樣、跟隨與純預讀，背景播放不變，恢復時直接讀實際位置。不能以 `document.hidden` 取代原生狀態，因為既有背景播放使用 `backgroundThrottling: false`；一般 document visibility 仍作補充。`useLyricsWaveformViewport` 對同一 tile pair 的在途及已完成跟隨意圖去重，不逐幀取消／重啟 decoder；只有需要不同相鄰區段時才沿原讀取 owner 取資料。錯誤、來源失效與清除仍由原邊界處理，沒有新播放或 timing owner。

整塊概覽可按住拖曳，依全曲比例平移目前區間；長曲不必精準抓小框，可見框仍保留實際區間寬度。局部波形以抓手方向平移，向右抓會看到更早內容；同一手勢可反向移動。兩者保持倍率，只改 viewport，3px 門檻內視為點擊，不 seek、不播放、不改 timing／offset 或確認。拖曳中使用現有摘要，缺少細節的部分可用同媒體概覽作明示預覽；放開才讀缺少的相鄰資料，不逐 pointermove 啟動音訊工作。Pointer cancel／失去 capture 還原該次未提交視窗，換來源／關閉／清除／卸載結束手勢並防止晚到的放開讀取。概覽本體可聚焦且有可見焦點，方向鍵逐目前視窗移動、Home／End 到媒體兩端、PageUp／Down 跨五個視窗；只對已處理的按鍵阻止預設與冒泡，Escape 仍可關閉。保留前後箭頭，不另加操作模式或視覺滑桿。

面板是持續對照工具，外點、背景捲動及句級操作不收起；入口切換、關閉鈕、空閒時的 Escape 才明確關閉；句界拖曳中 Escape 只取消手勢。換曲／來源及卸載仍取消舊 context。面板開啟且有讀取意圖時，曲庫通知先丟棄舊摘要，再經同一 Main gate／媒體證據重驗概覽與目前相鄰 tile，保留倍率及可用區段；手動清除後不因通知自動產生。讀取失敗保留面板與重讀入口，沒有晚回安裝。標題把手或聚焦後的方向鍵移動整個面板，波形內抓手只移動時間視窗；面板限制在視窗內，關閉或改變視窗尺寸回到入口旁，不保存位置，也不改播放狀態。

每條峰值／能量 path 最多 640 欄，另最多 512 個可見句首；尾端預留桶依實際 frame 座標裁切，不把預算餘裕拉伸進媒體時間。外層淡色 signed min／max 保留瞬時尖峰，內層深色為對稱 RMS；同一欄按覆蓋 frame 加權平方能量後開根號，分桶內視為均勻能量，不取 RMS 最大值或直接平均振幅。兩層都沿同一原始 frame 軸與固定振幅尺度，不做 denoise、平滑、正規化或訊號門檻裁切；不推定頻段、人聲、句子起音或對時品質。既有 accent 表振幅／能量、虛線表已存句首、帶頂端指示的實線表播放位置，配合秒刻度及中線。

父層沿既有 editor 唯讀傳入正在編輯的 line id／草稿行，沒有草稿時取既有 positioned line。局部圖保留目前句文字，有端點變更時才加「草稿」標示。已知且可見的有效句區間以強調色呈現同一峰值／RMS path，區間外改為較淡的中性色；概覽也以相同方式區分目前檢視與其餘全曲。高亮只是重用相同 path 的 SVG clip，不增加分析、正規化或訊號變更。保存虛線與草稿實線置於波形前方；橫向範圍線可裁切至視窗邊緣，垂直線只畫實際可見端點，不把視窗邊界當句界。

兩組邊界各自依 canonical 時間減 offset 投影，不自動移動播放或 viewport。推定句尾的說明收於句文字 Tooltip；未知句尾只顯示已知起點並標示未定，不借下一句或媒體長度補區間，也不淡化整幅波形。範圍超出原媒體只裁切可見區域並提示，不 clamp 回存；復原／取消／保存、換來源沿既有單一草稿與 CAS 流程更新，不產生第二份時間資料或新讀取工作。

主面板只保留標題／移位／關閉、概覽、一排前後移動／當前時間／跟隨／倍率、句文字及局部時間尺。最右側「⋯」沿共用 ActionMenu 提供重讀、清快取與按需展開的波形說明／圖例；常駐振幅聲明、重複範圍讀出、「局部放大」及例行播放／暫停文字移除，時間的無障礙描述仍保留狀態。未連結、檢視外、未知句尾與媒體外等必要提示保留。關閉重置說明／選單，重讀或清除不取消 editor 草稿。

開啟期間的概覽、操作列、句文字列、時間尺及 7rem 畫布保持固定幾何，不因 overview／detail 暫空而卸載；當前時間讀出固定 7ch，句文字列固定為共用 control height，以容納明確定位／播放按鈕。載入、錯誤、未連結、檢視外及媒體外提示顯示於畫布外常駐的 2rem 狀態列，不蓋住波形或新增臨時 layout 列；長訊息單行截斷並沿共用 Tooltip／完整無障礙文字讀取，錯誤重試仍可直接操作。已有細節時的背景讀取只用 aria-busy。無 overview 時不畫時間刻度、媒體游標或虛構區間，控制禁用；有 overview 的 detail 讀取期間仍允許取消舊意圖後導航／縮放，避免每次跨 tile 閃動禁用狀態。失效摘要照常立即清空，不為穩定外觀保留舊資料；只有使用者明確展開／收起說明等操作才可改面板高度。

## 有界預讀與概覽預覽

只有面板可見、同曲實際播放且跟隨啟用時，若目前視窗只需要一塊 detail，才用第二個空位讀下一塊；不讀超過曲末，也不為已占兩塊的視窗再留第三塊。這是既有讀取 owner 的 Renderer 意圖，Main IPC、FFmpeg gate／排程、cache 與媒體證據不變。預讀不改目前 viewport 或播放；後段開啟依實際位置取資料，不競爭啟動不需要的 detail 0。

下一塊成為可見需求時，已完成資料直接重用，在途讀取則提升為必要資料，不能取消後重啟同一 tile。一般必要讀取也適用相同合併，避免滑動視窗剛好丟掉上一塊時重讀下一塊。暫停、停止跟隨或隱藏會取消純預讀，已成為可見需求的讀取仍可完成；重新顯示只跟隨當前時鐘，不補跑中間區段。來源／scope／清除／關閉／卸載失效及重驗屏障涵蓋預讀，暫停期間的重驗晚回不能復活預讀。

額外預讀的 busy／逾時等失敗保留有效可見資料，不彈出無關錯誤；真正需要該 tile 時可作一次正常讀取。Main 明確回來源失效、gate／decoder 不可用、超界，或回應媒體版本不一致時清空整組（含概覽），不能保留看似 ready 的舊摘要。因媒體縮短而失效的 tile 意圖也保守要求重讀。所有晚回仍按 generation 拒絕。

細節缺口先以同一份已驗證 overview 的原 frame 軸補充，明示「概覽預覽」；只有正在讀取才說明讀取細節，拖曳中不假稱已啟動解碼。預覽最多另兩條 640 欄 path，裁切到真正缺少細節的區域，不與已到齊細節混算 extrema。沒有 overview 或來源失效時不提供舊預覽；概覽解析度不能視為細節或聲學句界。此機制不新增解碼、無界 cache 或自動 timing；1× 連續視窗已占兩塊時，仍可能等待新 detail，以概覽維持參考。

超出原媒體的 offset 句首另明示數量。關閉不清 editor 草稿；清 cache 不自動再產生，必要讀取失敗可重試，操作失敗沿共用 notify，正常完成不通知。

## 已驗證範圍（2026-10-28）

Main 接入使用既有系統 FFmpeg，九種合成來源含 WAV／MP3／AAC／Opus／FLAC、30 分鐘長曲、單聲道及四／八聲道；暖 cache 不啟動 producer。執行中取消、原媒體變更、scope 改變及清除均拒絕晚回，沒有新 cache 安裝，worker／decoder 已退出。共用排程、消費者上限、cache 淘汰／壞資料／連結／暫存清理、刪曲等待與 hold 釋放由相鄰測試固定。

封裝測試驗七個入口與實體 metadata 相依解析，搬移後 worker 在隔離 artifact 內讀取，不借用開發目錄。可見 Electron 在亮色 960／深色 1280 驗開啟、切段、Escape 焦點、清除、讀取中關閉、換來源及長曲讀取中刪曲；主播放持續前進，新增 play／pause 呼叫均為 0，沒有水平溢出。測試使用靜音的合成反相音訊，不作聽感結論。
