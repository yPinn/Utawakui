# 手機遙控與提詞契約

手機在同一區網內看歌詞並遙控播放。決策與威脅模型見 [ADR 0033](../adr/0033-mobile-companion-local-network.md)。此契約定義可驗證的行為；已實作，實機驗收見下方清單，現行狀態以[產品規格](../spec.md)為準。

## 範圍

- 提供整句歌詞、播放遙控、Right Dock 一般佇列與最近播放同步、點播、手動佇列編輯及曲庫瀏覽、搜尋與分類。演出清單和演出紀錄同步顯示，手機可切換這些分頁。手機可調整歌詞版型與字級。已配對裝置由桌面管理。
- 不提供：演出計畫編輯、曲庫刪除、上傳、雲端轉送、帳號、觀眾點歌。
- Output server、`/ws`、提詞器 preload 與 renderer IPC 一律不對區網開放，也不與此功能共用連接埠或憑證。

## 啟用與網路

- 功能受 `mobile-companion` gate 保護，預設關閉。gate 關閉時不建立 listener，已配對手機仍可在設定中管理。gate 開啟後自動嘗試啟動連線，舊版留下的個別開關設定會被忽略。
- 網路類型以 IPv4 位址對應 Windows 網路設定檔（依介面索引連結），不以介面名稱比對，避免本地化名稱在主控台編碼下失真。
- 啟動失敗時（網路尚未連上、仍為公用網路、連接埠全被占用）Main 每 10 秒於背景重試，結果改變才通知畫面；無法加密保存時不重試。
- 只有一個可用網路介面時由 Main 自動選用；有多個時手機畫面才顯示網路選單，未選擇前不啟動。Main 只綁定該 IPv4 位址。可用網路是私人網路，加上使用者按過「仍要使用」的公用網路；這個選擇依 Windows 網路設定檔名稱記住（最多 16 個），換到其他公用網路會再問一次。無法判定類型的網路視為公用。
- 連接埠不在任何畫面顯示。預設 8710；被占用或被 Windows 保留時依序改試 8711–8714，並記住成功的埠，之後沿用以維持手機端網址。換埠後，已配對的手機需重新掃描配對（憑證依網址保存）。全部失敗時顯示錯誤。
- 入口是標題列的手機按鈕：在右側 Dock 保留區直接顯示 iPhone 比例的手機外框（展開 Dock 時收起），配對 QR 碼、步驟、須知與網路選擇都在手機畫面內；頂部狀態列依序為時間、定位、動態島與鏡頭、訊號、Wi-Fi、電量。gate 未開啟時按鈕先顯示功能說明與開啟確認。配對 QR 碼一律搭配步驟、須知與防火牆提示；連線準備中 QR 框維持空白，只有出錯時才顯示原因；換新配對碼與失效遮罩以 motion token 淡入淡出。
- 每個 HTTP 請求的 `Host` 必須等於 `<所選位址>:<埠>`；WebSocket 的 `Origin` 必須等於 `http://<所選位址>:<埠>`。不送 CORS 標頭。
- 第一次監聽時若 Windows 防火牆詢問，手機面板提示允許私人網路。使用已允許的公用網路時，也提示允許公用網路。
- 關閉 gate 或結束 App 時，Main 停止監聽並關閉連線。
- 已配對手機完成讀者驗證後，外框自動顯示同一套可操作的手機頁面；最後一個讀者斷線後回到配對畫面。預覽以 390 CSS px 為基準寬度，等比縮放至外框可用空間。預覽沿用手機頁面的內容和操作元件。播放、歌詞、佇列與模板狀態跟隨桌面，預覽和真機各自管理分頁與捲動位置。

## 配對

1. 連線服務啟動且外框顯示配對畫面時產生配對 QR 碼（不顯示網址文字）。配對碼使用過或逾時後，原 QR 碼上蓋一層遮罩與「重新產生」按鈕；有待確認的手機時 QR 碼暫時收起。手機畫面收起時作廢未使用的配對碼。QR 碼外流（例如直播畫面）時，他人掃描只會開啟一個需在電腦允許、可拒絕的要求。
2. 網址形如 `http://<位址>:<埠>/m/#pair=<code>`。`code` 為 128 位元隨機值，120 秒內有效、只能用一次。收起手機面板或產生新碼會作廢舊碼，已掃描的要求仍由確認視窗處理。片段不隨請求送出，伺服器不記錄。
3. 手機頁讀取片段後立刻從網址列移除，再以 `POST /m/api/v1/pair` 提交 `{ code, label }`。`label` 為裝置名稱，1–40 字，預設取瀏覽器平台字串（iPhone、iPad、Android）；瀏覽器不提供真正的裝置名稱或型號（Android 的型號 API 只在 HTTPS 可用）。同名時依序存成「iPhone 2」「iPhone 3」，確認視窗即顯示將儲存的名稱。
4. 有效的碼只會開啟一個待確認要求，回 `202 { claimToken, matchCode, expiresAt }`，不發放憑證。`matchCode` 為 4 位數，手機與電腦同時顯示；`claimToken` 為 256 位元，只用來取回結果。同一時間只允許一個待確認要求，其他掃描回 `pairing-busy`。
5. 電腦不論在哪個畫面都跳出確認視窗（notice 尺寸），顯示「允許「名稱」連線？」與對照碼；關閉視窗等同拒絕。使用者核對手機顯示相同代碼後按「允許」才建立裝置；按「拒絕」或 60 秒未處理即失效。允許需要 gate，拒絕隨時可用。
6. 手機每 1.5 秒以 `POST /m/api/v1/pair/status { claimToken }` 查詢，允許後只取得一次 256 位元裝置憑證並存在 `localStorage`；拒絕、逾時或未知都回 403 並請使用者重新掃描。Main 只保存憑證的 SHA-256、名稱、建立與最後連線時間，以 `safeStorage` 加密寫入 userData。
7. 掃描失敗一律回同一個有界錯誤，不透露是過期、已用或錯誤。同一碼連續失敗 5 次即作廢。最多保留 8 台裝置，超過時允許會失敗並自動拒絕該要求。

## 裝置與撤銷

- 設定只保留功能說明與已配對手機的紀錄：每台裝置的名稱與最後連線時間，可就地重新命名（Enter 或離開欄位儲存、Esc 取消；使用者自訂的名稱照原樣保留），可個別撤銷或全部撤銷。改名與撤銷都不需要 gate。
- 撤銷立即關閉該裝置的連線，之後的請求回 401；手機頁清除本機憑證並回到「請重新掃描配對」。
- 關閉功能不刪除已配對裝置；關閉 gate 時同樣保留，重新開啟後仍可連線。

## 讀取通道

- 手機以 WebSocket `/m/ws`（子協定 `utawakui.companion.v1`）連線，3 秒內須送出 `{ type: "auth", credential }`，否則以 1008 關閉。驗證後只由伺服器送出訊息；其後任何客戶端訊息都關閉連線。
- 內容為已驗證的提詞器快照（`parsePerformerSnapshot` 的同一 schema），含 `bootId`、`sourceEpoch` 與 revision；不含路徑、網址、曲庫清單或 provider 資料。
- 畫面輸出功能開啟時，手機快照附上各輸出槽已套用的模板 ID、可編輯的設定值及有界的人物卡片資料。欄位取自共用的 Output 定義。
- 人物格的縮圖由 `/m/api/v1/output-portrait` 提供。只接受已發布的人物組合 ID 或目前曲目的「跟隨歌手」選項，Main 依快照解析圖像並檢查手機配對、有效連線及畫面輸出 gate。
- 快照發布不依賴桌面提詞器視窗是否開啟。沒有曲目時送出空狀態。
- 同一時間只連線一支手機：新手機驗證後，其他手機的讀取連線以 4410（displaced）關閉；被擠下的手機保留憑證、不自動重連，按「改用這支手機」即可取回連線。只有目前連線的手機能送出指令。同一支手機最多 2 條讀取連線；單訊息上限 64 KiB。10 秒心跳（ping 與 `heartbeat` 訊息）；手機 25 秒未收到訊息即重連。

## 遙控指令

指令以 `POST /m/api/v1/command` 送出，標頭 `Authorization: Bearer <credential>`，內容固定為：

```json
{ "command": "player.next", "sequence": 42, "revision": 17, "trackId": "abc" }
```

| command                                                                                          | 對應                                       |
| ------------------------------------------------------------------------------------------------ | ------------------------------------------ |
| `player.play-pause`                                                                              | 播放／暫停                                 |
| `player.previous`、`player.next`                                                                 | 上一首／下一首                             |
| `player.seek`                                                                                    | 跳轉到目前曲目內的 `positionMs`            |
| `queue.play`                                                                                     | 點播快照中待播曲目的 `queueIndex`          |
| `queue.remove`、`queue.clear`                                                                    | 移除或清空手動佇列                         |
| `queue.move-up`、`queue.move-down`                                                               | 於手動佇列或來源待播分組內移動             |
| `queue.play-recent`                                                                              | 點播已發布的最近播放項目                   |
| `queue.view-queue`、`queue.view-recent`                                                          | 切換 Right Dock 一般佇列分頁               |
| `queue.view-arrangement-pending`、`queue.view-arrangement-history`                               | 切換 Right Dock 演出清單分頁               |
| `library.play`、`library.enqueue`                                                                | 播放或排入指定的桌面曲庫曲目               |
| `player.transpose-up`、`player.transpose-down`                                                   | 升降 Key 1 個半音（±12 內）                |
| `player.transpose-original`                                                                      | 半音與微調音分歸零                         |
| `player.tempo-75`、`player.tempo-90`、`player.tempo-100`、`player.tempo-110`、`player.tempo-125` | 固定播放速度 0.75×、0.9×、1×、1.1×、1.25×  |
| `player.accompaniment`、`player.guide-vocal`                                                     | 分離音軌的監聽混音切換，監聽跟隨輸出時停用 |
| `player.volume-up`、`player.volume-down`、`player.mute`                                          | 監聽音量與靜音                             |
| `reading.off`、`reading.furigana`、`reading.romaji`                                              | 讀音顯示                                   |
| `output.set-option`                                                                              | 調整或重設目前套用的模板                   |

- `sequence` 為每台裝置單調遞增的整數，重複或倒退即拒絕；`revision` 與 `trackId` 必須對應最近發布的快照之一，否則回 `stale`。
- `player.seek` 需要多一個 `positionMs` 欄位，值為非負整數毫秒。桌面播放器確認曲目與目前長度後執行。手機拖曳時只預覽，確認新位置後才送出一次指令。
- `queue.play` 帶該版本待播清單中從 0 起算的 `queueIndex`。電腦依原快照解析曲目，並確認曲目仍在原分組。排序和移除使用同樣的待播索引；最近播放以該版本的最近播放索引解析。曲庫指令帶 `libraryTrackId`，由桌面解析。無正在播放曲目時，佇列和曲庫指令的 `trackId` 為空字串。
- `output.set-option` 帶 `outputChange: { templateId, fieldKey, value }`，沒有播放曲目時可用空的 `trackId`。Main 檢查畫面輸出 gate 與欄位和值的範圍。桌面比對快照與目前套用模板及設定，再由 Output 槽寫入單一欄位、人物選擇，或將手機可調欄位重設為模板預設值。桌面有待儲存的編輯時回 `busy`。
- Main 依序檢查 gate、憑證、能力 `player.transport.write`、schema、速率與 renderer 是否就緒，再交給對應的桌面指令路徑。
- 回應狀態為 `rejected`（含有界原因：`unauthorized`、`invalid`、`stale`、`rate-limited`、`unavailable`、`busy`、`displaced`）、`accepted` 或 `applied`；2 秒內未套用回 `timed_out`。renderer 不可用時直接拒絕，不排隊。
- 每台裝置每秒最多 8 個指令，同一指令每 100 ms 最多 1 個；請求本文上限 1 KiB。
- 直播或錄影中不另加確認；指令只限上表，不含破壞性操作。

## 手機頁

- 專用 renderer entry，由 listener 以精確檔案清單提供。CSP 只允許同源的 script、style、font、img（含 `data:`、`blob:`）、`media-src blob:` 與 `connect-src` 自身 WebSocket。
- 連線畫面顯示 Utawakui 標誌與產品名稱。尚未配對時依序引導使用者連到同一網路、從電腦標題列開啟手機遙控、掃描 QR 碼。等待確認時顯示對照代碼與電腦端操作。連線或配對失敗時依狀態提示下一步。
- 四個圓點以膠囊置於固定播放列上方中央，自左至右為佇列、歌詞、遙控、模板，預設進入歌詞。可按圓點或在內容區左右滑動換頁，各頁內容在切入後才掛載。播放列在四頁都顯示曲目、上一首／播放暫停／下一首和進度條。
- 佇列同步 Right Dock 的一般與演出清單模式。一般佇列顯示正在播放、手動排入和來源待播，也可切換最近播放。使用者可點播、分組內排序、移除手動排入項目，或確認後清空手動佇列。
- 曲庫以 `GET /m/api/v1/catalog` 分頁提供，只限目前連線的手機。可搜尋曲名、歌手和專輯，並依歌手或專輯分組；回應只含曲目 ID、曲名、歌手及專輯。
- 曲目封面從 `/m/api/v1/artwork` 取得，範圍同曲庫。Main 驗證本機封面，WebP 原格式回傳，JPEG 與 PNG 縮為最長邊 160px 的 JPEG。手機以最多 2 個並行請求在背景預載目前、待播與最近播放，可見列優先；以 Blob URL 暫存至多 150 張，無封面時用內建後備圖。
- 歌詞沿用 `selectPerformerFrame` 與 `PerformerLyricCue`，依播放時鐘及電腦已設定的曲目同步值跟隨整句，手機無法更改同步值。預設以捲動列表跟隨至上方三分之一，手動捲動後由懸浮工具回到目前歌詞。整句螢光筆標記最近開始的一句，空拍與曲末延續同一句；男聲、女聲與合唱使用桌面設定的顏色。每個字級下所有行的字級、字重與讀音尺寸一致。右下懸浮工具切換歌詞版型、字級與讀音，版型與字級存在手機。
- 模板頁可切換各輸出槽，以和桌面相同的分類顯示可調整的模板及元素欄位，欄位隨套用模板與呈現方式更新。
- 遙控頁使用固定刻度升降 Key 和音量、固定倍率調整速度。可開啟「鎖定畫面控制」：手機循環播放無聲音訊，以 Media Session 顯示曲名、歌手與 160px 正方形封面，並把鎖定畫面的播放暫停、換曲與拖曳轉成上表指令。開啟時暫停手機上的其他音訊；選擇存在手機，重新開啟頁面後於第一次點擊啟動。
- 使用共用 Compact tokens 與系統深淺主題，底色、面板與播放器分用 canvas、surface 與 raised surface。畫面填滿可視高度，頁首與播放列底色延伸至安全區，操作區依安全區退避。觸控目標 44px，輸入欄位字級 16px，圓點分頁觸控區 24 × 24px。
- 關閉懸停效果、工具提示與進度條預覽泡泡；按下、已選取、停用和鍵盤焦點仍有回饋。操作區停用文字選取與連點縮放，歌詞、曲名、歌手與配對代碼可長按複製，選取文字時暫停滑動換頁。
- 切頁以輕微方向位移與淡入呈現，遵從減少動態效果偏好。指令出錯時頁首下方以全寬通知列顯示，`stale` 時提示重試。
- 連線中斷時頁首顯示重新連線狀態，保留歌詞並暫停遙控，以退避重試。25 秒未收到訊息或回到前景時發現連線已斷，立即重連。指令 6 秒未回應視為逾時。收到 401 時停止重試並提示重新配對。被其他手機取代（4410 或指令回 `displaced`）時停止重試，顯示「目前由另一支手機連線」與「改用這支手機」。手機連上或中斷時，電腦顯示短暫通知。
- 分頁在背景時暫停歌詞的定時更新，回到前景後依最新快照對齊。

## 驗收

1. gate 關閉時 8710–8714 都沒有 listener；開啟後只在所選介面監聽，其他介面與 `127.0.0.1` 無回應。8710 被占用時改用下一個可用埠並在重啟後沿用。
2. 公用網路未經「仍要使用」不啟動並顯示原因；按下後只對該網路生效，換到其他公用網路仍不啟動。
3. 錯誤 `Host` 或 `Origin`、缺少或錯誤憑證、超時未驗證的 WebSocket 都被拒絕。
4. 配對碼過期、重用、第 5 次錯誤後作廢；網址片段不出現在伺服器紀錄或診斷匯出。配對碼失效時 QR 碼被遮罩覆蓋並可重新產生；未在電腦允許前手機拿不到憑證，拒絕或 60 秒逾時後要求失效，雙方顯示的對照碼一致。
5. 撤銷後該裝置連線立即中斷，舊憑證回 401；其他裝置不受影響。
6. 每個指令在已載入曲目時生效，並回 `applied`；切歌後送出舊 revision 回 `stale`；重送相同 sequence 被拒。
7. 超出速率回 `rate-limited`；不在清單的指令與多餘欄位回 `invalid`。
8. 桌面提詞器關閉時手機仍收到快照；renderer 重新載入期間指令回 `unavailable`。
9. 手機頁在 320 px 直向與 568×320 橫向可完整操作，深淺主題可讀。
10. 關閉功能或結束 App 後連線關閉且不再監聽；重新開啟後已配對裝置可直接連線。
11. iPhone 開啟鎖定畫面控制後，鎖定畫面顯示曲名與正方形封面，播放暫停與換曲傳到電腦；中斷 Wi-Fi 後 25 秒內顯示重新連線。
