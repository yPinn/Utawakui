# Output 動畫交付規格

本規格說明 After Effects 動畫師交付 OBS 輸出模板動態時，需要提供哪些檔案、如何設定，以及如何驗收。決策見 [ADR 0034](../adr/0034-output-motion-rendering-and-animation-handoff.md)，實作規則見 [Output 動態與渲染契約](output-motion-rendering.md)，素材驗證見 [Overlay pack 資產政策](overlay-pack.md#資產政策)。

## 為什麼要分成兩類交付

歌詞、曲名與歌單每首都不同，長度、語言和直書橫書也不同，所以 AE 算繪好的影片不能直接當成模板。交付分為兩類：

| 類型             | 內容                           | 後續處理                            |
| ---------------- | ------------------------------ | ----------------------------------- |
| 動態設計規格     | 文字與需要跟歌曲對齊的動態     | 開發者以 App 的時間軸與特效元件重建 |
| 可直接使用的素材 | 不含動態文字的裝飾、背景與貼圖 | 驗證後由 App 直接播放               |

AE 特效不會原樣搬進輸出畫面。開發者把每個特效對應到 App 內建的特效元件；沒有對應元件時新增元件，之後其他模板也能共用。

## 合成設定

| 項目     | 設定                                                                                            |
| -------- | ----------------------------------------------------------------------------------------------- |
| 尺寸     | 歌詞 1920×1080；歌單 480×810；播放中依模板，見 [Output runtime](output-runtime.md#只讀輸出視窗) |
| 幀率     | 60fps                                                                                           |
| 背景     | 透明；另附淺色、深色與複雜背景的檢查畫面                                                        |
| 安全框   | 標出文字不可超出的範圍                                                                          |
| 文字     | 以占位文字圖層表示，標明對應欄位（目前句、下一句、曲名、演出者等）                              |
| 圖層命名 | `欄位_用途_序號`，例如 `current_glow_01`；同一效果的圖層放在同一預合成                          |

## 動態設計規格

| 交付物       | 說明                                                               |
| ------------ | ------------------------------------------------------------------ |
| AE 專案      | 用「收集檔案」整理的 .aep 與素材；註明 AE 版本與使用的外掛         |
| 參考影片     | MP4，1920×1080、60fps；與 AE 合成同尺寸，用於逐格比對              |
| 關鍵影格資料 | 以約定的匯出腳本輸出 JSON，含時間、數值與貝茲緩動                  |
| 特效清單     | 每個圖層使用的特效、外掛與關鍵參數                                 |
| 時間規則     | 以句子開始與結束為基準描述進場、停留、退場，不使用固定的絕對秒數   |
| 極端情境     | 最短句、最長句、直書、連續快句、空白間奏，以及減少動態時的靜態版本 |

時間規則範例：「句子開始前 0.2 秒進場，持續 0.6 秒；停留到句子結束；結束後 0.25 秒內退場。句長短於 1 秒時省略停留。」

## 可直接使用的素材

| 格式                     | 適合用途                             | 能否對齊歌曲 | 注意事項                                                     |
| ------------------------ | ------------------------------------ | ------------ | ------------------------------------------------------------ |
| Lottie（.json／.lottie） | 框線、花紋、圖示、轉場形狀           | 可以         | 多數 AE 特效與文字不支援；表達式須先轉成關鍵影格；影像須內嵌 |
| 圖片序列（PNG、WebP）    | 光效、粒子等需要保留 AE 效果的短片段 | 可以（逐格） | 解碼後占用大量記憶體，限制解析度與影格數                     |
| 影片（WebM VP9 含透明）  | 背景循環、氛圍光效                   | 不行         | 只用於不需對齊歌曲的部分                                     |
| GLB                      | 3D 物件與模型動畫（由 3D 軟體製作）  | 可以         | 限制面數、材質與貼圖                                         |
| 貼圖（PNG、WebP）        | 置換圖、雜訊、漸層、紙紋             | 不適用       | 供特效元件使用                                               |
| LUT（.cube）             | 統一色調                             | 不適用       | 由開發者轉為點陣圖                                           |
| 字型（OTF、TTF）         | 模板指定字型                         | 不適用       | 須附授權與再散布許可                                         |

選擇原則：

1. 文字與需要對齊歌曲的效果，交付動態設計規格。
2. 向量裝飾優先用 Lottie。
3. AE 特效很重、又需要對齊歌曲的點陣片段，用圖片序列。
4. 不需對齊歌曲的背景或氛圍，才用影片。

所有素材不得含腳本、表達式或外部連結；Lottie 的表達式在匯出前用 AE 的「關鍵影格助理 > 將運算式轉換為關鍵影格」（Convert Expression to Keyframes）處理。素材的來源、作者與授權範圍須逐項列出。

## 驗收

- 參考影片與 OBS 實際輸出在相同時間點比對，差異逐項記錄並由雙方確認。
- 極端情境逐一檢查：文字不被裁切、不被裝飾遮擋，減少動態時顯示可讀的靜態畫面。
- 三個輸出位置同時運作時符合[效能預算](output-motion-rendering.md#效能量測)。
- 素材通過[資產政策](overlay-pack.md#資產政策)的格式與上限檢查。
