# Output 外觀契約

三個 slot 的模板可調欄位、本機來源與預覽一致性。分階段計畫見[外觀 set 計畫](../governance/appearance-sets-plan.md)；傳輸與頁面生命週期見 [Output runtime](output-runtime.md)；可見驗收見[驗收清單](../operations/output-appearance-acceptance.md)。

## 權威

- 執行時由 [outputAppearance.mjs](../../shared/outputAppearance.mjs)、[模板 registry](../../shared/outputTemplateValues.json)、[timing 能力](../../shared/presentation/lyricsTemplateCapabilities.mjs) 與 main／Overlay 驗證決定。Main 在儲存邊界驗證、renderer 依模板欄位清單產生控制、Browser Source 再次正規化後才投影為 `--ovl-*`。
- [固定基線](../../scripts/fixtures/output/appearance-baseline.json)是測試期望，不是第二套 runtime 設定；改能力時須明確審閱基線差異。`npm run output:verify` 唯讀核對，不啟動 App 或 OBS。
- CSS layer 順序：`ovl-reset`、`ovl-fallback`、`ovl-semantic`、`ovl-template`、`ovl-appearance`、`ovl-constraints`，四個 HTML route 以相同順序載入。Fallback 是內建復原基線，不是 Style Set。
- 同一輸出共用調色濾鏡、強度、材質顆粒、相容的字體與可讀性選項，以及功能相同的回顧設定。譯文字級沿用歌詞輸出的設定。模板專屬字型、版面、修飾、動畫與元素設定依模板保存，切回時恢復。初次使用模板時沿用該模板預設，並套用相容的共用偏好。三種輸出各自保存。

## 欄位與分級

- **default**：不需額外資產即可用的初始值。
- **opt**：使用者另選的值；原本就有安全預設。
- **advanced**：已驗證 consumer 的模板才有的藝術角色覆寫，仍有值域。
- **invariant**：App 持有的時序、幾何、source mapping 與安全規則，外觀不能改。
- **not-exposed**：目前沒有 consumer，不代表永遠禁止。

經典字幕、躍動字幕及三款直書的基準字級由 `outputAuthoredFontRem` 提供，以 ¼ rem 為檔位單位。工作臺顯示套用微調後的基準 rem，預覽與輸出共用同一基準。字級微調依模板保存並重新量測歌詞換行。字形比例、鏡頭透視與長句容量仍由模板管理。

每個欄位另宣告 [ADR 0027](../adr/0027-output-template-elements-and-property-workspace.md) 的定義屬性；`group` 仍只決定 Inspector 分組，畫面與儲存不受這些屬性影響。

已登錄模板使用 `UiFolderInspector`。上方排列顯示與文字，其次是播放中可操作的氣泡、特效與人物，再接翻譯。外觀、修飾與動態屬於風格微調，版面與佔位是底部的基礎配置。「模板」是獨立的切換入口，使用中性色底片並留在分頁列末端。工作臺與手機遙控共用分頁順序、短名稱及圖示，各自列出所支援的分頁。初次開啟沿用模板原先的預設分頁。版面涵蓋排列與定位，外觀包含調色濾鏡與顆粒，修飾包含自訂色、背景、裝飾、點綴字體與文字陰影。靛藍色階由上方確認、播放中操作與翻譯、其他設定依序由強至弱。選中分頁使用高對比底色，鍵盤焦點使用外框。模板還原只重設其專屬欄位，共用設定由各區段還原。

只有一個欄位且已有相近分頁時，該欄位連同原設定區段併入相近分頁。讀音、字幕呈現及文字排列可併入文字，魚眼字幕分段併入版面，單一自訂色或唱片高光可併入外觀。歌單背景固定在「修飾 → 背景」。專用操作工具保留自己的分頁。

工作臺與手機遙控共用 `ObsInspectorHeader`、`ObsPropertySection` 及 `ObsAppearanceControlRow`。分頁標題使用 subtitle（16 px／600），區段標題使用 label（14 px／600），欄位標籤使用 body compact（14 px／400），補充說明使用 caption（14 px／400）。標題與模板名稱、直排標籤與控制項保留 4 px，區段標題至內容、欄位間距與標題上下留白各為 8 px，區段上下留白為 12 px。標題下方與同層區段之間各使用一道 1 px 主題分隔線。單一設定區段可沿用分頁標題，例如翻譯。以上尺寸為預設字級下的值，元件使用既有語意 tokens。

| 屬性     | 值與目前規則                                                                                                                                                                                                                                                                        |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `family` | document：Look、強度、字級、讀音、歌詞呈現策略；swatch：兩個自訂色；character：字型、字重；legibility：對比、文字材質；fill：背景；layout：對齊、密度、內容寬度、文字排列、出紙方向、位置與微調；motion：回顧開關與間隔；asset：唱片高光、魚眼鏡框與鏡內反光樣式。stacking 尚無欄位 |

### 設定欄互動

- 視窗縮小時，並排預覽至少保留 18rem，設定欄可縮至 16rem，與展開的左側 Sidebar 同寬。空間不足時自動收合，拉寬須多出 4rem 才恢復並排。手動收合者拉寬後仍收合。
- 設定欄每次展開採最小寬 16rem。展開期間可在 16–24rem 內調整，並受工作臺可用寬度限制。切換頁籤保留當次寬度。窄窗時，點頁籤或拖曳邊線可展開浮層。高度跟隨預覽區，頁籤與欄位各自捲動。預覽與工具列維持原尺寸，點露出的預覽或按 Escape 可收合。
- 游標指向調寬邊界或拖曳時顯示邊線。展開時在寬度範圍內跟手，往外拖到最小寬度時停止縮小，拖過最小寬度的一半才亮起固定邊線並在放手時收合。已收合時也以固定邊線提示，放手才展開。並排開合立即定位，窄窗浮層使用標準滑動過渡，減少動態模式立即定位。

### 元素層級設定

元素宣告在 [outputTemplateElements.mjs](../../shared/outputTemplateElements.mjs)。封面電台提供下列元素設定，演出票根提供曲名的 `fontSizeScale`。

| 元素      | 屬性                               | 備註                                                         |
| --------- | ---------------------------------- | ------------------------------------------------------------ |
| title     | fontWeight、fontSizeScale          | 不可隱藏                                                     |
| artist    | fontWeight、fontSizeScale、visible |                                                              |
| progress  | visible                            | 進度條與時間                                                 |
| transport | visible                            | 播放控制（播放鍵與音量列）；與 progress 都隱藏時收起整個區塊 |

- fontWeight：inherit（跟隨模板）／regular／semibold／bold，預設 inherit；fontSizeScale：80–125% step 5，預設 100；visible：shown／hidden，預設 shown。
- 儲存為 `element.<元素>.<屬性>` 扁平鍵，值存完整而非差異。Main 依模板保存欄位，切回原模板時恢復。
- Browser Source 在 root 投影 `--ovl-el-<元素>-font-weight`、`--ovl-el-<元素>-size-scale` 與 `data-ovl-el-<元素>-visible`，模板規則依元素宣告讀取。
- `ovl-constraints` 的 `--ovl-text-min-size`（0.75rem）為縮小下限：元素字級不低於此值與原始字級中較小者，預設輸出不變。
- Workbench 有元素的模板在 Inspector 頂端提供「調整對象」，預設「整個模板」；選元素時只顯示該元素的屬性群組，底部「恢復模板預設」一併重設元素設定。
- 畫布點選：Workbench 預覽 iframe 帶 `workbench=1`（複製給 OBS 的 URL 不帶），Output 頁面依 `data-ovl-element` 回報目前模板已宣告元素的矩形；同一元素多個節點取聯集，隱藏者不回報。控制台只在目前選中的擷取尺寸上疊選取層：點元素矩形選該元素（重疊時取面積最小者），點其他區域（含封面）選「整個模板」，與「調整對象」共用同一選取。選取層只處理指標，鍵盤與輔助技術使用「調整對象」。

## 外觀套用時機

| 調整                                             | 畫面套用                                                               |
| ------------------------------------------------ | ---------------------------------------------------------------------- |
| 歌詞模板、版型變體和模板進階顯示                 | 播放同步歌詞時從下一個有文字的來源行套用。底片列與模板庫共用這個規則   |
| 字體、位置、可見性、入退場、配色與材質等模板屬性 | 工作臺及手機調整在同一個換句邊界套用。重設或連續調值採最新已儲存的設定 |
| 分格對白的氣泡樣式卡、幻影怪盜的人物組合         | 樣式卡只覆蓋下一句。人物組合從下一句持續使用，播畢回到跟隨歌手         |
| 翻譯顯示與字級、魚眼攝影機特效、取景控制         | 即時套用。翻譯獨立更新，取景按既有預覽及擷取規則處理                   |
| 歌單和播放中模板                                 | 立即切換至當前內容。套用模板不重播已呈現內容的進場                     |

工作臺先儲存選擇。工作臺預覽、OBS 與同路徑擷取以 Browser Source 的播放時間、顯示延遲與歌詞偏移判定換句，句內片段、換頁及間奏不提前套用。最後一句後若無下一句，延至播放離開當前狀態時套用。暫停、跳播、換歌詞及來源恢復時採最新設定靜態收斂，無同步歌詞或首句前可直接調整。

Setlist 只公開目前演唱曲目與已唱紀錄，不投影待唱。480×810 是擷取尺寸而非固定版面：queue-board 以約兩成高度保留目前歌曲，其餘給已唱紀錄，兩區只以固定 spacing 分隔；最近八首依播放順序向下排列，超出時才自動垂直滾動。

歌單背景預設採各模板原有樣式。選擇純色時，共用選色控制及百分比滑桿，0% 為不透明，100% 為全透明。透明度只作用於背景，前景文字、分隔線及緞帶維持各自的繪製。票據歌單的純色沿用紙緣輪廓。樣式、顏色與透明度按模板保存，預覽與 Browser Source 共用相同設定。

`ribbon-setlist` 在 480×810 依演唱順序由上往下填頁。每頁最多 14 列，並依實際列高在整列放不下時換頁。目前曲目置於當頁末列，換頁時從新頁頂端開始。每首沿用依曲序與曲目身分取樣的紅黑配色。預設使用模板白底。拉丁曲名預設 36 px，超過兩行降至 30 px。含漢字、假名或韓文的曲名使用相應無襯線字型，預設 32 px、字重 700，超過兩行降至 28 px，保留原本行高與色帶留白。仍放不下時於第二行省略。序號固定 15 px。色帶的傾斜、錯位與搭接獨立於文字排版。Gallery 與 Browser Source 共用版面及 Output tokens。

緞帶歌單初次顯示目前曲目或換曲時，以 GSAP 播放約 1.18 秒入場。左端與印字位置固定，卷邊連續向右展開，印字依序短暫交疊過渡至放大印字、白色滿版印字及正式曲名。色帶底色由展開延續至落版。曲目轉為已唱時沿用同一字寬、行數、配色與形狀。重複快照、同首資料刷新與重連不重播。減少動態時直接顯示最終樣式。模板庫與正式 Browser Source 共用入場和刷幕時間軸。

中日韓曲名中的拉丁片段與其標點使用 Output 的 UI 字型。原始曲名、全形字元與東亞標點保留。

白色實底沿用 Output 間距 token，紙面與刷幕皆收在四周 8 px 的透明邊界內。

開啟緞帶歌單的定時回顧且已有上一頁時，直播版面經過工作臺設定的間隔後，依直播分頁的原邊界回顧較早的一頁。GSAP 在上下紅色刷痕各自覆蓋後換頁，目前曲目隨下半切出。兩塊刷幕在中央略微交疊，以覆蓋縮放時可能出現的接縫。刷入 640 ms，兩段退開後固定停留 3 秒，接著以 320 ms 刷回。下一輪繼續回顧更早的一頁，回到最早頁後循環。關閉回顧、調整間隔、換曲、切換模板及連線恢復會取消舊刷幕並還原直播畫面。減少動態或動畫引擎無法使用時直接換頁。兩頁共用相同背景。刷幕暫時覆蓋掃過的區域。

Now Playing 的三款模板共用 `artwork-overlay` 結構及封面、曲名、藝人呈現。舊 `now-next` id 在設定讀取邊界回退為 `art-card`。

星空黑膠的「外觀 → 裝飾」提供唱片高光，預設關閉，可選柔和或標準。高光沿盤面掃過，限制在唱片溝槽區域。GSAP 移動光帶，CSS 負責光色與遮罩。播放時往返，暫停時定格，減少動態或動畫引擎無法使用時保留靜態高光。模板庫的動態樣張展示標準高光，工作臺與 OBS 依保存的選擇呈現。

`ticket-stub` 以既有 Now Playing Browser Source 輸出暖白票根。方形封面使用已驗證的 artwork route，票身隨當前曲目更新。短副券維持素面，兩側缺口與票身外使用透明合成。控制台預覽與 Browser Source 共用票身樣式，Folder 共用切口與紙紋。

`cover-player` 採使用者確認的Apple Music參考比例：預設portrait擷取360×480，portrait-large保留480×640。原portrait設定直接採用較小尺寸，舊medium設定正規化為portrait；medium本身仍為480×540。封面方形、曲目資訊靠左，單行超長省略；480×640設計基準的曲名22px、藝人18px；360×480等比縮為16.5px、13.5px。背景依既有封面取色產生暗色暈染，透明／柔和背景仍可選。細進度條與剩餘時間跟隨播放器權威；僅保留上一首、播放／暫停、下一首三個圖示及音量外觀。這些是只讀Output的非互動圖示；音量列同步App主音量與靜音，播放／暫停符號跟隨實際狀態。音量為0或靜音時顯示靜音符號，靜音時滑塊歸零，解除後恢復原設定；沒有音量資料的舊來源保留該列空間但不顯示數值或符號。隱藏transport時一併隱藏音量列。封面沿用已驗證media route，缺圖用曲名首字；不交付參考截圖或其專輯美術。

Gallery 的 CoverPlayerPreview 沿用相同3:4比例與480×640設計座標，在360×480及480×640擷取尺寸等比呈現，以 canvas 單位縮放封面、metadata、16px 時間行框、進度與控制列；詳細預覽與 16:9 縮圖容器都保留完整直式版面。進度填色與圓點共用同一有界 scene progress，不以假循環或封面位移動畫改變此版型；預設示範封面仍使用既有曲名首字與 feature 色彩 tokens。

封面電台以track id變更觸發160ms淡出、透明時交接封面／曲名／藝人、240ms淡入；音量、靜音、進度及時間不等待此過場，亦不觸發重播。快速連切只交付最新曲目，過期callback失效；reduced-motion、隱藏恢復與模板切換直接settle。Gallery維持固定合成場景，不加入假切歌循環。

## 歌詞模板呈現

`fisheye-lens` 的工作臺與 Browser Source 讀取同一曲目的歌詞投影。字列由右至左閱讀，每列由上到下。拉丁詞與 grapheme 保持完整，兩列各最多 10 個單位，超長以省略號提示。文字頁籤調整字級，修飾頁籤調整文字色、鏡框及鏡內反光樣式。鏡心維持透明。內圈反光依播放時間向外擴散，到鏡口逐漸淡去。換句和間奏延續同一波紋，暫停時定格，減少動態時使用固定反光。

「修飾 → 裝飾」的鏡框與鏡內反光各自可選關閉、柔和、標準，預設標準。柔和使用該物件原本的 50% 強度。既有百分比依原設定的 5% 步進正規化後，0% 對應關閉，5–70% 對應柔和，75–100% 對應標準。讀取時正規化，下一次儲存時寫入樣式。關閉一個裝飾時，另一個仍依自身設定呈現。關閉鏡框只隱藏前景繪製，歌詞與反光仍沿原有圓形鏡口裁切。

有可信副歌區間時，魚眼鏡筒在副歌起訖切換基本／副歌狀態。自動構圖在基本狀態使用標準構圖，副歌使用近景。退場預設「隨段落切換」，基本狀態使用沿弧轉出，副歌使用漩渦捲退。明確選取的退場在兩種狀態都採用所選效果。交界落在同一句內時，字幕從目前的時間繼續。跳播直接採用落點的狀態。區間優先取自曲目段落，其次取自同曲同步歌詞中的重複段落，證據不足時使用基本狀態。

「版面 → 鏡頭構圖」可選副歌自動貼近、標準或貼近。貼近以同一鏡心放大鏡圈 28%，上下伸出畫幅。左右字幕沿各自外弧排列，右列略高，字級較大，長句仍收在畫幅內。鏡心留給外部近景人物與背景。

副歌自動貼近以播放位置為起點，推近 560 毫秒，拉回 430 毫秒。鏡框、玻璃反光與外弧字列共用構圖進度。進退場依歌詞時間取樣同一組 GSAP 時間軸，量測的動畫格之間可連續取樣。暫停會定格，跳播與減少動態會直接呈現目標構圖。

圓形外圈是貓眼視野的前景遮罩。波紋、歌詞及其進退場共用同一個圓形裁切，前景鏡框最後疊上。內圈反光帶有厚薄起伏，各圈向外推進時略微旋轉，擴散越過內部橢圓，直到外圈。圓形上下超出畫幅的部分依畫面邊界裁切。透色本體、外緣柔光和局部亮邊分層繪製，保留底圖可見。冷青高光與暖紫粉反光分布在不同方向。反光以透明色層與 OBS 場景合成，底圖的實際折射需取得背景畫面。

工作臺的「攝影機特效」可切換自動穿插，並分別觸發一次 Glitch、推拉或雜訊。Output 將同一事件同步送至已連線的工作臺和字幕輸出頁。短效事件繪製在鏡圈與歌詞上方的全幅透明畫布，涵蓋鏡口外緣與四角。Glitch 位移取樣魚眼模板自身的畫布，推拉縮放魚眼鏡圈和字列，其他獨立來源透過色帶、暗角與顆粒呈現疊加效果。自動穿插預設關閉，只維持本次 Output 執行期間，切換模板或停止 Output 時關閉。過期事件不補播，減少動態時停用特效。

動態頁籤分開設定進場及退場。兩個選單都依沿弧、逐字縮放、漩渦、直接切換排列，進場專用的煙團露字排在最後。預設沿弧依原有 24 格／秒的節奏轉出 3 格、留空 2 格、翻正 3 格。停留縮放可由 0% 調至原幅度，沿弧動態模糊預設關閉。極短字幕、暫停、跳轉當格與減少動態時顯示完整字形。同步曲目間奏保留空鏡。

顯示頁籤的字幕分段預設整句。短句優先採用對得上時間標記的句末標點和原文換行，斷點避開引號或括號內、數值內及重疊時段。可用的短句先等到第一個有字內容的時間點才出現。來源段落沿用歌詞文件的逐段時間與段間空白。沒有可靠斷點時回到整句。左右弧列在容量允許時，讓逗號與閉引號留在前文所在的列、開引號跟著後文，並將英文縮寫、連字詞、數值及組合字形保留為單一單位。所有模式沿用播放速率和歌詞偏移，設定不寫回歌詞文件。

和風直書的「文字陰影」位於文字頁籤。標準保留正文的基礎陰影，漢字入場時另有一層投影從字形向右橫移 0.14 em，最多 0.18 秒到位。首字為漢字時，正文立即顯示，投影接著展開。極短字幕、跳播或減少動態時，陰影直接到位。既存設定缺值時使用標準。關閉移除正文字形的基礎陰影與移動投影，藝術字的輕墨層仍由強調色控制。工作臺預覽與 OBS 使用同一條 Browser Source 渲染路徑。

同一頁籤的「字體排列」預設為「等大」。選擇「大小字」時，漢字用基準字級的 125%，假名用 80%。同欄相鄰漢字之間加 0.08 em，漢字與假名交界加 0.12 em，均以基準字級計算。連續假名、標點、空白、拉丁字與欄末沿用原間距。量測與輸出共用這組字級和字距。

英文直排保留同欄內的原文詞距，並將 `I'll`、`I’ll` 這類縮寫視為同一入場單位。西文標點隨英文詞側轉，中日文標點沿用直排字形。分欄處的空白留在原文索引中，排版時去除欄尾的空白。單欄內仍有換行符號時，以行內空格顯示。

和風直書的預設組合是左右滑入與同批顯示。同一條計時歌詞拆成多欄時，各欄同時開始進場並一起退場。選擇一次一欄時，依已對時的歌詞片段切換，片段不足時按字量分配當頁時間。任一欄的可讀時間短於 380 毫秒時，整頁改為同批顯示。逐字淡入時，各欄由上往下進場。重點漢字先入時，每欄優先顯示已標成關鍵字的第一個漢字，其次為首個漢字。其餘字依欄內讀序補位，沿用原字位與漢字投影。

每批歌詞優先沿來源換行、片語分隔空白、句末標點或明確語意斷欄，從右往左閱讀。短前置片語可獨立成欄，三個清楚片語可同批排三欄。短句的弱詞界留在欄內。缺乏明確斷點的長句再依安全詞界及可用空間選擇兩欄。標點留在前段，開引號隨後段第一字，閉引號隨前一字。引號或括號內的標點、小數點與數字中的千分位不產生欄界。

同批同步進場時，相鄰欄的起筆位置依序下移 2 em。長句的相鄰欄放不下時，以主要語意斷點分成右、左兩區，每區最多兩欄。新區首欄回到頂線，區間總留白為 2.5 em，區內欄距為 0.5 em。量測納入各欄字高、下移量與區間留白。仍超出可用空間時，依來源時間與斷句分頁。

同批顯示會將相鄰計時行中明確的日文原因段與接句合在同一構圖。原因段保留右欄，左段到自己的起點才進場。這類接句的區內續欄以 1.25 em 逐欄下移。先量測右一、左一欄，左段太長才量測右一、左兩欄。兩種排法都放不下時沿用原有分頁。原因段與接句之間最多可銜接 100 毫秒的短空隙。

左右滑入時，文字依欄內讀序從短距離滑回各自字位。位移以左右方向為主，同一歌詞批次的起點固定。暫停、跳播與減少動態時直接顯示當時的歌詞批次。

同一頁籤的「段落強調」預設關閉。自動模式從已對時的歌詞找連續三句以上且完整重現至少兩次的段落，起始三句的文字須各不相同。以全部重現的總行數選出一組主要段落。較早出現時每句選一處，最後一次重現可在後半加一處。選點由句序、段落次序與字位決定，保留英文詞及結合字形。自動模式停用藝術字輕墨層，無合格段落時維持單色。強調色沿用自訂值，預設使用玫瑰色。換曲目或歌詞文件時重新判定，跳轉時依同一版本的來源範圍重現字色。此選項仍待實曲驗收。

五款正式字幕的構圖、位置限制與左中右人物佔位研究見[VTuber 佔位回看](../research/design/lyrics-overlays/production-vtuber-placement-review.md)。

歌詞呈現分兩層：`lyricsTimingUnits.mjs` 只把 T1 fallback 切成無語意的 `{ text, weight }` 單元，原文換行、空白與標點無損附著；`lyricsPresentation.mjs` 再依版本化的 Generic／KTV／Kinetic Pop／Ornate Vertical／Manga／Live Stage profile 解讀為 phrase、role、bubble 或 caption page。Browser Source 依 document id、revision、language 與 profile 快取靜態結果，`state.mjs` 投影動態 frame 與下一個 boundary。`lyricsTemplateCapabilities.mjs` 是各模板 T1／T2、source mapping、music cue 與 scheduler wake 的唯一宣告。模板分句不回寫 canonical timing，T2 永遠優先；raw LRC／VTT parser 不進模板。

- **karaoke-stack**：封裝 justfont open-huninn 2.1（OFL 1.1），使用 beat phase 與段落（見[音樂分析](music-analysis.md)）。
- **live-stage**：轉播精簡（移除可判定的 filler、連續重複與 CJK 顯示標點）、平衡分行、忠實原文三個 policy，都保留 canonical `sourceText` 與 line／segment identity。Caption 先列出 1／2、2／1、2／2 候選，依容量、作者與跨語邊界、附著性與幾何選解，不為個別歌曲加例外。多頁且有 T2 時以 `lyricsSourceMapping.mjs` 映回來源區間插值，失敗才用 T1 權重。
- **manga-frame**：依 document language、實際假名或既有讀音投影 `ja`／`other`。預設封裝 GenEi Antique 6.0a，可改 sans／serif／rounded；ruby 繼承對話框字體。可從 `lyrics.document` 取得已存在且 identity 相符的日文讀音；publisher 只讀 sidecar，不為 OBS 啟動讀音 worker。
- 中央直書提供文字色與可讀性選項。黑板直書的文字色和輔助線色可分別調整，預設沿用原本的紙白色。
- **ornate-vertical** 以 grapheme 保留原文，漢字與假名都以完整字形進場。標點隨相鄰文字出現，拉丁字母與數字成詞。關鍵字保留群組強調。分欄保留連續漢字詞，可在明確的語意詞界分開相鄰的詞。Browser Source 與 Gallery 共用 `ornateVerticalMotion.mjs` 的入場節奏。每批的首個入場單元立即顯示，後續單元淡入 0.12 秒，間隔按字量及實際可讀時間收短。時間極短、跳播、來源中斷與減少動態時，該時刻的正文直接顯示。字型為封裝的 Hina Mincho 與 GenEi Antique。
- **chalkboard-vertical**：畫布橫向等分，預設左區，可切右區。每頁至多三欄，共用頂線與右側起點，續欄往左排。首欄在來源句首起筆，後續各欄對應自己的來源起點，缺少細時間時按字量估算，後續欄比起點稍早寫入。每欄文字與右線由上往下逐字寫入。右線與同欄文字等高。舊段在自己的時段末端退場，文字由下向上逐字收回，右線在同一時段由上向下連續擦除。換句或分頁時清掉殘留再接新段。暫停、seek、重連及 reduced motion 直接顯示已到起筆點的欄位。沿用 Open Huninn、字級和 X ±12%、Y ±25% 微調，水平位置受所選區邊界約束。見[第一版驗收](../research/design/lyrics-overlays/chalkboard-vertical-build-spec.md)。
- **centered-vertical** 將當前頁的單欄文字水平與垂直置中。欄內字距為 0.08em，預設小字級，長句按高度分頁，換句與換頁直接替換。字型預設依歌詞語言，繁體中文使用辰宇落雁體，日文使用 Klee One SemiBold，其他或未標記語言使用 Open Huninn。可手動指定其中任一字型。白字帶薄暗邊和右下陰影，適合有直排慣例的歌詞。混語中的英文側轉，英文為主的歌曲建議使用橫排。[中央直書首版](../research/design/lyrics-overlays/centered-vertical-build-spec.md)
- **kinetic-pop**：每次顯示一個橫列短句，依來源行輪替三種材質。優先採原文換行和片語空白，其次用標點及連續重複的短詞，再為長句找安全詞界。引號、括號及混語中的英文詞組保持完整。T2／已套用 T1+ 以來源起點切換，只有行級時間時按字重估算。一般短句至少 400 ms，已識別的連續疊詞可縮至 200 ms。過寬的單列以畫布底部中心為基準等比縮合，預留描邊及進場空間。大字級以 8.5 rem 為基準，文字列錨定於畫布下緣上方 4.5% 或 3 rem，以較大者為準。紅色亮邊材質在此檔位使用基準字級。原色材質以原版《阿修羅ちゃん》MV 為參考。黃字主歌採亮黃，副歌短句轉為金橙，外側用 0.14 em 暗線。紅字採上深下亮漸層、0.038 em 細白線、0.145 em 暗色外框。色差款用冷白字面、0.06 em 暗線及小幅錯位的青紫邊。三款色彩與描邊共用同一份 CSS，色調濾鏡從這組原色混合。Gallery 依同一組短句播放樣張，與 Browser Source 共用 `shared/browser/kineticPop.mjs` 和 `overlay/lyrics/kineticPop.css`。換句直接替換。普通句保留 28 ms 內的錯序入場。短句在最多 52 ms 內錯序彈出，單字先放大，再以兩段逐次減弱的位移與縮放收穩，完整入場最多 183 ms。三個材質層共用同一字的姿態與開場時間。端正排列使用零偏移，些微偏移保留八相位姿態。GSAP 依播放位置取樣。
- **textured-credits**（開發中）：全句以原字級完整顯示。橫書沿用共用斷行規則，先斷在標點與片語空白，拉丁詞不拆，每列上限 18em，再平衡各列寬度，不留孤立詞尾。直書每欄放一個完整片語，片語超過欄長才在詞邊界拆開；超過三欄時分成兩段左右並列，先讀的段在右。紋路包含公式、電路、小線稿與化學結構，方向隨直書或橫書轉向，範圍限在歌詞外約 1.6 倍字級並帶不規則邊緣。每句隨機 3–5 層，各層沿自己的方向燃入後立即同向燃出，起點錯開、終點一致。效果只佔句首，時長取 0.7 秒與句長 40% 的較小值。歌詞先以螢光色出現，紋路消散時轉為白字。
- **來源視窗的混語長句預覽**：`lyricsPhraseBreaks.mjs` 提供最多兩段的顯示候選。對時預覽使用來源 T2 或已套用 T1+ 的精確起點，來源時間不足時只展示文字候選。躍動字幕依模板的短句規則選擇斷點，沿用相同的來源時間。

所有封裝字型、來源 checksum 與授權位於 `shared/assets/fonts/`。Renderer 預覽與 Browser Source 用同一份檔案，網頁端透過明列的路由載入本機字型。GSAP recipe 持有可中斷的 playhead、sequencing、reduced motion 與清理，CSS 持有版面、材質與靜態狀態，兩者不同時控制同一屬性。GPU 特效與動畫師素材的分工見 [Output 動態與渲染契約](output-motion-rendering.md#渲染分工)。

模板字型提供 Black Han Sans、Gowun Batang、Jua 與 Single Day。選擇後只替換 Hangul 字形，混排段落的其他文字沿用模板的字型順序。Black Han Sans 與 Jua 缺字時會先使用完整涵蓋現代韓文音節的 Gowun Batang。選擇記在該輸出的共用偏好，可隨同一輸出切換模板。

### 重複歌詞入場

句內自動合併限於原樣連續出現至少三次的片段，空白分隔的單字須至少四次。只出現兩次、標點隔開、或位於括號及引號內的片段保留原文。達到門檻後，直書、對白及字卡維持一份字幕；躍動字幕依短句切割，獨立的連續疊詞可逐次彈出，接續日文詞尾的短詞保留為一個入場。經典字幕抑制相同的預告列及換列殘留，逐字填色沿用來源的演唱時間。連續同句選擇入場一次時維持同一列，首句完成後保留其填色。中央直書以靜態換頁顯示。

「共用文字處理」內的「重複歌詞入場」依來源及歌詞行儲存「依模板」、「保留原文」、「入場一次」或「逐次入場」。選擇「保留原文」會略過該行的去重；使用「入場一次」或「逐次入場」可手動處理連續兩份的候選片段。逐次入場優先使用 T2 或已套用 T1+ 的來源起點；只有行級時間時才估算。粗詞塊無法取得疊詞的起點時保留單份顯示。相同句子出現在不相鄰的段落時各自入場。

### 分格對白

- 三個氣泡同時顯示時採右上、左中、右下，右側上下框及尾巴共用預留間距。換句時若重用同一側，舊框先淡出再由新框淡入。位在不同側的兩句可同時淡出與淡入。模板 Gallery 的動態樣張共用這套行為。
- 「版面」可選一般對話、低語、思考及爆發，作為主歌詞的預設氣泡樣式。插語使用低語，預設為低語時改用思考外框。
- 「尾巴朝向」預設跟隨模型佔位，可切為固定朝向。工作台預覽在拖曳時即時跟隨遮罩中心，確認位置後同步到 OBS。一般對話、耳語與思考的尾巴朝向遮罩中心下方，偏移量為畫布高度的 4%，最遠到畫布底緣。指向點落在框內時收起尾巴，爆發維持鋸齒輪廓。
- 「氣泡」頁籤提供四種 SVG 樣式卡。選擇後只在下一句有時間標記的主歌詞套用一次。可改選或再按一次取消。選擇期間當句照常顯示，再下一句恢復預設樣式。切歌、跳播、換歌詞、切模板與自然播畢會清除排定。

### 幻影怪盜

幻影怪盜預設使用側邊彈卡的「有頭像」樣式，亦可切換「純對話框」。對話框主體依歌詞實測寬度及安全內距調整，最寬為畫面的三分之二。正文區預留至少 1.5 行字高，單行垂直置中。歌詞起點在尾端留少量內距。只有名牌輪廓與正文同高的部分會增加內距。黑色斜框的 W 折線上方開口，外側黑邊沿折角延伸，抖動時仍與白邊相連。有名牌時，W 的右端接至名牌下緣。主框上緣向右抬升，底緣向右下降。主框白線外包連續的粗黑邊，右側框線由尖片上方及下方接續。名牌的上下長邊接近平行，姓名固定在名牌本體的基準中心，外框抖動時文字位置保持穩定。三角尾與名牌主體交疊成連續輪廓。名牌與末端白色尖片沿各自輪廓描黑邊。名牌底部的三角尾接近水平。姓名起點靠近對話框上緣，單行與雙行時，名牌疊在對話框靠人物側的上角。名牌與對話框的尾尖接近人像高度的 1/2 至 2/3 處，各自作為動畫支點。聊天可選泡泡、思考泡泡、堆疊卡或手機。預告信可選怪盗予告ゴシック、怪聞書或無點綴字體。紙片的底色、紋理、切邊與方向依曲目和句序搭配，同一句重繪保留原搭配。選句剪報預設右下，以有尖折尾和斜切邊的紙帶顯示白底當句及已有的黑底前後句。選句紙帶與彈卡的框形延伸至對齊位置外，留出文字與斜邊間的空間。左右換位時，框形水平鏡像，文字照常閱讀。

- 側邊彈卡的「人物」頁籤每列三格，排滿後往下續列。格內顯示方形預覽，格下顯示名稱。「跟隨歌手」在清單首位，採用目前歌曲的歌手名稱、第一位藝人的照片，以及按歌手穩定分配的專案四色之一。自訂組合依名稱字母順序排列，最後一格為新增入口。可另建最多 12 組。
- 上方工具列可依名稱篩選，並可編輯或移除目前選取且顯示於結果中的自訂組合。篩選時可用「跟隨歌手」或當前歌手的名稱找到預設組合。
- 點選新增或編輯後，依序顯示照片預覽與操作、顯示名稱、人像底色。新增時以專案色票帶入底色，預覽隨草稿的照片和底色更新。未設定自訂照片時，編輯欄位顯示人像圖示。自訂照片支援 10 MB 以內的 PNG、WebP 或 JPEG，可清除以跟隨歌手照片。名稱留空時跟隨歌手。
- 選檔後開啟「編輯照片」。原圖等比例完整置入 1:1 畫布，可直接拖曳取景，以滾輪或圖示按鈕縮放。棋盤底顯示透明區域。可直接套用，或透過「移除背景」使用內建模型離線去背。去背成功時，已有手動取景則保留位置與縮放，否則將主體等比例置中。原圖與去背結果共用取景，套索啟用時拖曳用於圈選。取消時捨棄選圖草稿。套用時保留未變更的正方形原圖，其他情況另存 1:1 PNG，再更新人物組合草稿。斜切框合成在人物組合的 Output 預覽確認。
- 右側依序顯示移除背景、結果切換與去背工具。使用去背結果時，去背範圍和邊緣銳化以百分比顯示調整幅度，局部修正預設收合。去背範圍以 0% 為基準，負值多保留，正值多移除。
- 「邊緣銳化」調整遮罩半透明邊界。「局部修正」提供圖示按鈕，可用智慧套索圈選殘留區域或補回原圖內容。放開時套索自動閉合，圈內邊緣依去背遮罩柔化。圈選結果跟隨原圖座標，取景變更後仍對準同一位置，可復原最近十次圈選。
- 選圖後預設啟用「構圖輔助」。九宮格顯示於 1:1 取景畫布，拖曳時依目前影像的可見範圍吸附至中心、三分線或底緣。按住 Alt 可暫時自由拖曳，關閉構圖輔助可同時停用格線和吸附。構圖輔助線僅供編輯預覽。
- 儲存後建立或更新組合並套用，取消則捨棄草稿。同步歌詞播放中切換人物組合時，當句保留原有姓名、照片及底色，下一句使用最新選擇。曲目自然播畢後，自動回到「跟隨歌手」，已建立的人物組合仍可選用。切換模板會保留組合，移除目前套用的組合會回到「跟隨歌手」，並保留照片檔。舊版自訂人物設定會移入組合，保留套用狀態。
- 桌面預覽可在 Output 停止時載入。桌面與輸出皆優先使用自訂照片，歌手照片等比例填滿人像框。透明自訂圖可在輸出的斜切框頂緣露出，底緣沿框收齊。

### 翻譯字幕

翻譯字幕從同一播放時間取對應來源行，預設固定在輸出畫布左下。原文模板切換、換頁或進行版面量測時，字幕維持自己的位置與樣式。當句缺譯、譯文語言關閉或時間軸進入空白時，字幕隱藏。

歌詞工作臺的「翻譯」分頁管理顯示模式與譯文字級。可關閉譯文、跟隨畫面輸出語言或選擇指定語言。字級以 100% 為預設，可從 75% 調到 150%。兩項設定跨歌詞模板共用，切換模板和重設原詞外觀時保留。

Browser Source URL 可用 `translationPosition` 指定位置，接受 `bottom-left`、`bottom-right`、`top-left`、`top-right`。

## 配色風格

所有輸出模板提供「配色風格」與「套用強度」。工作臺色票使用共用目標色，Browser Source 依模板混合語意色，或對保留原有繪製方式的字幕與收據套用 RGB 調色。
黑白、Fujifilm NOSTALGIC Neg.、Fujifilm ETERNA、Fujifilm Velvia、Kodak Gold 200與 Polaroid 600也會調整播放中模板的封面 RGB，涵蓋切換中的封面。調色維持影像的 alpha 與畫布透明區，強度為零時使用原貌。
三款 Fujifilm 風格依照原廠公開描述設計，為應用內的調色近似。NOSTALGIC Neg. 偏琥珀、ETERNA 降低飽和度與對比、Velvia 提高飽和度與對比。參考 [Fujifilm 膠片模擬](https://www.fujifilm-x.com/global/products/film-simulation/)。
Kodak Gold 200使用偏暖的鮮明色彩。Polaroid 600以 Color 600 即影即有底片為參考，採奶油色亮部與較淡的暗部。參考 [Kodak Gold 200](https://kodakprofessional.com/photographers/film/everyday-film) 與 [Polaroid Color 600](https://www.polaroid.com/en_us/products/color-600-instant-film)。

## 材質顆粒

底片風格各自指定顆粒的強度與粗細，和配色共用「套用強度」，歸零時一起關閉。
所有輸出模板的「材質」另提供顆粒強度與粗細。這層預設關閉，粗細可選細、中、粗，切換配色風格時會保留設定。
歌詞與歌單顆粒作用於實際輸出內容。播放中顆粒作用於封面與演出票根的紙面。兩層可同時使用，依序套用風格、材質，各自保留來源透明度。

## 預覽

`shared/presentation/outputPreviewScene.mjs` 提供唯一的合成場景 `showcase-t1-v1`：固定時間 2026-10-20T00:00:00Z，paused 5 秒／長度 32 秒，自製日文 T1 與讀音、示範曲目與目前／已唱／待唱項目，不摘錄真實歌曲。`createOutputPreviewScene()` 直接呼叫 canonical frame selector，同一 snapshot、時間與設定得到相同 frame；空 snapshot 得到空 frame。

- Workbench URL 先清除 query／hash 再加受控參數；OBS 複製 URL 只附 layer 名稱與尺寸，由 main 推導。
- Workbench 畫布依序切換透明、白底與黑底，預設以棋盤格標示透明區域。底色由工作台繪製在即時預覽下方，純色固定為白或黑。
- Gallery 網格顯示靜態縮圖，圖片無法載入時顯示佔位。展開的模板詳情會依目前選取載入共用畫布與該模板的預覽模組，並自動播放。切換模板或收起詳情時會停用先前預覽，並忽略尚未完成的舊載入。載入前、載入或渲染失敗，以及系統偏好減少動態效果時，詳情使用靜態圖。
- Gallery 的躍動字幕預覽先依畫布實際寬度換算字級與安全邊界，再開始繪製字層。畫布尺寸改變時維持比例，動畫循環依原進度繼續。
- Gallery 搜尋比對目前種類內的模板名稱與顯示的特色；語言名稱比對模板的建議語言。收藏依模板 ID 存在本機，Gallery 與 Workbench 底片都先列收藏，各組內維持目錄順序。篩選隱藏目前選取時，詳情區提示重新選擇。
- 歌詞 Workbench 的「模型佔位」依寬高比由等寬高到細長提供正圓形 1:1、正方形 1:1、直橢圓 3:4、圓角矩形 5:8、直長方形 9:16。預設為直橢圓。拖曳本體可移動，角點等比縮放。正圓形與正方形依畫布像素維持等寬高，側欄輸入會同步調整另一邊。其餘形狀也可用邊點獨立調寬或調高。切換形狀時以目前高度為基準套用新比例，中心位置會在畫布邊界內調整。側欄可還原預設直橢圓與位置尺寸。
- 拖曳佔位時，中心和四個外緣都可吸附水平與垂直的中央線及三分線，外緣也可對齊畫布邊界。每個方向會保留已吸附的對齊點，移開後才重新選擇最近的對齊點。縮放時由移動的邊吸附，角點維持等比與對角固定。只在吸附期間顯示對應輔助線，按住 Alt 拖曳可暫停吸附。側欄數值輸入與正式 Output 保持獨立。
- 模型佔位面板同時顯示「圖片」及「遮罩與位置」。圖片區提供換圖及預設圖。遮罩與位置區依序顯示遮罩形狀、中心 X／Y、寬／高，調整後可由區段標題還原。內建圖片裁掉全透明外邊後置中等比縮放。換圖接受本機 PNG、JPG 或 WebP，並開啟共用圖片編輯視窗。視窗依開啟時的遮罩形狀與實際寬高比例預覽，套用後以該比例保存 PNG，遮罩由工作台合成。已啟用畫面輸出時可選擇去背。圖片位於歌詞畫面下方，選取時邊線和控制點位於歌詞畫面上方。
- 圖片、形狀與畫布比例存為本機工作台偏好，跨歌曲及歌詞模板共用。切換為 MV 或隱藏預覽背景時收起編輯工具。MV 無法顯示時仍可看見人物參考。正式輸出只接收分格對白尾巴所需的已確認中心點。
- 分格對白在工作台選擇顯示模型時，使用遮罩的外接矩形試算氣泡避讓。有重疊時優先採最近的水平空位，並檢查畫布邊界與同批其他氣泡。找不到空位時保留既有構圖。尾巴在氣泡定位後再計算方向。新舊框的實際位置相交時，舊框淡出後再讓新框進場。切換為 MV 或隱藏背景會移除預覽避讓。

## 驗證

相鄰測試比較模板 canonical frame、設定正規化、V3 讀音 document、空態、Vue reactive prop 與 URL 隔離。`createAcceptanceMatrix()` 產生逐模板的適用 case 與證據層級；純投影通過不代表 runtime 或人工驗收完成，也不代表作品可上架。全模板的 Browser Source／透明合成與長時間效能仍待驗；W3 的有限視窗擷取結果見[驗收紀錄](../operations/output-appearance-acceptance.md#w3-收尾紀錄2026-10-21)。

## 收據歌單

`receipt-setlist` 使用480×810透明外圍與無字熱感紙底圖。SETLIST與NOW PLAYING為固定區塊，不顯示播放清單名稱或曲目計數；向下為預設，向上另選。紙卷側保留76px安全區，文字避開陰影。短曲名自然一行，長曲名最多兩行、第二行末省略，原唱一行緊接下方；缺原唱保留該行。最新端依實際列高取完整可見項目，不為短曲名保留空白第二行。一般播放歷史可顯示但不視為確認完成。演出安排只以completed項目產生內部已唱總數與明細；略過、中止不列印，最後一首已完成但沒有下一首仍可顯示。

完成一項僅將該項從固定印字邊界送入歷史，不重印整張，送紙距離使用該項實際高度。定時回顧僅於溢位時啟動，預設15秒。回顧期間同一DOM清單在固定viewport內連續位移，不切頁、不改裁切高度或重建項目；內部有界分段只用來選更舊的終點，每輪最多推進三段，長歷史下輪接續。每程依距離0.8–6秒勻速移動，抵達後停1秒，再反向連續捲回最新端；回程完成才重設間隔。新完成優先取消去程／停留／回程，回到最新端送紙並重設計時。Reduced-motion直接安置；inactive／dispose取消timer與tween，恢復或切方向不補播舊列印。

Browser Source與Vue預覽共用receiptView、receiptMotion與receipt.css。正式回顧最多最近100筆來源確認明細，來源總數另計；不是無界整場歷史瀏覽。實機OBS alpha與使用者視覺驗收另記，不以單測／截圖代替。

紙面採已確認的淡紙紋：`receipt-grain.png`以0.32圖層opacity、multiply輕疊，並以既有`receipt-paper.png`的alpha作mask；單次覆蓋、不重複接縫。紋理在文字下方且不隨歷史捲動改變，紙邊輪廓與排版維持原樣。

切歌文字共用`createSetlistCurrentMotionController`的fade-only交接，只作用於曲名與原唱：160ms淡出後才commit新frame，再260ms淡入；NOW PLAYING標籤與紙面不位移。交接時一併commit該frame的歷史，避免先換文再補動畫。一般播放時鐘更新不重播；快速連切保留最新pending frame，recovery／停用直接安置，reduced-motion改為120／180ms淡出淡入。

字體與對齊以480px寬度為基準：SETLIST採等寬22／30px、600字重、0.04em字距並置中；NOW PLAYING維持16／22px靠左。目前曲名26／34px、600字重，明細曲名20／26px、400字重，原唱18／22px。序號欄右對齊並與曲名第一行共用基線，續行與原唱保留同一文字起點；列高仍依實際字型量測，不固定回兩行槽位。
