# 外觀 set 規劃與交付標準

本文件維護額外外觀作品的取得方向、範圍與品質標準；產品現況見[規格](../spec.md)，元素工作區的實作順序見[ADR 0027](../adr/0027-output-template-elements-and-property-workspace.md#phases)，Pack 技術邊界見[契約](../contracts/overlay-pack.md)。目前沒有定價、收款或上架安排；既有模板不因共用基礎完成而取得商品驗收。

2026-10-20 的[八模板盤點](../archive/appearance-template-gap-audit-2026-10-20.md)與[原始資料](data/appearance-template-audit-2026-10-20.json)保留當時範圍。之後的模板數量、缺省值與可調項以[Output 外觀契約](../contracts/output-appearance.md)為準，不以舊盤點覆蓋現況。

## 已確認的取得方向

未來每個額外 set 個別單次取得，新作品另計，已取得作品範圍內的修復不另收；純自願支持與作品取得分開。現有模板都只是待改善素材，不安排當期合集、定價或上架。
不同取得途徑可以授予同一作品使用權，但目前不建立點數／廣告系統。Discord、充值、任務與合作贈送等比較只保留在[市場研究](../research/product/appearance-support-models-market-plan-2026-10-20.md)，不繼續擴張本輪共用基礎工作。

## Set 的身份與範圍標準

商業上的一個 set 是對外宣告的作品範圍，不必等於一個技術壓縮包或單一模板。
沿用 [ADR 0011](../adr/0011-overlay-instances-and-presentation-pack-delivery.md)與 [Overlay Pack Contract](../contracts/overlay-pack.md)的 Template、Official Style Set、Presentation Pack 與版本分工，不另造競爭的 runtime 模型。

| 項目         | 未來必須明定的標準                                                                                                                  |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| 身份         | 穩定的作品身份、名稱、作者、簡介與內容清單；改名不讓已擁有者變成未擁有，不藉改 ID 再收修復費                                        |
| 範圍         | 明列適用 Lyrics／Setlist／Now Playing 哪些用途。單一用途作品可以成立，不強制每個 set 都涵蓋三種；宣稱完整套裝時才須交付所列完整範圍 |
| 風格         | 定義文字、色彩、材質、構圖與動態語言；不是把同一版型的每個色號拆成作品                                                              |
| 可調整性     | 明列可調項與保留的設計規則；基本字級、配色／位置、同步修正、可讀性與 reduced motion 仍屬免費能力                                    |
| 能力與相容性 | 明列依賴的 app-owned template／capabilities、最低 App／契約版本與已驗證輸出尺寸；不以購買權利覆蓋依賴缺失或功能 gate                |
| 版本         | 作品使用權、packVersion、styleSetId、模板能力與 App 版本分開；實際欄位沿既有 contract，商業身份對內容的映射待正式設計               |
| 來源與授權   | 每項字型、插畫、材質、音效等有來源、版本、license／NOTICE、商用與散布依據；自有／委託權利範圍可追溯                                 |
| 商品說明     | 展示實際版本與內容，不把 prototype、研究模型、估計同步或尚未提供的 slot 當成交付內容                                                |

## 品質驗收標準

以下是日後每個 set 都要保存結果的驗收清單，目前沒有任何模板因本文件而被認定通過。
實際測試案例、可接受效能預算與支援矩陣，在進入製作時固定；本輪不虛構已達成的數值。

| 面向           | 至少涵蓋的情境                                                                 | 通過原則                                                                         |
| -------------- | ------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- |
| 排版／內容     | 短句、長句、多行、中文／日文／韓文／拉丁字、標點與缺字；其餘 script 依宣告範圍 | 在支援範圍內不裁掉關鍵資訊、不讓控制或裝飾遮字；未支援範圍清楚標示並有 fallback  |
| 狀態           | 空資料、缺封面／讀音／時間資料、載入、暫停、seek、換曲、結束與重連             | 可辨識且不殘留上一首的私有／過期資訊；跟隨既有播放器與 projection 權威           |
| 歌詞同步       | T0／T1／可信 T2，以及 seek 後恢復、間奏與段落交接                              | 缺精確資料時有明確回退；不將估算動畫宣稱為精確逐字，不新增模型授權需求來完成外觀 |
| 視覺／可及性   | 淺／深／複雜背景、透明 alpha、字體載入失敗、對比與 reduced motion              | 支援情境可讀；無字型時仍可用，不因付費主題略過強制可及性／效能限制               |
| OBS 與生命週期 | 明列的 Windows／OBS／Browser Source 組合、重載、離線與 App 重啟                | 真實可見的 OBS 模式驗收，保留版本與結果；內部預覽或截圖不能獨自代替輸出驗收      |
| 效能           | 初次載入、冷啟動、長時間播放、換曲與內容壓力                                   | 有可重現測量與事前預算，不以「付費版」宣稱未測量的更低延遲或穩定性               |
| 隔離與回復     | 不相容／缺損 pack、壞資產、更新失敗與取消                                      | 保留已驗證版本及 default fallback；不阻斷免費播放，不在演出中無預警切換作品版本  |
| 交付／附文     | 來源、hash、大小、license／NOTICE、描述與實際資產逐項一致                      | 沒有未核清的代用圖／字型／片段；不能只有一個籠統 license 名稱                    |

## 更新與使用權標準

買 A set 就取得 A，不自動取得後來獨立發布的 B。A 的修復、已承諾內容與必要 fallback 不另作付費解鎖。
同風格擴充是否屬 A，依原先明列範圍判斷；不能先宣稱完整套裝，之後把補齊內容改稱 B。
修改可調參數與保存本機偏好，不改變上游資產授權，也不等於可對外再散布原包或衍生完整素材。

已取得作品以長期使用、離線可用、重裝後可復原為設計要求；復原與身份方式尚未決定，不在此要求社群帳號或常駐連線。
下架停止新的取得，不自動撤銷既有權利；合法退款撤銷、權利瑕疵等例外須另訂明確處理，不能口頭保證任何情況都永不撤銷。
允許的直播／錄影／VOD、裝置／創作者使用範圍、轉讓／贈送與退款條款需在收款前明定；不能照抄 Discord 的平台帳號或點數政策。

## 實作階段與依賴順序

2026-10-20／21 的 F1–F5 共用基礎工作已收尾：F1 建立情境與設定基線，F2 整理 host 生命週期，F3 統一預覽資料，F4 建立 capture／來源工具，F5 完成本機整合與短測。各階段結果、來源 hashes、歷史失敗及未測範圍統一見[驗收紀錄](../operations/output-appearance-acceptance.md)。這是歷史交付，不再列為下一輪 F3 計畫。

後續依 ADR 0027 的 P4→P5→P6 分別處理畫布選取、配置操作與 Styles；個別模板的藝術改善各自驗收。相容性與功能 gate、作品取得權利分開；若新外觀需要 renderer 能力，先由 App 更新交付通用能力，再提供相容作品。Pack 不交付任意 HTML／CSS／JavaScript、shader source、外部 URL 或安裝 hook。

## 尚待完成與下一步

- W3 僅在當時使用者環境確認 Queue Board、Karaoke Stack、Art Card 的只讀視窗擷取短測；詳細通過／未驗界線見[W3 收尾](../operations/output-appearance-acceptance.md#w3-收尾紀錄2026-10-21)。這不涵蓋其他模板、Browser Source alpha、跨環境或耐久。
- 安裝版 smoke、大曲庫／慢磁碟、完整演出耐久及 GPU VRAM／utilization／FPS 仍缺代表性證據；本機短測不推論整場可靠性。
- 各模板仍需藝術與可讀性驗收、逐項素材權利及真實縮圖來源紀錄；10-20 原盤點的四張 reference 缺口須依實際替換版本重新核對。
- 付款、帳號、entitlement、復原與遠端 pack 的獨立實作範圍另行確定；不因共用基礎完成就自動開始。依賴版本與適用條件查[依賴盤點](community-dependency-boundaries-2026-10-20.md)，市場選項查[研究](../research/product/appearance-support-models-market-plan-2026-10-20.md)，早期分層提案見[歷史](../archive/community-feature-tiers-plan-2026-10-20.md)。
