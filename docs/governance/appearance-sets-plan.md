階段順序為 F1 → F2 → F3 → F4 → F5，每階段均應可獨立審查及回復。F1–F4 已建立並驗證；F5 本機結果見下節，不因工具可產圖而勾選作品／OBS／完整耐久驗收。

## Set 的身份與範圍標準

商業上的一個 set 是對外宣告的作品範圍，不必等於一個技術壓縮包或單一模板。
沿用 [ADR 0011](../adr/0011-overlay-instances-and-presentation-pack-delivery.md)與 [Overlay Pack Contract](../contracts/overlay-pack.md)的 Template、Official Style Set、Presentation Pack 與版本分工，不另造競爭的 runtime 模型。

| 項目         | 未來必須明定的標準                                                                                                                  |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| 身份         | 穩定的作品身份、名稱、作者、簡介與內容清單；改名不讓已擁有者變成未擁有，不藉改 ID 再收修復費                                        |
| 範圍         | 明列適用 Lyrics／Setlist／Now Playing 哪些用途。單一用途作品可以成立，不強制每個 set 都涵蓋三種；宣稱完整套裝時才須交付所列完整範圍 |
| 風格         | 定義文字、色彩、材質、構圖與動態語言；不是把同一版型的每個色號拆成作品                                                              |
| 可調整性     | 明列可調項與保留的設計規則；基本字級、配色／位置、同步修正、可讀性與 reduced motion 仍屬免費能力                                    |
| 能力與相容性 | 明列依賴的 app-owned template／capabilities、最低 App／契約版本與已驗證輸出尺寸；不以購買權利覆蓋依賴缺失或功能 gate                |
| 版本         | 作品使用權、packVersion、styleSetId、模板能力與 App 版本分開；實際欄位沿既有 contract，商業身份對內容的映射待正式設計               |
| 來源與授權   | 每項字型、插畫、材質、音效等有來源、版本、license／NOTICE、商用與散布依據；自有／委託權利範圍可追溯                                 |
| 商品說明     | 展示實際版本與內容，不把 prototype、研究模型、估計同步或尚未提供的 slot 當成交付內容                                                |

## 更新與使用權標準

買 A set 就取得 A，不自動取得後來獨立發布的 B。A 的修復、已承諾內容與必要 fallback 不另作付費解鎖。
同風格擴充是否屬 A，依原先明列範圍判斷；不能先宣稱完整套裝，之後把補齊內容改稱 B。
修改可調參數與保存本機偏好，不改變上游資產授權，也不等於可對外再散布原包或衍生完整素材。

已取得作品以長期使用、離線可用、重裝後可復原為設計要求；復原與身份方式尚未決定，不在此要求社群帳號或常駐連線。
下架停止新的取得，不自動撤銷既有權利；合法退款撤銷、權利瑕疵等例外須另訂明確處理，不能口頭保證任何情況都永不撤銷。
允許的直播／錄影／VOD、裝置／創作者使用範圍、轉讓／贈送與退款條款需在收款前明定；不能照抄 Discord 的平台帳號或點數政策。

## 技術邊界與準備順序

App-owned template 提供可執行排版與動態；Presentation Pack 仍是經驗證的宣告式外觀與資產，不能含任意 HTML／CSS／JavaScript、shader source、外部 URL 或安裝 hook。
若外觀需要全新 renderer 能力，先以免費 App 更新交付通用能力與契約，再提供對應自有 set；不透過付費 pack 偷渡可執行程式。
ownership 決定能否選用該作品；既有 feature gate 決定是否啟用該流程；依賴／相容性決定是否能執行。三者分開，不用點數餘額控制演出。

以下先完成共用基礎，才另案改善 default 與代表性 set。樣本或基礎階段通過不等於作品可售；不規定新品數量、售價或月更。
