| 模板／字型容量             | 有效列隱藏已修，不等於預告次列長句容量全部修復。先前 960×540 次列裁切、不同字型與尺寸尚未全面接受；其他 Output 模板與 Self-View 不因本輪而自動取得相同細進度。                |

| 冷啟與歷史慢值             | Focus 冷啟 raster／shader 長尾未解；歷史 Local warm 200.473ms 等無同次 trace 的慢值仍保留。後續未重現不等於已解決，不宣稱兩端所有首字／p95／max 都改善。                      |
| 人工與正式模式驗收         | 原錄音歌聲進出、弱尾音、和聲、短換氣、正式 profile、非零 displayDelay 及 OBS／物理呈現尚未完整接受。靜音 monitor 或代理時鐘測試不能代替聽辨真值。                             |

## 排除與提交前程序

其他演出安排／播放佇列／曲目操作／一般 UI、獨立 Output 工作區 ADR、offset 研究及離線 Qwen 文字實驗維持原狀。後者即使名稱含 lyrics，也另案保留，不接進這四組。相對地，`electron/lib/lyricsResearch/` 的既有聲學產品任務隔離屬 B，不能只因路徑含 Research 就全部排除。

`tasks/`、raw traces、失敗原型、使用者 profile／歌詞／音訊／sidecar、模型資產都不提交；公開 JSON 只包含去識別統計或本 repo 路徑。不得用 `git add .`。

本輪依核准順序建立精確隔離快照，先驗中間依賴，再將明確路徑及功能差分寫入 index。逐組 review、staged／committed bytes 核對及 Git hooks 均保留；hooks 在隔離快照運作，避免改寫原混合工作樹。遇驗證環境或 hook 備份失敗時保留收據、修正環境後才接續，沒有放寬產品斷言或帶入下一組。GPU 不追加性能實驗，未 push。
