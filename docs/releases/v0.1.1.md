# Utawakui v0.1.1 公開測試版

這是 Utawakui 的公開測試版本，提供 Windows 64 位元電腦使用。此版本著重於本機
曲庫、播放、歌詞輔助、音訊處理及 OBS 畫面輸出的整體操作。

## 本次調整

- 改善歌詞操作、人聲分離進度與結果狀態。
- 改善 OBS 畫面輸出及演出者歌詞視窗的呈現。
- 強化進階來源工具的準備、檢查與修復流程。
- 修正導唱混音與升降調切換時的音訊處理。

## 安裝前須知

- 此測試版本 **尚未加上受信任的 Windows 數位簽章**，安裝時可能顯示「未知的發行者」。
- 請 **只從** [Utawakui 官方 Releases](https://github.com/yPinn/Utawakui-Releases/releases)
  下載，並可使用隨附的 `SHA256SUMS.txt` 核對檔案。
- 目前採 **手動安裝與更新**；軟體內自動更新尚未啟用。
- 一般覆蓋安裝會 **保留** 應用程式設定與自選曲庫。重要的自備素材仍建議自行備份。
- 使用者 **須自行確認** 歌曲、歌詞、封面、錄音及其他素材的使用權利。

## Utawakui v0.1.1 Public Test

This public test build is available for 64-bit Windows. It focuses on the
overall local-library, playback, lyrics, audio-processing, and OBS output
experience.

## Changes

- Improved lyrics controls and vocal-separation progress and result states.
- Refined OBS output and the performer lyrics window.
- Strengthened preparation, validation, and repair for advanced source tools.
- Fixed guide-vocal mixing and audio routing during pitch changes.

## Before Installing

- This test build **does not yet have a trusted Windows digital signature**, so
  Windows may show “Unknown publisher”.
- Download **only** from the
  [official Utawakui Releases](https://github.com/yPinn/Utawakui-Releases/releases)
  and use `SHA256SUMS.txt` to verify the file when needed.
- Installation and updates are currently **manual**. In-app automatic updates are
  disabled.
- A normal installation over an earlier version **preserves** app settings and the
  selected library. Important user-provided media should still be backed up.
- Users **remain responsible** for the rights to songs, lyrics, artwork,
  recordings, and other materials they use.
