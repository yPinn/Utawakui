# Utawakui v0.1.2 公開測試版

這是 Utawakui 的 Windows 64 位元公開測試版本。本次更新帶來更多卡拉 OK
歌詞畫面、較順手的歌詞整理、更好的分離品質，以及更穩定的啟動與畫面輸出。

## 新功能

- 新增 Live Stage、Manga Frame 與 Classic KTV 等 OBS 歌詞版型，提供版型選擇與
  預覽、歌詞進度效果、雙行歌詞輪替及進歌提示。
- 應用程式現在可以檢查後續版本，並引導使用者完成下載與安裝。

## 改善

- 讓線上歌詞搜尋與儲存更可靠，歌詞時間也更容易校正。
- 提升一般人聲分離的品質；需要額外下載的音訊功能在準備或修復時，也會提供更清楚的
  狀態與提示。
- 改善 OBS 畫面輸出的切換與重新整理、播放時的音訊處理、啟動穩定性，以及功能啟用
  與錯誤提示。

## 問題修復

- 修正全假名日文歌詞可能不顯示羅馬字、歌詞換行可能遺失，以及 OBS 預覽在切換版面
  或更新素材後未即時刷新的問題。

## 升級注意事項

- 由 v0.1.1 升級到本版仍須手動下載並安裝一次。完成後，後續版本才能透過應用程式
  進行更新。

## 已知限制

- 此測試版本尚未加上受信任的 Windows 數位簽章，安裝時可能顯示「未知的發行者」。

## 安裝前須知

- 請只從 [Utawakui 官方 Releases](https://github.com/yPinn/Utawakui-Releases/releases)
  下載。下載頁隨附的 `SHA256SUMS.txt` 可用來確認安裝檔是否完整。
- 應用程式可能在啟動後檢查是否有新版本，但不會自行下載或安裝；這些步驟仍由使用者
  決定。
- 一般覆蓋安裝會保留應用程式設定與自選曲庫；重要的自備素材仍建議自行備份。
- 使用者須自行確認歌曲、歌詞、封面、錄音及其他素材的使用權利。

## Utawakui v0.1.2 Public Test

This public test build is available for 64-bit Windows. It adds more karaoke
looks, makes lyrics easier to manage, improves separation quality, and makes
startup and OBS output more reliable.

## New Features

- Added Live Stage, Manga Frame, and Classic KTV lyric looks for OBS, with template
  selection and previews, timed lyric progress, two-line handoffs, and entrance
  cues.
- The app can now check for later releases and guide users through downloading and
  installing them.

## Improvements

- Made online lyric search and saving more dependable, and made lyric timing easier
  to adjust.
- Improved regular vocal-separation quality and added clearer setup and repair
  guidance when extra audio features are needed.
- Made OBS output switching and refreshing, playback audio handling, startup, and
  recovery messages more reliable.

## Bug Fixes

- Fixed missing romaji for all-kana Japanese lyrics, lost lyric line breaks, and
  OBS previews that did not refresh after layout or media changes.

## Upgrade Notes

- Upgrading from v0.1.1 still requires one manual download and installation. Later
  releases can then be updated through the app.

## Known Limitations

- This test build does not yet have a trusted Windows digital signature, so
  Windows may show “Unknown publisher”.

## Before Installing

- Download only from the
  [official Utawakui Releases](https://github.com/yPinn/Utawakui-Releases/releases)
  page. The included `SHA256SUMS.txt` can be used to confirm that the installer is
  complete.
- The app may check for a newer version after startup, but it will not download or
  install one without the user's action.
- A normal installation over an earlier version preserves app settings and the
  selected library. Important user-provided media should still be backed up.
- Users remain responsible for the rights to songs, lyrics, artwork, recordings,
  and other materials they use.
