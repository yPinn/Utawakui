# Utawakui v0.2.0 公開測試版

這是 Utawakui 的 Windows 64 位元公開測試版本。本次更新新增多個線上歌詞來源、
中文歌詞的繁體顯示、匯入後自動偵測 BPM 與節拍、更貼近正式錄音的匯入結果，
並讓應用程式內的更新流程更完整。

## 新功能

- 線上歌詞新增多個來源，搜尋時會一併查詢，同一首歌也可以切換不同來源
  （部分來源仍為實驗性）。
- 歌詞為中文時，可切換為「繁體中文」顯示（預設開啟），也能隨時切回「原文」。
- 匯入歌曲後可自動偵測 BPM 與節拍，開關位於設定（預設開啟）；下載與匯入不會
  等待分析，分析失敗也不會影響歌曲。
- 從網路匯入時，候選結果會以歌曲版本優先，並依與正式錄音的接近程度排序；
  也可以直接輸入文字搜尋。
- 應用程式會在啟動後與之後每隔數小時檢查是否有新版本（可在設定關閉自動檢查）；
  下載更新時會顯示速度與剩餘時間，有新版本時「設定」頁會出現提醒標記。
- 日文假名讀音現在也會顯示在 OBS 的「漫畫對白」歌詞版型。

## 改善

- OBS 畫面輸出：「星染黑膠」與「封面播放卡」等版型移至「播放中」之下，版面切換
  與動畫呈現一併更新。
- 只有在來源資料完整且通過驗證時，歌詞才會標示為逐字同步。
- 線上歌詞的搜尋、儲存與刪除更可靠。
- 改善升降調切換時的音訊輸出、啟動穩定性，以及畫面輸出的重新整理。

## 問題修復

- 修正 OBS 預覽在切換版面或更換素材後可能沒有即時重新整理、歌詞掃動效果顯示
  不穩，以及線上歌詞在查無結果時誤判為錯誤的問題。

## 升級注意事項

- **重要變更**：OBS 中結尾為 `/overlay/artwork` 的獨立畫面來源網址已移除。如果你
  先前在 OBS 加入過這個來源，更新後它會失效，請改用「播放中」版型（「星染黑膠」
  與「封面播放卡」都在其中）並重新設定來源網址。固定畫面來源由四個減為三個：
  歌單、歌詞、播放中。
- 由 v0.1.1 升級到本版仍須手動下載並安裝一次；v0.1.2 之後可透過應用程式更新。

## 已知限制

- 此測試版本尚未加上受信任的 Windows 數位簽章，安裝時可能顯示「未知的發行者」。
- 部分線上歌詞來源仍為實驗性，可能不穩定。
- 匯入後自動偵測 BPM 與節拍仍在持續驗證離線環境、儲存空間與失敗復原的表現。

## 安裝前須知

- 請 **只從** [Utawakui 官方 Releases](https://github.com/yPinn/Utawakui-Releases/releases)
  下載。下載頁隨附的 `SHA256SUMS.txt` 可用來確認安裝檔是否完整。
- 應用程式會在啟動一段時間後、以及之後每隔數小時 **檢查** 是否有新版本，但 **不會
  自行下載或安裝**；這些步驟仍由使用者決定，也可以在設定中關閉自動檢查。
- 一般覆蓋安裝會 **保留** 應用程式設定與自選曲庫；重要的自備素材仍建議自行備份。
- 使用者 **須自行確認** 歌曲、歌詞、封面、錄音及其他素材的使用權利。

## Utawakui v0.2.0 Public Test

This public test build is available for 64-bit Windows. It adds several online
lyric sources, a Traditional Chinese lyric display, automatic BPM and beat
detection after import, import results that better match a release recording,
and a more complete in-app update flow.

## New Features

- Online lyric search adds several sources, queried together, with the option
  to switch sources for the same song (some sources are still experimental).
- Chinese lyrics can be switched to a Traditional Chinese display (on by
  default) and back to the original text at any time.
- Imported songs can be checked for BPM and beats automatically, with the
  toggle in Settings (on by default); downloads and imports do not wait for the
  analysis, and a failed analysis does not affect the song.
- When importing from the web, candidates favour song versions and are ordered
  by how closely they match a release recording; plain-text search also works.
- The app checks for a newer version after startup and every few hours after
  that (automatic checks can be turned off in Settings); the update download
  shows speed and remaining time, and the Settings tab shows a marker when an
  update is available.
- Japanese kana readings now also appear in the OBS manga-dialogue lyric look.

## Improvements

- OBS output: the vinyl and cover-card looks move under the Now Playing source,
  with updated layout switching and motion.
- Lyrics are marked as word-synced only when the source data is complete and
  passes validation.
- Online lyric search, saving, and deletion are more dependable.
- Audio output on pitch changes, startup stability, and output refresh are more
  reliable.

## Bug Fixes

- Fixed OBS previews that could fail to refresh after a layout or media change,
  an unstable lyric sweep effect, and online lyric search treating no results
  as an error.

## Upgrade Notes

- **Important change**: the standalone OBS browser-source URL ending in
  `/overlay/artwork` has been removed. If you added that source in OBS, it will
  stop working after updating — use the Now Playing source instead (the vinyl
  and cover-card looks are both there) and set the source URL again. The fixed
  browser sources go from four to three: Setlist, Lyrics, Now Playing.
- Upgrading from v0.1.1 **still requires one manual download and installation**;
  later releases can be updated through the app.

## Known Limitations

- This test build **does not yet have a trusted Windows digital signature**, so
  Windows may show "Unknown publisher".
- Some online lyric sources are still experimental and may be unreliable.
- Automatic BPM and beat detection after import is still being validated for
  offline use, storage footprint, and failure recovery.

## Before Installing

- Download **only** from the
  [official Utawakui Releases](https://github.com/yPinn/Utawakui-Releases/releases)
  page. The included `SHA256SUMS.txt` can be used to confirm that the installer
  is complete.
- The app **checks** for a newer version a short time after startup and every
  few hours after that, but it **will not download or install** one without the
  user's action, and automatic checks can be turned off in Settings.
- A normal installation over an earlier version **preserves** app settings and
  the selected library. Important user-provided media should still be backed up.
- Users **remain responsible** for the rights to songs, lyrics, artwork,
  recordings, and other materials they use.
