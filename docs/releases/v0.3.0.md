# Utawakui v0.3.0 公開測試版

本次更新加入使用者回饋、歌詞自動取得、歌詞自動跟隨與 GPU 人聲分離加速，並擴充 OBS 歌詞版型和歌單呈現。

## 新功能

- **回饋與建議：**可以從設定送出錯誤回報、功能請求、使用體驗意見或內容問題。送出前會先顯示完整預覽；只有錯誤回報可選擇附上最近的錯誤紀錄。若網路送出失敗，也能另存為 JSON 檔案。
- **歌詞自動取得：**曲目缺少歌詞時，應用程式會在背景尋找與曲目資訊精確相符的歌詞並保存，不會中斷匯入或播放。需要人工判斷的結果仍會留在原本的搜尋流程。
- **跟隨目前歌詞：**播放時可以讓歌詞工作區自動保持目前行可見；關閉後即可自由瀏覽。
- **GPU 人聲分離：**Windows 上的 `quick`／`general` 分離預設會嘗試使用相容 GPU。若 GPU 無法使用，會自動改用 CPU；也可以在設定中關閉 GPU 加速。
- **OBS 歌詞版型：**新增「霓彩跳字」與「華綴直書」。前者提供逐字跳入的流行字卡，後者提供適合日文內容的明朝體直書呈現。
- **實驗性 Spout2 輸出：**Windows x64 的 Output 設定新增 Spout2 歌詞輸出，供相容的本機軟體接收透明歌詞。OBS Browser Source 仍可獨立使用，也是目前建議的穩定輸出方式。
- **版本重點：**更新後會顯示一次本版摘要；之後可隨時從設定重新開啟，不需要連線下載。

## 改善

- **外觀設定更精簡：**選擇 OBS 歌詞版型後，只會看到該版型可用的配色、字體、可讀性、背景與版面選項；變更會自動儲存。
- **歌詞時間更一致：**版型會更一致地使用來源提供的逐行或逐字時間，並改善長句、多語內容與不同顯示方式之間的切換。
- **OBS 歌單更易辨識：**目前歌曲和已唱紀錄有更清楚的區隔；只有內容超出可用高度時才會開始平順捲動。
- **錯誤紀錄更完整：**曲庫、播放清單、歌詞、匯入與音訊處理涵蓋更多錯誤情況。診斷資料只會在使用者選擇時匯出或附在錯誤回報中。

## 問題修復

- 修正 Better Lyrics 查無結果時可能誤顯為錯誤的問題。
- 修正曲目刪除或重建時，舊的歌詞讀音工作可能套用到錯誤曲目的問題。
- 修正部分 OBS 歌詞共用模組無法載入，以及部分版型未正確對齊不同來源歌詞時間的問題。
- 修正回饋表單說明與所選類別不符，以及通知視窗尺寸不合適的問題。

## 已知限制

- 此公開測試版尚未加入受信任的 Windows 數位簽章，因此安裝時可能顯示「未知的發行者」。
- 部分線上歌詞來源仍為實驗性，可能暫時找不到結果。需要人工判斷的來源不會在背景自動保存。
- Spout2 輸出尚未完成所有接收軟體、多 GPU、顯示裝置重設與透明邊緣合成的相容性驗收。需要穩定輸出時，請使用 OBS Browser Source。

## 安裝前須知

- 請**只從** [Utawakui 官方 Releases](https://github.com/yPinn/Utawakui-Releases/releases) 下載。可使用下載頁提供的 `SHA256SUMS.txt` 確認安裝檔是否完整。
- 應用程式會在啟動後及之後每隔數小時**檢查**新版本，但**不會自行下載或安裝**。你可以在設定中關閉自動檢查。
- 覆蓋安裝通常會**保留**應用程式設定與自選曲庫；重要的自備素材仍建議先備份。
- 使用者**須自行確認**歌曲、歌詞、封面、錄音與其他素材的使用權利。

## Utawakui v0.3.0 Public Test

This update adds user feedback, automatic lyric acquisition, current-line following, and GPU-accelerated vocal separation, while expanding OBS lyric looks and setlist presentation.

## New Features

- **Feedback and suggestions:** Send bug reports, feature requests, experience feedback, or content issues from Settings. A full preview appears before anything is sent; only bug reports can optionally include recent error records. If network delivery fails, the report can be saved as a JSON file.
- **Automatic lyric acquisition:** When a track has no lyrics, the app looks in the background for lyrics that exactly match the track information and saves them without interrupting import or playback. Results that need human judgement remain in the existing search flow.
- **Follow the current lyric:** Keep the active line visible during playback, or turn the option off to browse freely.
- **GPU-accelerated vocal separation:** On Windows, `quick` and `general` separation try a compatible GPU by default. If GPU acceleration is unavailable, the app automatically uses the CPU instead. GPU acceleration can also be turned off in Settings.
- **OBS lyric looks:** Added Kinetic Pop and Ornate Vertical. Kinetic Pop provides animated pop lettering, while Ornate Vertical provides Mincho-style vertical presentation for Japanese lyrics.
- **Experimental Spout2 output:** Output settings on Windows x64 now provide Spout2 lyrics output for compatible local receivers. OBS Browser Source remains independently available and is still the recommended stable output path.
- **Release highlights:** The app shows this summary once after an update. It can be reopened from Settings at any time and does not need to be downloaded.

## Improvements

- **Simpler appearance settings:** After selecting an OBS lyric look, only its supported palette, typography, readability, background, and layout options are shown. Changes save automatically.
- **More consistent lyric timing:** Lyric looks use source-provided line and word timing more consistently, with better handling of long lines, multilingual content, and presentation changes.
- **Clearer OBS setlists:** The current song is easier to distinguish from completed history. Smooth scrolling starts only when the content exceeds the available height.
- **More complete error records:** More library, playlist, lyric, import, and audio-processing failures are covered. Diagnostic data is exported or attached only when the user chooses to do so.

## Bug Fixes

- Fixed Better Lyrics misses sometimes appearing as errors.
- Prevented stale lyric-reading work from being applied to the wrong track after a track was deleted or rebuilt.
- Fixed shared OBS lyric modules that could fail to load and source timing that could become misaligned in some lyric looks.
- Fixed feedback guidance that did not match the selected category and notification windows that used an unsuitable size.

## Known Limitations

- This public test build does not yet have a trusted Windows digital signature, so Windows may show “Unknown publisher”.
- Some online lyric sources remain experimental and may temporarily return no result. Sources that require human judgement are not saved automatically in the background.
- Spout2 output has not completed compatibility acceptance across every receiver, multi-GPU setup, display-device reset, or transparent-edge composition. Use OBS Browser Source when stable output is required.

## Before Installing

- Download **only** from the [official Utawakui Releases](https://github.com/yPinn/Utawakui-Releases/releases) page. Use the included `SHA256SUMS.txt` to confirm that the installer is complete.
- The app **checks** for a newer version after startup and every few hours, but it **will not download or install** an update on its own. Automatic checks can be turned off in Settings.
- Installing over an earlier version normally **preserves** app settings and the selected library. Important user-provided media should still be backed up first.
- Users **remain responsible** for the rights to songs, lyrics, artwork, recordings, and other materials they use.
