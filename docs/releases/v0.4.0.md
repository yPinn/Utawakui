# Utawakui v0.4.0 公開測試版

本次更新加入唯讀 OBS 直播狀態與場次時間標記、可發聲節拍器和 Windows 背景執行，並改善變調音質、資源顯示、更新檢查與設定操作。

## 新功能

- **OBS 直播狀態與場次時間標記：** 在設定中連接 OBS 後，可以查看直播或錄影是否進行中，以及已經過多久。Utawakui 會在曲目切換或手動加入標記時，將時間保存在這台電腦；之後可匯出為 YouTube 章節文字。這項連線只讀取狀態，不會切換場景或修改來源。
- **可發聲的節拍器：** 演出工具新增有第一拍重音的節拍器。曲目已有可靠的 BPM 分析時會自動套用；手動設定速度後，切換歌曲也不會覆蓋，直到重設節拍器。
- **Windows 背景執行：** 按下關閉按鈕時，可以選擇留在系統匣、結束程式或取消，並可記住選擇。留在背景時，播放、OBS 連線與輸出會繼續；你可以從系統匣重新開啟 Utawakui 或結束程式。
- **應用程式資源顯示：** 標題列會顯示 Utawakui 使用的 CPU 與記憶體，不再把整台電腦的用量算進來。處理音訊時，相關工具的用量也會計入。

## 改善

- **更自然的即時變調：** 播放預覽改用新的高品質變調處理，在不改變播放速度時提供更穩定的聲音。
- **更可靠的 OBS 連線：** 連線或讀取狀態逾時時，Utawakui 會停止舊連線再重試，不會讓較早的結果蓋過目前狀態。連線資料會在儲存前檢查，已保存的密碼也能在設定中移除。
- **更容易找到設定：** 設定頁重新整理了分區和操作層級，背景執行、更新、版本公告、社群連結與診斷功能更容易找到。

## 問題修復

- 修正檢查更新可能一直停在「檢查中」，以及下載選用功能所需檔案時可能無限等待的問題。
- 修正多個對話框同時開啟時，按 Escape 可能一次關閉多個對話框的問題。

## 升級注意事項

- 從舊版本升級後，第一次按下視窗關閉按鈕會詢問要背景執行、完全結束或取消。勾選「記住我的選擇」後不再詢問；也可隨時從設定改回每次詢問。最小化按鈕仍會正常縮到工作列。
- OBS 整合維持預設關閉。啟用時需要 OBS WebSocket 5 的連線資料；密碼只保存在這台電腦的作業系統加密儲存區。

## 已知限制

- 此公開測試版尚未加入受信任的 Windows 數位簽章，因此安裝時可能顯示「未知的發行者」。
- OBS 整合目前只讀取狀態與時間，不會切換場景、修改來源或遠端控制播放。
- Spout2 歌詞輸出仍是實驗性功能，尚未完整驗證所有接收軟體、多 GPU 和顯示器重新連線情境。若需要穩定輸出，請使用 OBS Browser Source。

## 安裝前須知

- 請 **只從** [Utawakui 官方 Releases](https://github.com/yPinn/Utawakui-Releases/releases) 下載。可使用下載頁提供的 `SHA256SUMS.txt` 確認安裝檔是否完整。
- 應用程式會在啟動後及之後每隔數小時 **檢查** 新版本，但 **不會自行下載或安裝**。你可以在設定中關閉自動檢查。
- 覆蓋安裝通常會 **保留** 應用程式設定與自選曲庫；重要的自備素材仍建議先備份。
- 使用者 **須自行確認** 歌曲、歌詞、封面、錄音與其他素材的使用權利。
- 加入 [Discord](https://discord.gg/yJKddEtpNt) 社群，查看公告或回饋想法。

## Utawakui v0.4.0 Public Test

This update adds read-only OBS live status and session time markers, an audible metronome, and Windows background operation. It also improves pitch quality, resource reporting, update checks, and Settings navigation.

## New Features

- **OBS live status and session time markers:** After connecting OBS in Settings, you can see whether streaming or recording is active and how long it has been running. Utawakui saves a time marker when the track changes or when you add one manually; you can then export the session as YouTube chapter text. The connection is read-only and cannot change scenes or sources.
- **Audible metronome:** Performance Tools now includes a metronome with an accented first beat. A reliable analyzed track BPM is applied automatically. Once you set the tempo manually, changing tracks will not overwrite it until you reset the metronome.
- **Windows background operation:** The close button can now send the app to the system tray, exit, or cancel, with an option to remember your choice. Playback, the OBS connection, and output continue in the background. You can reopen or exit Utawakui from the tray.
- **App resource reporting:** The title bar now shows the CPU and memory used by Utawakui instead of the whole computer. Related audio tools are included while they are running.

## Improvements

- **More natural live pitch changes:** Playback preview now uses higher-quality pitch processing for more stable sound when pitch changes without changing playback speed.
- **More reliable OBS connections:** If a connection or status check times out, the app stops the old connection before retrying, so an earlier result cannot replace the current state. Connection details are checked before saving, and a stored password can be removed in Settings.
- **Easier-to-scan Settings:** Settings now groups related actions more clearly, making background behavior, updates, release announcements, community links, and diagnostics easier to find.

## Bug Fixes

- Prevented update checks from remaining in “Checking” indefinitely and downloads for optional features from waiting forever.
- Fixed Escape closing more than one dialog when multiple dialogs are open.

## Upgrade Notes

- After upgrading, the first press of the window close button asks whether to run in the background, exit completely, or cancel. Selecting “Remember my choice” skips later prompts; Settings can restore the ask-every-time behavior. The minimize button continues to use the taskbar normally.
- The OBS integration remains off by default. Enabling it requires OBS WebSocket 5 connection details; its password is stored only in this computer's operating-system-backed encrypted storage.

## Known Limitations

- This public test build does not yet have a trusted Windows digital signature, so Windows may show “Unknown publisher”.
- The OBS integration currently reads status and time only. It does not switch scenes, modify sources, or remotely control playback.
- Spout2 lyric output remains experimental and has not been fully tested with every receiver, multi-GPU setup, or display reconnection. Use OBS Browser Source when stable output is required.

## Before Installing

- Download **only** from the [official Utawakui Releases](https://github.com/yPinn/Utawakui-Releases/releases) page. Use the included `SHA256SUMS.txt` to confirm that the installer is complete.
- The app **checks** for a newer version after startup and every few hours, but it **will not download or install** an update on its own. Automatic checks can be turned off in Settings.
- Installing over an earlier version normally **preserves** app settings and the selected library. Important user-provided media should still be backed up first.
- Users **remain responsible** for the rights to songs, lyrics, artwork, recordings, and other materials they use.
- Join the [Discord](https://discord.gg/yJKddEtpNt) community for announcements and feedback.
