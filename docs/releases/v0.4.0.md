# Utawakui v0.4.0 公開測試版

本次更新加入唯讀 OBS 直播狀態與章節紀錄、節拍器及 Windows 背景執行，並改善變調音質、資源顯示、更新檢查與設定可靠性。

## 新功能

- **OBS 直播與錄影紀錄：** 啟用 OBS 整合並連線 OBS WebSocket 5 後，可以查看直播／錄影狀態與經過時間。曲目切換和手動標記會保存在本機 session history，並可匯出 YouTube 章節文字。這項整合只讀取狀態，不會變更場景或來源。
- **可發聲的節拍器：** 演出工具新增有重音第一拍的節拍器。曲目已有可信的 BPM 分析時可自動套用；手動調整後會保留使用者選擇。
- **Windows 背景執行：** 按下關閉按鈕時，可以選擇留在系統匣、完全結束或取消，也能記住選擇。背景執行會保留播放、OBS 連線與 Output；系統匣可重新開啟主視窗或直接進入設定。
- **應用程式資源顯示：** 標題列會顯示 Utawakui 自身的 CPU 與記憶體使用量；執行音訊處理時也會納入 App 啟動的工作程序。

## 改善

- **更自然的即時變調：** 播放預覽改用新的高品質變調處理，在不改變播放速度時提供更穩定的聲音。
- **更可靠的 OBS 連線：** 連線、狀態讀取與重試都有明確期限；重新設定或中斷後，舊連線結果不會覆蓋目前狀態。Host、port、略過門檻與密碼會在儲存前檢查，已保存的密碼也能在設定中明確移除。
- **更清楚的媒體庫操作：** Context Inspector 可以調整寬度，側欄、內容區與 inspector 的間距和對齊也更一致。

## 問題修復

- 修正部分開發或執行環境中，設定頁可能因共用驗證模組格式而無法顯示的問題。
- 修正檢查更新可能長時間停在「檢查中」，以及可選依賴下載在沒有資料傳輸時可能無限等待的問題。
- 修正標題列資源數字可能反映整台電腦、而不是 Utawakui 自身使用量的問題。
- 修正 OBS 重新設定、斷線或較慢的舊請求可能覆蓋較新狀態，以及安全儲存失敗時仍可能顯示為已保存的問題。
- 修正多個對話框重疊時，Escape 可能同時關閉不只一個對話框的問題。

## 升級注意事項

- 從舊版本升級後，第一次按下視窗關閉按鈕會詢問要背景執行、完全結束或取消。勾選「記住我的選擇」後不再詢問；也可隨時從設定改回每次詢問。最小化按鈕仍會正常縮到工作列。
- OBS 整合維持預設關閉。啟用時需要 OBS WebSocket 5 的連線資料；密碼只保存在這台電腦的作業系統加密儲存區。

## 已知限制

- 此公開測試版尚未加入受信任的 Windows 數位簽章，因此安裝時可能顯示「未知的發行者」。
- OBS 整合目前只讀取狀態與時間，不會切換場景、修改來源或遠端控制播放。
- Spout2 歌詞輸出仍屬實驗性，尚未完成所有接收軟體、多 GPU、顯示裝置重設與透明邊緣合成的相容性驗收。需要穩定輸出時，請使用 OBS Browser Source。

## 安裝前須知

- 請 **只從** [Utawakui 官方 Releases](https://github.com/yPinn/Utawakui-Releases/releases) 下載。可使用下載頁提供的 `SHA256SUMS.txt` 確認安裝檔是否完整。
- 應用程式會在啟動後及之後每隔數小時 **檢查** 新版本，但 **不會自行下載或安裝**。你可以在設定中關閉自動檢查。
- 覆蓋安裝通常會 **保留** 應用程式設定與自選曲庫；重要的自備素材仍建議先備份。
- 使用者 **須自行確認** 歌曲、歌詞、封面、錄音與其他素材的使用權利。
- 加入 [Discord](https://discord.gg/yJKddEtpNt) 社群，查看公告或回饋想法。

## Utawakui v0.4.0 Public Test

This update adds read-only OBS live status and chapter logging, an audible metronome, and Windows background operation, while improving pitch quality, resource reporting, update checks, and Settings reliability.

## New Features

- **OBS streaming and recording history:** After enabling the OBS integration and connecting to OBS WebSocket 5, the app shows streaming and recording state and elapsed time. Track changes and manual markers are saved to local session history and can be exported as YouTube chapters. The integration reads status only; it does not change scenes or sources.
- **Audible metronome:** Performance Tools now includes a metronome with an accented downbeat. A reliable analyzed track BPM can be applied automatically, while manual adjustments remain under the user's control.
- **Windows background operation:** The close button can now send the app to the notification area, exit completely, or cancel, with an option to remember the choice. Background mode preserves playback, OBS connections, and Output. The notification-area menu can reopen the main window or go directly to Settings.
- **App resource reporting:** The title bar shows CPU and memory usage for Utawakui itself, including app-launched workers while audio processing is active.

## Improvements

- **More natural live pitch changes:** Playback preview now uses higher-quality pitch processing for more stable sound when pitch changes without changing playback speed.
- **More reliable OBS connections:** Connection, status, and retry operations have explicit deadlines. Older connection results cannot overwrite current state after a reconfiguration or disconnect. Host, port, skip threshold, and password values are validated before saving, and a stored password can be explicitly removed in Settings.
- **Clearer library layout:** The Context Inspector can be resized, with more consistent spacing and alignment across the sidebar, content area, and inspector.

## Bug Fixes

- Fixed Settings sometimes failing to display in certain development or runtime environments because of a shared validation-module format mismatch.
- Prevented update checks from remaining in “Checking” indefinitely and optional-dependency downloads from waiting forever when no data arrives.
- Fixed title-bar resource figures reflecting the whole computer instead of Utawakui's own usage.
- Fixed slower OBS requests or stale connections overwriting newer state, and secure-storage failures being shown as if settings were saved.
- Fixed Escape closing more than the topmost dialog when multiple dialogs overlap.

## Upgrade Notes

- After upgrading, the first press of the window close button asks whether to run in the background, exit completely, or cancel. Selecting “Remember my choice” skips later prompts; Settings can restore the ask-every-time behavior. The minimize button continues to use the taskbar normally.
- The OBS integration remains off by default. Enabling it requires OBS WebSocket 5 connection details; its password is stored only in this computer's operating-system-backed encrypted storage.

## Known Limitations

- This public test build does not yet have a trusted Windows digital signature, so Windows may show “Unknown publisher”.
- The OBS integration currently reads status and time only. It does not switch scenes, modify sources, or remotely control playback.
- Spout2 lyric output remains experimental and has not completed compatibility acceptance across every receiver, multi-GPU setup, display-device reset, or transparent-edge composition. Use OBS Browser Source when stable output is required.

## Before Installing

- Download **only** from the [official Utawakui Releases](https://github.com/yPinn/Utawakui-Releases/releases) page. Use the included `SHA256SUMS.txt` to confirm that the installer is complete.
- The app **checks** for a newer version after startup and every few hours, but it **will not download or install** an update on its own. Automatic checks can be turned off in Settings.
- Installing over an earlier version normally **preserves** app settings and the selected library. Important user-provided media should still be backed up first.
- Users **remain responsible** for the rights to songs, lyrics, artwork, recordings, and other materials they use.
- Join the [Discord](https://discord.gg/yJKddEtpNt) community for announcements and feedback.
