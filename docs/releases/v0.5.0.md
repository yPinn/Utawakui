# Utawakui v0.5.0 公開測試版

本次更新把曲庫改造成可整理的資料夾式頁面，重整演出場次與 BGM 流程，新增輸出視窗與多款直播畫面樣板，並加入經你同意才傳送的嚴重錯誤回報。

## 新功能

- **資料夾式曲庫：** 歌手、專輯與歌單都有自己的頁面，可放上照片、便條與文具，像整理資料夾一樣排列；歌手頁會整理合作作品，也能選用 YT Music 上的歌手照片；重複的歌手資料會自動整理，也可手動合併或拆分。
- **更完整的歌曲資料：** 支援單曲與發行資訊、作品之間的關聯，並可在同一個視窗編輯歌曲。修改會先暫存，確認後才寫入；FLAC 檔可安全寫回標籤。
- **最近播放與續播：** 會記錄最近播放與每首歌的播放次數，重新開啟後可從上次位置繼續；側欄的歌手與專輯會依最近播放排序。播放資訊改在右側面板顯示，並支援鍵盤媒體鍵、滑鼠側鍵與「上一頁／下一頁」瀏覽。
- **試聽預覽：** 在歌單中可直接試聽歌曲片段或副歌，不會打斷正在播放的內容。
- **重整的演出場次：** 演出場次整合 BGM 控制，可事先準備場次、在歌曲之間自動銜接 BGM，並把場次存成歌單。演出佇列與一般播放佇列分開管理。
- **伴奏處理佇列：** 人聲分離改由統一的佇列處理，可從佇列中的任一首歌加入或重新產生。
- **輸出視窗與新樣板：** 直播畫面可開在獨立視窗，並可自由調整大小。新增「票據歌單」（並設為預設）與新版封面播放器，換歌時有動畫；可套用配色組合與本機字型，音量與靜音狀態也會同步到畫面。在編輯畫布上直接點選元素即可調整。
- **聲部標註：** 在歌詞編輯選「編輯 › 標註聲部」，選擇男、女或合後點歌詞行即可標註，按住 Shift 可一次標一整段；點人名行會沿用到下一位歌手。歌詞頁的螢光筆會依聲部變成藍、紅、綠，KTV 樣板也會依聲部顯示。
- **直播畫面的歌詞文字整理：** 製作人員資訊、提示標記與圓括號內的內容預設不顯示在直播畫面，可在歌詞「顯示 › 共用文字處理」逐行還原；原歌詞與時間不會被修改。
- **提詞器：** 提詞器會依視窗大小調整版面，並可直接播放／暫停與調整閱讀位置。
- **嚴重錯誤回報：** App 發生嚴重錯誤時會先詢問你，同意後才傳送錯誤類型、程式位置與版本給開發者，不含曲庫、歌詞、檔案路徑或你輸入的內容。可在設定中改為自動傳送或不傳送；傳送後可再補充說明。
- **從錯誤通知直接回報：** 錯誤通知多了「回報這個問題」，會自動填好發生的狀況。

## 改善

- **歌詞同步更穩定：** 改善逐字填色、換行銜接與尾段時間，支援英文與中英混合歌詞，並保留歌詞來源的原始文字。直播畫面上的長歌詞會依原本的換行逐段顯示並以動畫銜接，不再擠在一起或超出畫面；對唱、和聲與製作資訊的辨識也更準確。
- **匯入更方便：** 少見的音訊格式可轉成 FLAC 後匯入，原檔不會修改；匯入欄位會提示剪貼簿中可用的來源連結，同時下載的數量也有上限。
- **曲目表：** 可選擇要顯示的欄位與密度，並可依專輯、發行年份、匯入日期與播放次數排序。
- **啟動與曲庫更快：** 減少啟動時的重複工作，掃描曲庫時每個資料夾只讀一次，縮圖與較少用到的功能改為需要時才載入。
- **回報與建議更可靠：** 送出的內容與預覽完全一致，也會記錄是否已送出。
- **介面一致性：** 對話框、選單、提示與通知採用一致的外觀與鍵盤操作，設定頁分區更清楚。
- **更安全的本機連線：** 直播畫面伺服器只接受本機請求；錯誤紀錄會遮蔽檔案路徑與帳號資訊。

## 問題修復

- 修正 Windows 使用者名稱含空格時，選用工具可能無法安裝的問題。
- 修正結束程式時可能出現的錯誤，以及開啟對話框時按 Escape 誤觸其他操作的問題。
- 修正合作歌曲可能顯示錯誤歌手，以及查詢歌曲資料時過度頻繁重試的問題。

## 升級注意事項

- 「以瀏覽器登入資料重試下載」改為預設關閉。若有影片需要登入才能下載，請到「設定 › 瀏覽器登入資料」開啟。
- 線上來源下載工具已更新安全憑證元件。已安裝的使用者會在設定中看到「可更新」，建議更新後再下載。
- 「嚴重錯誤回報」預設為每次詢問，第一次遇到嚴重錯誤時才會出現提示。
- 直播畫面預設不再顯示歌詞中圓括號內的內容（例如和聲或回聲）。需要時可在歌詞「顯示 › 共用文字處理」取消勾選該行；這個選擇只在本次使用期間有效，換歌詞後會回到預設。
- 九款直播樣板改用新名稱，例如「票據歌單」「封面電台」。OBS 網址與已儲存的設定不受影響。

## 已知限制

- 此公開測試版尚未加入受信任的 Windows 數位簽章，因此安裝時可能顯示「未知的發行者」。
- OBS 整合仍只讀取狀態與時間，不會切換場景、修改來源或遠端控制播放。
- Spout2 歌詞輸出仍是實驗性功能。若需要穩定輸出，請使用 OBS Browser Source。

## 安裝前須知

- 請 **只從** [Utawakui 官方 Releases](https://github.com/yPinn/Utawakui-Releases/releases) 下載。可使用下載頁提供的 `SHA256SUMS.txt` 確認安裝檔是否完整。
- 應用程式會在啟動後及之後每隔數小時 **檢查** 新版本，但 **不會自行下載或安裝**。你可以在設定中關閉自動檢查。
- 覆蓋安裝通常會 **保留** 應用程式設定與自選曲庫；重要的自備素材仍建議先備份。
- 使用者 **須自行確認** 歌曲、歌詞、封面、錄音與其他素材的使用權利。
- 加入 [Discord](https://discord.gg/yJKddEtpNt) 社群，查看公告或回饋想法。

## Utawakui v0.5.0 Public Test

This update turns the library into organizable folder-style pages, rebuilds performance sessions and BGM handling, adds output windows and new stream templates, and introduces severe-error reports that are sent only with your consent.

## New Features

- **Folder-style library:** Artists, albums, and playlists each have their own page where you can arrange photos, notes, and stationery like a folder. Artist pages gather collaborations and can use an artist photo from YT Music. Duplicate artist entries are tidied automatically and can also be merged or split by hand.
- **Richer song details:** Singles, release information, and links between works are supported, and songs can be edited in one window. Changes are staged until you confirm them, and FLAC files can have their tags written back safely.
- **Recently played and resume:** The app records recent plays and per-song play counts, and can resume where you left off. Sidebar artists and albums are ordered by recent playback. Playback info now lives in the right panel, with support for keyboard media keys, mouse side buttons, and back/forward navigation.
- **Track previews:** Preview a song clip or chorus from a playlist without interrupting what is playing.
- **Rebuilt performance sessions:** Sessions now include BGM controls, can be prepared in advance, hand off to BGM between songs automatically, and can be saved as playlists. The performance queue is managed separately from the regular playback queue.
- **Accompaniment queue:** Vocal separation now runs through one shared queue, and any queued song can be added or regenerated.
- **Output windows and new templates:** Stream output can open in its own resizable window. The new “票據歌單” receipt setlist (now the default) and a new cover player with track-change animation are available. Color looks and local fonts can be applied, volume and mute are mirrored to the output, and elements can be selected directly on the editing canvas.
- **Vocal-part marking:** In lyrics editing, choose Edit › 標註聲部, pick male, female, or group, and click lyric lines to mark them; Shift-click marks a whole passage, and clicking a singer-name line carries that part to the next name. The lyrics page highlighter turns blue, red, or green by part, and the KTV template follows the same parts.
- **Lyric text cleanup for stream output:** Credit lines, cue markers, and text inside round brackets are hidden from stream output by default and can be restored line by line under the lyrics Display › 共用文字處理 panel. The original lyrics and timing are never changed.
- **Prompter:** The prompter adapts its layout to the window size and offers play/pause and reading-position controls.
- **Severe-error reports:** When the app hits a severe error, it asks first and sends only the error type, code location, and version to the developer — never your library, lyrics, file paths, or anything you typed. Settings can switch this to send automatically or never; after a report is sent you can add a description.
- **Report from error notices:** Error notices now include “Report this problem”, prefilled with what happened.

## Improvements

- **Steadier lyric sync:** Improved word-by-word fill, line transitions, and line-ending timing, added English and mixed-language lyrics, and kept the original text of each lyric source. Long lyrics on stream output now follow their original line breaks, appearing one section at a time with animated transitions instead of crowding together or overflowing; duets, backing vocals, and credit lines are recognized more accurately.
- **Easier importing:** Uncommon audio formats can be converted to FLAC and imported without changing the original file; the import field suggests supported source links found on the clipboard, and simultaneous downloads are capped.
- **Track tables:** Choose which columns to show and the row density, and sort by album, release year, import date, or play count.
- **Faster startup and library:** Less repeated work at startup, each track folder is read once per library scan, and thumbnails and rarely used features load only when needed.
- **More reliable feedback:** What is sent now matches the preview exactly, and the app records whether it was delivered.
- **Consistent interface:** Dialogs, menus, hints, and notifications share one look and keyboard behavior, and Settings is grouped more clearly.
- **Safer local connections:** The stream output server accepts only local requests, and diagnostic logs mask file paths and account details.

## Bug Fixes

- Fixed optional tools failing to install when the Windows user name contains a space.
- Fixed errors that could appear when quitting, and Escape triggering other actions while a dialog is open.
- Fixed collaborations sometimes showing the wrong artist, and song-data lookups retrying too often.

## Upgrade Notes

- Retrying downloads with browser sign-in data is now off by default. If a video requires sign-in, turn it on in Settings › Browser sign-in data.
- The online-source download tool now includes updated security certificates. If it is already installed, Settings shows “可更新” (update available); update it before downloading.
- Severe-error reporting defaults to asking each time; the prompt appears only the first time a severe error occurs.
- Stream output no longer shows lyric text inside round brackets (such as backing or echo lines) by default. To show a line, uncheck it under the lyrics Display › 共用文字處理 panel; this choice lasts for the current session and resets when the lyrics change.
- The nine stream templates have new display names, such as “票據歌單” and “封面電台”. OBS URLs and saved settings are unchanged.

## Known Limitations

- This public test build does not yet have a trusted Windows digital signature, so Windows may show “Unknown publisher”.
- The OBS integration still reads status and time only. It does not switch scenes, modify sources, or remotely control playback.
- Spout2 lyric output remains experimental. Use OBS Browser Source when stable output is required.

## Before Installing

- Download **only** from the [official Utawakui Releases](https://github.com/yPinn/Utawakui-Releases/releases) page. Use the included `SHA256SUMS.txt` to confirm that the installer is complete.
- The app **checks** for a newer version after startup and every few hours, but it **will not download or install** an update on its own. Automatic checks can be turned off in Settings.
- Installing over an earlier version normally **preserves** app settings and the selected library. Important user-provided media should still be backed up first.
- Users **remain responsible** for the rights to songs, lyrics, artwork, recordings, and other materials they use.
- Join the [Discord](https://discord.gg/yJKddEtpNt) community for announcements and feedback.
