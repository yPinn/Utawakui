# Utawakui v0.5.2 公開測試版

本次更新加入練唱與對時工具：可在歌詞頁反覆練習指定段落、用原曲波形調整每句時間，並為每首歌保存三組演唱設定；同時新增 App 內快捷鍵，BGM 也會優先播放伴奏。

## 新功能

- **逐曲演唱設定：** 每首歌可保存三組變調、速度與導唱設定，並指定其中一組作為下次播放的預設；切換組別時不會中斷播放。
- **區段練習：** 在歌詞頁標記開始與結束位置後可反覆播放同一段，並可在每輪之間插入短暫休息。
- **句子對時與波形：** 歌詞頁可顯示原曲波形，直接拖曳句子的開頭／結尾或整句平移；調整內容先存為草稿，可復原，確認後再手動保存。
- **App 快捷鍵：** 可在設定中自訂常用操作的快捷鍵，在主視窗內使用。
- **BGM 伴奏優先：** 已處理過人聲分離的歌曲，BGM 會優先播放伴奏，並可另外開啟導唱；沒有伴奏時會標示正在播放「原曲」，並可直接在導唱分頁產生伴奏、查看進度或重試。
- **節拍器音量：** 節拍器有獨立音量，不再跟著播放器音量或變調改變。

## 改善

- **歌詞搜尋：** 可辨識部分羅馬字與原文歌名的對應；主要來源沒有合適的同步歌詞時，會嘗試酷狗逐行歌詞備援。結果可預覽、比較，仍可再擴大搜尋。
- **搜尋結果保留：** 部分來源失敗或追加搜尋未完成時，保留已載入的歌詞候選，方便繼續檢視與選擇。
- **背景歌詞查詢：** 減少重複請求，並限制大量匯入時的背景查詢頻率，優先處理手動搜尋。
- **演出工具整理：** 調整、導唱與節拍器三個分頁改用一致的版面；原有的快速預設按鈕由逐曲三組設定取代，重複的人聲分離分頁也已移除。
- **長清單更流暢：** 曲庫曲目、播放佇列與歌詞選曲清單在曲目很多時捲動更順暢，曲庫連續更新時也減少重複讀取。
- **側邊面板配置：** 左右面板會依視窗寬度分配空間，展開或收合時不再擠壓或遮住主畫面。
- **隨機預覽：** 從歌手或全部曲目開始播放時，預覽會以選中的歌曲開頭並隨機排列其餘曲目；專輯與自建歌單仍維持原本順序。
- **通知：** 通知移到視窗右上角，不再遮住播放列向上展開的選單；播放錯誤改由統一的通知顯示，相同的失敗只提示一次；帶有操作的通知會保留到手動關閉。演出安排與演出播放的問題分開說明，重試文字也統一為「請再試一次」。
- **畫面細節：** 可捲動的區域會在上下緣顯示陰影，提示還有更多內容；提示框不再隨捲動移動或蓋住已開啟的選單；深色區域內的下拉選單顏色與周圍一致；間距、圓角、字級與動態效果更一致。

## 問題修復

- 修正 Better Lyrics 部分查詢條件及結果判讀，減少符合條件的歌詞被錯誤排除。
- 修正變調或速度設定尚未生效就開始播放，可能短暫聽到錯誤音高的問題。
- 修正播放錯誤提示與其他通知重疊在同一角落的問題。
- 修正只需轉檔確認的匯入結果，在匯入頁已開啟時仍重複跳出通知的問題。
- 修正歌詞來源清單或波形讀取失敗時，錯誤訊息未顯示在對應工具中的問題。
- 修正合併後的歌手名稱未在選曲清單、專輯預覽、直播輸出、Windows 媒體卡片與視窗標題一致顯示的問題；選曲時也可用任一種歌手寫法搜尋。
- 修正曲庫排序與日期格式跟著 Windows 系統語言改變，導致不同語言的 Windows 排序結果不一致的問題。
- 修正英文版 Windows 上人聲分離等音訊處理可能因文字編碼失敗，以及中文版 Windows 上錯誤訊息出現亂碼的問題。

## 升級注意事項

- **AMLL 舊歌詞：** AMLL 線上來源已移除。原先保存的歌詞會在讀取時轉為本機來源，保留歌詞、對時、時間偏移、來源偏好、讀音及聲部標註，並備份原始來源資料。

## 已知限制

- 此公開測試版尚未加入受信任的 Windows 數位簽章，安裝時可能顯示「未知的發行者」。
- 快捷鍵目前只在 App 視窗位於前景時有效，尚不支援在背景或遊戲／OBS 畫面中觸發。
- 線上歌詞仍可能因來源未收錄、限流或暫時中斷而查不到；歌名辨識與備援不保證每首歌都能找到，可改用原文歌名或匯入本機歌詞。
- 播放時偶發電子音／雜訊仍在調查；特定輸出設定下，監聽可能出現短暫無聲、卡頓、聲音模糊或延遲。直播或錄影前請先試播並確認實際收音。
- 節拍器長時間使用的節拍準確度仍在驗證。

## 安裝前須知

- 請 **只從** [Utawakui 官方 Releases](https://github.com/yPinn/Utawakui-Releases/releases) 下載。可使用下載頁提供的 `SHA256SUMS.txt` 確認安裝檔是否完整。
- 應用程式會在啟動後及之後每隔數小時 **檢查** 新版本，但 **不會自行下載或安裝**。你可以在設定中關閉自動檢查。
- 覆蓋安裝通常會 **保留** 應用程式設定與自選曲庫；重要的自備素材仍建議先備份。
- 使用者 **須自行確認** 歌曲、歌詞、封面、錄音與其他素材的使用權利。
- 加入 [Discord](https://discord.gg/yJKddEtpNt) 社群，查看公告或回饋想法。

## Utawakui v0.5.2 Public Test

This update adds practice and timing tools: loop a chosen section from the lyrics page, adjust each line's timing against the original audio waveform, and save three performance setting sets per song. It also adds in-app keyboard shortcuts, and BGM now prefers the accompaniment.

## New Features

- **Per-song performance settings:** Save three sets of pitch, tempo, and guide-vocal settings for each song and choose one as the default for next time. Switching sets does not interrupt playback.
- **Section practice:** Mark a start and end point on the lyrics page to loop the same section, with an optional short rest between passes.
- **Line timing and waveform:** The lyrics page can show the original audio waveform. Drag a line's start or end, or shift a whole line. Changes stay in a draft you can undo until you save them.
- **App shortcuts:** Customize keyboard shortcuts for common actions in settings and use them in the main window.
- **Accompaniment-first BGM:** For songs with vocal separation results, BGM plays the accompaniment first and can add the guide vocal separately. When no accompaniment exists, BGM shows that it is playing the “Original,” and the guide-vocal tab can generate the accompaniment, show its progress, or retry.
- **Metronome volume:** The metronome has its own volume and no longer follows player volume or pitch.

## Improvements

- **Lyrics search:** Recognizes some romanized and original-script song names as the same title. When primary sources have no suitable synchronized lyrics, it tries Kugou line-synced lyrics as a fallback. Preview and compare candidates, then broaden the search for more choices.
- **Keeping search results:** Lyrics candidates already loaded stay available when another source fails or an expanded search cannot finish.
- **Background lyrics searches:** Reduces duplicate requests and limits background search frequency during large imports, with manual searches taking priority.
- **Performance tools cleanup:** The adjustment, guide-vocal, and metronome tabs share one consistent layout. The previous quick preset buttons are replaced by the per-song setting sets, and the duplicate vocal separation tab is removed.
- **Smoother long lists:** Library tracks, the play queue, and the lyrics track picker scroll more smoothly with many songs, and bursts of library updates trigger fewer repeated reads.
- **Side panel layout:** Side panels share space based on window width and no longer squeeze or cover the main view when opened or closed.
- **Shuffled previews:** Starting playback from an artist or all-tracks view now starts with the selected song and shuffles the rest. Albums and your own playlists keep their order.
- **Notifications:** Notifications now appear in the top-right corner and no longer cover menus that open upward from the player bar. Playback errors use the shared notification area, identical failures are reported once, and notifications with an action stay until you dismiss them. Session-plan and session-playback problems are described separately, and retry wording is consistent.
- **Visual details:** Scrollable areas show edge shadows when more content is hidden. Tooltips no longer follow scrolling or cover open menus, and dropdown lists in dark areas match their surroundings. Spacing, corners, text sizes, and motion are more consistent.

## Bug Fixes

- Fixed some Better Lyrics query conditions and result checks that could incorrectly exclude suitable lyrics.
- Fixed playback sometimes starting before pitch or tempo settings took effect, briefly playing at the wrong pitch.
- Fixed playback error messages overlapping other notices in the same corner.
- Fixed a repeated notice for conversion-only import results while the import tab was already open.
- Fixed lyrics source list and waveform loading errors not appearing in the tool where they happened.
- Fixed merged artist names not appearing consistently in track pickers, album previews, stream output, the Windows media card, and the window title. Pickers now find a song by any of its artist name forms.
- Fixed library sorting and date formats following the Windows display language, which made sorting differ between language versions of Windows.
- Fixed audio processing such as vocal separation failing on English Windows due to text encoding, and garbled error messages on Chinese Windows.

## Upgrade Notes

- **Existing AMLL lyrics:** The online AMLL source has been removed. Previously saved lyrics are converted to local sources when read, preserving lyrics, timing, time offsets, source preferences, readings, and vocal-part annotations. The original source data is backed up.

## Known Limitations

- This public test build does not yet have a trusted Windows digital signature, so Windows may show “Unknown publisher.”
- Shortcuts currently work only while the app window is in the foreground; they cannot yet be triggered from the background or from game or OBS windows.
- Online lyrics may still be unavailable because a source has no matching lyrics, limits requests, or is temporarily down. Title matching and fallback sources cannot find every song; try the original-script title or import a local lyrics file.
- Intermittent electronic noise during playback remains under investigation. With some output settings, monitoring may have brief silence, stuttering, muffled sound, or delay. Test playback and check the actual captured audio before streaming or recording.
- Long-session metronome timing accuracy is still being verified.

## Before Installing

- Download **only from** the [official Utawakui Releases](https://github.com/yPinn/Utawakui-Releases/releases). Use the supplied `SHA256SUMS.txt` to check the installer.
- The app **checks** after startup and every few hours, but **does not download or install automatically**. Automatic checks can be disabled in settings.
- Installing over an existing copy normally **preserves** app settings and your selected library. Back up important user-supplied media first.
- Users **must confirm** their rights to songs, lyrics, artwork, recordings, and other materials they use.
- Join the [Discord](https://discord.gg/yJKddEtpNt) community for announcements and feedback.
