# Utawakui v0.5.3 公開測試版

收播後可保存場次、連結回放並匯出時間點。這版也加入播放清單資料夾、兩款直書歌詞、歌詞校訂與字幕匯出，以及可分開設定的介面與畫面輸出語言。

## 新功能

- **收播與場次紀錄。** 已連線的 OBS 結束直播時，Utawakui 會提醒你結束場次，確認後才保存。之後可從曲庫的「場次紀錄」或播放清單上的「本場演出」查看，重唱與中途停止的曲目也會記下。再次使用同一份播放清單，不會改動已保存的紀錄。
- **回放與時間點。** 在場次紀錄貼上 YouTube 影片或 Twitch 回放連結。場次有 OBS 直播或錄影時間時，可選擇對應片段並校正影片起點，再複製 YouTube 章節或儲存 CSV，方便剪輯時定位。
- **播放清單資料夾。** 在側欄拖曳，把自建播放清單收進資料夾，也可直接播放整個資料夾。刪除資料夾會一併刪除裡面的播放清單，音檔會保留。
- **OBS 直書歌詞。** 新增「黑板直書」與「中央直書」，可選手寫風格字型並調整文字清晰度。
- **歌詞校訂與字幕匯出。** 在歌詞頁「編輯 → 校訂文字」另存一份本機校訂版來修改歌詞，隨時可切回原來源。「逐句打點」可邊聽邊標記每句開頭，「匯出歌詞」可存成 LRC 或 SRT 檔。
- **風格標籤。** 在「編輯曲目」為歌曲加上自己的風格標籤。
- **介面與輸出語言。** 在「設定 → 語言」選擇繁體中文或 English。介面預設跟隨 Windows，重新啟動後套用；畫面輸出預設跟隨介面，也可單獨設定並立即套用。
- **YouTube 登入。** 在「設定 → YouTube 登入」使用 Firefox 的登入資料，或匯入從瀏覽器匯出的登入檔。登入檔只保留 YouTube／Google 資料並在本機加密保存，只在你手動開始的下載無法正常完成時使用。

## 改善

- **場間音樂與節拍器。** 在右側待唱面板展開場間音樂，可搜尋本機曲庫換曲、拖曳進度或調整音量。節拍器第一次點擊後會提示再點一下，擷取音量改以百分比顯示。
- **試聽與曲目表。** 試聽會顯示已有的同步歌詞，音量可單獨調整。曲庫會記住你選的欄位。
- **歌詞換句與尾奏。** 「和風直書」長句最多排成三欄，預設位置改到右上，換句時直接替換。尾奏時，最後一句歌詞不再停留過久。
- **線上歌詞搜尋。** 更多歌曲能找到同步歌詞。來源忙碌時，已找到的結果會保留。
- **匯入與背景處理。** 匯入面板可重試未完成的批次，或清除已完成的紀錄。關閉視窗時會說明哪些工作會繼續；伴奏處理中可選擇繼續處理，或停止並結束。

## 問題修復

- 重新命名播放清單時，目前歌曲的歌詞會保持顯示。修正播放器的彈窗互相重疊。

## 升級注意事項

- **YouTube 登入。** 原有的瀏覽器登入設定會改為 Firefox。使用 Chrome 或 Edge 時，請改為匯入登入檔。若提示登入可能已過期，請重新匯入。

## 已知限制

- 直播前請先試播，並確認 OBS 實際收到的聲音。偶發播放雜訊、部分監聽設定下的短暫無聲或延遲，以及節拍器長時間的準確度仍在驗證。快捷鍵目前只在 App 位於前景時有效。

## 安裝前須知

- 請從官方發行頁下載，並可用 `SHA256SUMS.txt` 核對安裝檔。覆蓋安裝通常會保留設定與曲庫。此測試版安裝時可能顯示「未知的發行者」。[官方發行頁](https://github.com/yPinn/Utawakui-Releases/releases)
- **更新與素材。** App 會自動檢查更新，可在設定中關閉；是否下載與安裝由你決定。請自行確認素材的使用權利。歡迎到社群查看公告或回饋意見。[Discord](https://discord.gg/yJKddEtpNt)

## Utawakui v0.5.3 Public Test

Save your session, link the replay, and export timestamps after a stream. This update also adds playlist folders, two vertical lyrics styles, lyric correction with subtitle export, and separate language settings for the app and Output.

## New Features

- **End a stream and save your session.** When a connected OBS stream ends, Utawakui prompts you to end the session and saves it once you confirm. Open it later from Session records in the library or the performance note on its playlist. Repeats and songs stopped partway are included. Reusing the playlist leaves the saved record unchanged.
- **Replays and timestamps.** Paste a YouTube video or Twitch replay link into the session record. When OBS stream or recording times are available, select the matching segment and adjust the video start time, then copy YouTube chapters or save a CSV for editing.
- **Playlist folders.** Drag your own playlists into sidebar folders, or play an entire folder. Deleting a folder also deletes the playlists inside it and keeps the audio files.
- **Vertical lyrics for OBS.** Chalkboard Vertical and Centered Vertical add handwriting-style fonts and readability controls.
- **Lyric correction and subtitle export.** On the lyrics page, choose Edit → Correct lyrics to save a local revision you can edit and switch back from at any time. Tap line timing marks each line’s start as you listen, and Export lyrics saves an LRC or SRT file.
- **Style tags.** Add your own style tags to a song in Edit track.
- **App and Output language.** In Settings → Language, choose Traditional Chinese or English. The app follows Windows by default and applies changes after a restart. Output follows the app by default, or can be set separately with immediate effect.
- **YouTube sign-in.** In Settings → YouTube sign-in, use your Firefox sign-in or import a file exported from your browser. The imported file keeps only YouTube and Google data, is encrypted on your computer, and is used only when a download you start can’t finish the usual way.

## Improvements

- **Interlude music and metronome.** Expand Interlude music in the right-hand performance queue to search your local library for another track, seek, or adjust volume. The metronome prompts you to tap again after the first tap, and capture volume is shown as a percentage.
- **Previews and track columns.** Track previews show synced lyrics when available and have their own volume. The library remembers the columns you choose.
- **Lyric transitions and outros.** Japanese Vertical wraps long lines into up to three columns, defaults to the upper right, and replaces each line directly. The final line no longer lingers through instrumental outros.
- **Online lyrics search.** More songs now find synced lyrics. Results already found stay available when a source is busy.
- **Imports and background work.** The import panel lets you retry unfinished batches or clear completed records. The close prompt explains what keeps running, and during accompaniment processing lets you keep processing or stop and quit.

## Bug Fixes

- Renaming a playlist keeps the current song’s lyrics on screen. Playback popovers no longer overlap.

## Upgrade Notes

- **YouTube sign-in.** The previous browser sign-in setting changes to Firefox. If you use Chrome or Edge, import an exported file instead. Import a fresh file if the app says the sign-in may have expired.

## Known Limitations

- Before streaming, test playback and check the audio OBS actually receives. Intermittent playback noise, brief dropouts or delay in some monitoring setups, and long-session metronome accuracy remain under review. Shortcuts currently work only while the app is in the foreground.

## Before Installing

- Download from the official releases page and use `SHA256SUMS.txt` to check the installer. Installing over an existing copy normally keeps your settings and library. Windows may show “Unknown publisher” for this test build. [Official releases](https://github.com/yPinn/Utawakui-Releases/releases)
- **Updates and media.** The app checks for updates automatically, and you can turn this off in Settings. You choose when to download and install. Confirm that you have the rights to use your media. Join the community for announcements and feedback. [Discord](https://discord.gg/yJKddEtpNt)
