# HubertFA CPU／DirectML 有界對照

日期：2026-10-21。研究已完成，未接入產品。使用者已決定目前 CPU 足夠，新的歌詞 GPU 路徑暫緩；既有伴奏分離 DirectML 不變。當前方向見[歌詞研究結論](../lyrics-alignment/lyrics-alignment-summary.md)，去私有化數據見[JSON](data/lyrics-hubertfa-directml-2026-10-21.json)。

## 方法與分母

RTX 5060 Ti、driver 617.14、16,311 MiB 顯存，Node 24.17.0／ORT Node 1.30.0。使用同一 HubertFA model.onnx、既有字典及隔離 Python／small 環境，不新增下載。DXGI 確認 NVIDIA adapter，ORT profile 確認實際 DML／CPU 混合執行；沒有只憑 backend 登錄判定成功。

固定中／日／英正常句各一案及一個既有日文長尾案，共四行。沿用原來源、offset、原文範圍、至多 30 秒聲學窗、20 秒單句上限及 350 ms decoder padding。small 仍在 CPU；英文每句前後 500 ms 盲轉寫，中日沿用原整窗查核。只省略 small 的 no-prints 日誌旗標以取得 timing，模型／內容門檻未改。

每 backend 一個新 session：先跑四案完整研究流程，再跑兩輪四窗暖聲學推論，共 24 次正常推論。另有一次獨立 8.91 秒相容性前測，以及 CPU／DML 各一次送出推論後取消；不把取消或前測加進正常四案的品質分母。CPU 先、DML 後，未隨機化或清空 OS cache；兩組均開 profiling。I/O 皆 float32，DML 內部 compute 精度未獨立量測。

## 效能與品質

| 指標                      |       CPU |  DirectML |
| ------------------------- | --------: | --------: |
| 新 session 模型載入       |  1.019 秒 |  1.191 秒 |
| 四窗首輪 ONNX 推論合計    |  6.914 秒 |  2.953 秒 |
| 八次暖聲學推論平均／窗    |  1.666 秒 |  0.155 秒 |
| 四案 small wall time 合計 | 37.863 秒 | 38.172 秒 |
| small 原生模型載入合計    |  1.189 秒 |  1.216 秒 |
| 四案首輪研究批次          | 47.490 秒 | 43.899 秒 |

整批省 3.591 秒（7.56%）；暖聲學約 10.76 倍不能視為整體倍速。DML 第一窗仍花 2.512 秒，之後三窗約 0.129–0.183 秒。small 占 DML 批次約 87%，context 重用的實際收益未測，不能把約 1.2 秒載入成本視為一定全部消除。

批次包含前端／decoder／日文字典啟動、音訊解碼、CPU 解碼、small 與研究輸出；共用資產驗證 3.154 秒另列，來源／工具凍結及 hash 不計入。這是四行研究 batch，不是四首整曲或 App 按下分析至完成的實測，亦非 production latency 保證。

| -------- | -------------------: | ------------------------------ |
| 中文正常 |                 6／6 | 7 詞塊，可用                   |

完整分母為 24 個要求的內部切點，兩組皆保留 22、缺 2；可比較的 22 個內部起點毫秒差全為 0，原文 UTF-16 範圍、詞塊數、內容決策、警告及回退相同。4 個來源行起點是固定錨點，不當額外聲學命中。長尾案的 3 個原始內部起點仍因內容拒絕而不套用。

這只表示四案 backend 間一致，沒有證明一般時間準確率、內容品質或長尾改善。人工時間仍 pending，不以 provider／模型時間代填。

## 執行證據與限制

- DML 的 profile 去重為 1,042 個 DML、196 個 CPU 節點；十二次推論共 12,504／2,352 筆節點執行事件。CPU 對照為 1,244 個 CPU 節點，最佳化後圖不同，不拿節點總數作效率或品質評分。
- 前端 high-water RSS：CPU 1,484,681,216 bytes、DML 602,148,864 bytes；Python decoder 各約 144 MB。small 峰值 RAM 未量，不將各程序峰值相加或據此宣稱總記憶體更省。
- 約每秒整卡採樣 83 筆為 2,725–4,446 MiB，晚於批次開始且含其他桌面負載，不代表單程序顯存峰值。未做 OBS 競用驗收。
- 兩組送出 infer 約 25 ms 後要求取消，request 均拒絕、owned workers 退出，沒有完成估計、後續解碼／small 或 CPU 重試。收尾 CPU 5.255 秒、DML 0.119 秒；沒有獨立 kernel-entered 標記，未涵蓋每個 native 階段。
- 初次 frozen snapshot 缺少完整性驗證所需的 node_modules 相對路徑，在四案推論前失敗；以既有依賴 junction 補足後用新目錄重跑，不改驗證器或環境。首次失敗與完整原始日誌保留。
- 來源、模型、環境及 harness hashes 前後核對一致，取消後無 owned 程序。未新增 App／OBS／人工驗收，也不將既有全庫測試數當成這輪研究結果。

公開 JSON 不含私人音訊、歌詞、來源路徑、模型檔或人工標記；原始證據保留於 ignored 本機研究目錄，不清除、不分發。此報告只收錄已完成實測，不要求重跑。small Vulkan／CUDA 的容量與未測項另見[成本評估](whisper-small-gpu-cost-2026-10-21.md)。
