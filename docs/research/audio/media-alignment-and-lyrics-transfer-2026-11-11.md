# MV 時間對照與歌詞時間搬移

2026-11-11。第一階段獨立離線探針，未接正式播放器、歌詞匯入或校對介面。兩支指定的飛ぶ時來源仍只有前輪公開 metadata，這輪未下載音軌，不能給出它們的實際偏移。操作與輸入格式見[工具入口](../../../scripts/research/mediaAlignment/README.md)。

## 結論與共用邊界

可共用的是兩份已知音源之間的時間對照。對同錄音的片頭差異與剪輯增刪，先找共同音訊，再把已存在的歌詞時間搬到另一版本。只有文字、沒有已知參考音源或只有無聲影片時，這套方法本身無法建立演唱時間。既有歌詞聲學研究仍見[研究結論](../lyrics-alignment/lyrics-alignment-summary.md)，本輪沒有更換模型、安裝套件或放寬門檻。

| 用途                                 | 如何共用                               | 本輪範圍                       |
| ------------------------------------ | -------------------------------------- | ------------------------------ |
| 無聲 MV 跟隨本機音訊                 | 正向查本機音訊到 MV 的時間             | 僅輸出離線候選，未接播放       |
| MV 歌詞搬回本機版本                  | 在單調、無歧義的共同段落做反向時間轉換 | 已有句首／句區間候選與測試     |
| 同歌不同剪輯的原文及譯文             | 保留行 ID 與原文，只附新時間候選       | 已驗原資料不變、重複文字不合併 |
| 新增逐字時間或修正原來唱錯位置的標記 | 需要另外辨識文字與演唱位置             | 不屬於音訊版本時間搬移         |

正式播放仍由本機 audio 控制時間。已對應本機音源的歌詞沿原座標，不再套一次 MV 映射；只有外部來源歌詞時間需要轉換。變調及監聽延遲屬播放投影，不寫回離線資料。若原始歌詞時間錯誤，版本搬移也會帶著該錯誤，不能把成功配對音源當成已校正唱詞時間。

T2 詞塊理論上也能轉換已有的時間點，但會同時承受原始詞界及時間對照的誤差。每個詞塊都須通過缺口與剪輯邊界檢查，仍需逐字真值另驗。本輪只輸出 T1 句級候選，不宣稱改善逐字準確度。

## 方法與結果

沿用 NumPy／FFmpeg，先做小型同錄音 baseline：4 kHz mono、2 秒窗口、0.5 秒步距的 normalized cross-correlation，四個子窗確認、第二候選差值與至少兩個連續窗口支持。整段偏移範圍須不超過 30 ms，避免相鄰窗口差異逐步累積成錯誤固定偏移；輸出依雙側時長裁切且保留原偏移。只輸出斜率 1 的穩定段，雙側其餘區域列為未知。靜音、重複、局部失配及重排保留不支持，此版不提供速度差校正；候選不會寫回正式 sidecar。

音樂特徵與 DTW 可作後續複雜配對候選；普通 DTW 仍須額外處理增刪、重複與未配對區，不能直接將完整路徑套到影片每一影格。本輪尚未實作此方法。[AudioLabs 音樂同步](https://www.audiolabs-erlangen.de/resources/MIR/FMP/C3/C3_MusicSynchronization.html)

合成評估的一般案例使用不同於單元測試的種子生成和聲、節奏與噪音，另納入複查發現的低通慢速漂移回歸案例，均沒有真人歌唱。每 100 ms 評分一次，超過 100 ms 誤差或落在已知無對應區的輸出都計入錯配。未知的共同內容仍進覆蓋分母。固定快照見[評估摘要](data/media-alignment-2026-11-11.json)。

| 合成案例                 | 結果                              | 共同區覆蓋 |
| ------------------------ | --------------------------------- | ---------- |
| 前後留白與音量差         | 一段固定偏移                      | 100%       |
| 刪除來源片頭             | 一段固定偏移，缺少的片頭保持未知  | 100%       |
| 中間插入 3 秒並刪除 3 秒 | 三段正確候選                      | 100%       |
| 8.17 秒處插入 2.37 秒    | 兩段候選，剪輯附近 0.5 秒保留未知 | 97.92%     |
| 同一片段重複兩次         | 歧義，無候選                      | 不適用     |
| 不同素材或靜音           | 無候選                            | 不適用     |
| 1.5% 速度差              | 此 baseline 不支持，無候選        | 0%         |
| 0.3% 慢速漂移回歸        | 整段偏移不穩定，拒絕固定偏移候選  | 0%         |

上表在抽樣網格上沒有錯配；不代表每個連續時刻都經驗證，也不代表真曲準確率。四分鐘合成音訊的單次檔案級測量為分析 12.645 秒、含 FFmpeg 解碼及指紋共 12.772 秒，2400 個評分位置均配對。這不是目標硬體基準或實曲效能保證，沒有量測記憶體峰值。另有 FFmpeg 真實 MP3 編解碼測試確認同錄音壓縮後仍可找出偏移；測試沒有語音、現場編曲或跨母帶素材。

21 項單元／檔案測試通過。複查找到的慢速漂移累積、候選超出媒體邊界及無效 JSON 留下殘檔，均先以負控制重現後修正。Ruff 檢查／格式、Markdown、文件格式與評估程式指紋均經核對。正式程式未變更，未重做 App 建置、封裝或可見 Electron 驗收。

## 歌詞候選政策

- 原文、行 ID、譯文與來源時間完整保留；候選時間獨立保存。來源是 MV、目標是本機時使用反向映射。
- 只有句首的 T1 保持句首，句尾為 null，不以下一句或拍點推造句尾。
- 有句尾的句子必須完整位於同一可配對段落；跨剪輯、落在缺段或沒有時間時標為待校對。
- 重複歌詞依各次行身分保留，不以相同文字當配對鍵。音訊出現多個同樣合理的位置時，保留歧義。
- 報告綁定兩份媒體 SHA-256、演算法版本與參數；帶歌詞時再記錄原始 JSON SHA-256 及方向。正式接入前仍需對接既有 document／音源修訂與人工 offset 規則。

這輪完成雙向時間轉換與拉條所需的純查表行為，尚未將候選套入正式歌詞或可見 Electron。原歌詞與影片控制台的行為均由既有 owner 保持。

## 下一階段

先用可取得的同錄音實曲驗固定偏移及中後段，補上壓縮、母帶處理、剪輯邊界與錯配負控制，再決定是否接入預覽／套用。接入時沿現有 Main 候選、音源修訂與歌詞 document 身分，renderer 只提出有界操作。

播放器再接斜率 1 的分段跳接與未知區；歌詞端先接既有時間候選的人工校對，不自動覆寫來源。拉條、AB 循環、暫停、降 2 Key、版面穩定及即時監聽延遲都需要可見驗收。速度差、不同錄音、Chroma／DTW、T2 搬移與純文字建時另列驗證，這輪沒有宣稱完成。
