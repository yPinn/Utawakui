# 飛ぶ時實曲音軌對時

2026-11-11。延續[離線探針](media-alignment-and-lyrics-transfer-2026-11-11.md)，本次核對同一首歌的實際音軌、既有歌詞及受控剪輯。結果支持先提供固定偏移候選；此輪未接正式介面，也未量測 MV 畫面時間戳。

## 來源與結果

| 來源                                                         | 取得方式                                      | 4 kHz 解碼時長 |
| ------------------------------------------------------------ | --------------------------------------------- | -------------- |
| [飛ぶ時音源](https://www.youtube.com/watch?v=LVCwdZoUFQ8)    | 本機曲庫原始 WebM，唯讀                       | 252.81125 秒   |
| [飛ぶ時官方 MV](https://www.youtube.com/watch?v=ARj1adoUoEU) | 同一 ID 以現有 yt-dlp 取得格式 251 的參考音軌 | 254.33975 秒   |

兩條參考音軌均為 48 kHz 雙聲道 Opus，容器音訊起點均為 0。既有探針對 4 kHz 單聲道訊號做整曲比對，共 502 個窗口，其中 494 個配對、7 個歧義、1 個靜音。配對區為本機 `0–246` 秒及 `247–251` 秒，共 250 秒，占解碼本機時長 98.89%，兩段固定偏移皆為 0 ms。含解碼和指紋的單次探針耗時 13.587 秒。

另以 2 秒窗口在 ±250 ms 內直接做正規化相關，抽查本機 2、20、60、126、190、239、246、248、250 秒。九個窗口的最佳偏移均為 0 ms，相關值為 0.9996329–0.9998219。全域探針在 246–247 秒留有歧義，局部檢查支持相同偏移；不將未知區解讀為影片刪段，也不改寫原始候選。

MV 參考音軌比本機多 1.5285 秒，4 kHz 解碼後該尾端全零。另以 FFmpeg 在原始 48 kHz 雙聲道的第 12134940 個 sample frame 後量測，73370 個 sample frame 的峰值與 RMS 都是負無限 dBFS，確認這段為數位靜音。這些量測只描述音軌；尚未確認 FHD 影片的畫面起點、結尾內容或瀏覽器呈現。固定偏移候選為 **0 ms**，沒有根據要求使用者整首移動或變速。

## 剪輯、壓縮與歌詞控制

從本機原曲取 60–120 秒，建立 60 秒真實錄音片段。對照版先加 2 秒靜音，接著在片段第 20 秒加入 3 秒非相鄰素材，刪去第 40–46 秒。已知的三段偏移依序為 +2000、+5000、−1000 ms；被刪段無對應。以每 100 ms 抽樣，540 個已知共同位置全部配對，沒有在缺段產生錯誤位置。另以相同片段加 2 秒並做音量改變及 64 kbps MP3 編碼，600 個共同位置均找回 +2000 ms；用另一首本機曲目作負控制，無候選。這是受控同錄音驗證，未涵蓋不同演唱、母帶或速度差校正。

曲庫的既有 LRC 由現行歌詞 normalizer 載入，共 53 個行身分。原始歌詞與推定句尾保留在原文件；候選只使用句首，不把下一句推定邊界當成已標註句尾。全曲 53 個句首均能轉到 MV 再回到原值，0 個需要移位。剪輯測試的 12 個句首中，11 個依各段移位且往返一致，落在刪段的 1 個保留待校對。沒有重寫歌詞、產生新翻譯或認證原本句首是否對準演唱。

## 接入決策

- 本曲先用既有固定偏移 0 ms。在實際 FHD 檔案確認畫面時間原點後，再驗拉條、暫停、降 2 Key 及固定畫面區。
- 正式影片分頁優先沿用既有對時區，加一個估算偏移動作。候選顯示偏移及可抽查位置，由使用者預覽後套用；同錄音的尾端差異不需要分段介面。
- 只有共同內容跨越確定的剪輯變化時才提供分段候選。無法配對的區間與需要校對的歌詞獨立列出，避免把單一低分窗口當作缺段。
- 已對應本機版本的歌詞維持原時間。外部版本的時間搬移放在既有歌詞校對流程，按行身分保留原文與譯文，確認後才套用；缺少已知參考音源時維持人工校對。
