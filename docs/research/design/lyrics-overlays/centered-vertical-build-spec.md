# 中央直書首版 Build Spec

依 Proposal 實作中央單欄。每頁單欄的水平及垂直中點對齊畫布正中心。上下安全線分別在畫布高度 15% 與 85%，欄內字距為 0.08em，維持單欄排版。畫面透明，繁體中文用封裝的辰宇落雁體 2.0 細體，日文用 Klee One SemiBold，其他或未標記語言用 Open Huninn。文字為白色，帶薄暗邊與向右下偏移的陰影。工作臺預設小字級，可選小、標準或大。字型可依歌詞語言或手動選擇辰宇落雁體、Klee One、Open Huninn。

使用既有 1920×1080 歌詞 Browser Source 與逐行時間。當前句及換頁直接替換，間奏回到透明。每欄按 68% 畫布高度量測，保留字形及陰影的空間。分頁沿用來源換行及判定為分句的中日文空格。仍超過欄高的片段再沿自然斷點切分，原句和來源範圍由共用排版保留。每頁保留可對應的 T2／T1+ 起點，即使該頁可讀時間短於 800 ms。分句落在兩個計時起點之間時，只估算該分句的起點。只有逐行時間時按頁面內容加權，優先留 800 ms 閱讀時間。混語沿瀏覽器直排規則保留原字形，英文詞組側轉，放得下一欄時優先保留在同一頁。

Gallery 使用合成歌詞定格。實際頁面容量和換句時間以工作臺及正式 Browser Source 為準。[中央直書 Proposal](centered-vertical.md)

## 首版 OBS 驗收（固定上緣）

OBS 32.2.2 以正式 `/overlay/lyrics` 回放 Proposal 的短句、長中文句、中日英混語及連續短句。中字級與大字級各擷取 21 張播放定格和一張暫停跳轉定格。在 960×540 的取樣畫面以無字幕底圖比對，安全線為 Y 81 至 459 px，兩種字級的可見文字都落在 Y 82 至 413 px 內，並維持水平中央。大字級的長句頁數可增加，欄位仍從同一上緣直接換頁。間奏回到透明。

完整 OBS 回放的取樣落在混語的日文頁與中文頁。英文中間頁的 OBS 補擷取在連線前中斷，另用 Electron 載入同一 Browser Source 路徑，在 6750 ms 暫停確認「stay with me，」完整位於同一欄，中字級與大字級都在安全線內。完整回放另有一次 OBS 擷取呼叫延遲，下一張中字級短句取樣已進入間奏。結果限於離散取樣。

## 正中央版 OBS 驗收

以正式 Browser Source 重播短句、中文長句、混語與連續短句。960×540 的中字級與大字級可見取樣都維持單欄。相對畫面中心，可見字形的外接框中點水平偏差至多 0.5 px，垂直偏差至多 5.5 px，取樣皆在上下安全線內。
