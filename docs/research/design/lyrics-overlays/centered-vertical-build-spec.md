# 中央直書首版 Build Spec

依 Proposal 實作中央單欄。字幕欄固定在畫布水平中線，起讀點在畫布高度 15%，下安全線在 85%。畫面透明，採封裝字體 Open Huninn，文字白色並帶細暗影。工作臺可調字級。

使用既有 1920×1080 歌詞 Browser Source 與逐行時間。當前句及換頁直接替換，間奏回到透明。每欄按 68% 畫布高度量測，保留字形及陰影的空間。長句沿自然斷點分頁，原句和來源範圍由共用排版保留。分頁沿用可對應的 T2／T1+ 時間，無對應時間時按頁面內容加權。分頁優先留 800ms 閱讀時間，時間不足時在該句時段內重排。混語沿瀏覽器直排規則保留原字形，英文詞組側轉，放得下一欄時優先保留在同一頁。

Gallery 使用合成歌詞定格。實際頁面容量和換句時間以工作臺及正式 Browser Source 為準。[中央直書 Proposal](centered-vertical.md)

## OBS 驗收

OBS 32.2.2 以正式 `/overlay/lyrics` 回放 Proposal 的短句、長中文句、中日英混語及連續短句。中字級與大字級各擷取 21 張播放定格和一張暫停跳轉定格。在 960×540 的取樣畫面以無字幕底圖比對，安全線為 Y 81 至 459 px，兩種字級的可見文字都落在 Y 82 至 413 px 內，並維持水平中央。大字級的長句頁數可增加，欄位仍從同一上緣直接換頁。間奏回到透明。

完整 OBS 回放的取樣落在混語的日文頁與中文頁。英文中間頁的 OBS 補擷取在連線前中斷，另用 Electron 載入同一 Browser Source 路徑，在 6750 ms 暫停確認「stay with me，」完整位於同一欄，中字級與大字級都在安全線內。完整回放另有一次 OBS 擷取呼叫延遲，下一張中字級短句取樣已進入間奏。結果限於離散取樣。
