# 中央直書

模板 ID 為 `centered-vertical`。2026-11-04 依本次字幕風格討論收錄，源自使用者對ヨルシカ《盗作》系列的構想。目前採中央單欄、水平與垂直置中、直接換句及單欄分頁。[首版 Build Spec](centered-vertical-build-spec.md) · [候選索引](README.md)

## 體驗與舞台參考

讓觀眾一眼找到畫面中央的一欄乾淨直書。字距與上下留白維持穩定，句子只做簡易切換。相較現行和風直書的右側、多欄與字組揭示，本款以單欄、穩定軸線及簡單交接為主要特徵。

《前世》約 [1:04:08](https://www.youtube.com/watch?v=Rl1xfaXlrxw&t=3848s) 的全景可見歌詞集中在背景中央的小區域，外圍由布景及燈束構成。借用其集中視線的取景關係。單欄直書及簡易切換來自使用者描述。參考為已抽看定格的外部影片，未保存影片或截圖作為素材。

## 定格構圖與圖層關係

以 16:9 固定取景，正中央設一條直欄軸線和固定的上下安全線。短句和長句沿用相同字距，整欄的垂直中點固定在畫面中央，長句仍須落在上下安全線內。畫面其餘部分留給 OBS 底圖及人物。

| 群組 | 外觀與堆疊                                   | 附帶動效                     |
| ---- | -------------------------------------------- | ---------------------------- |
| 舞台 | 基本版透明，由 OBS 場景提供背景和人物        | 無                           |
| 歌詞 | 單欄當前句位於最上層，可比較低顯著描邊或陰影 | 同一錨點直接換句，或做輕淡化 |

若採短淡化，舊句先退離主焦點，再讓新句取得完整對比。基準版只顯示當前正文，裝飾、曲名、讀音與預讀皆留待評估。描邊或陰影跟字定位，可比較獨立停用。單欄的安全線、字距與位置一起納入量測。

## 長句、混語與同步

用「夜色亮起」確認短句起讀點，再用「等到遠處的燈一盞一盞亮起，再把那封信慢慢讀給你聽」確認下界。「夜が明けるまで，stay with me，陪我走過這條街」比較 Latin 詞組整段側轉及單欄不足時的可讀回退，保留詞序、標點和內容。

先維持自然字距，超出欄高時比較有限縮字與沿自然斷點單欄分頁。最低字級、分頁可用時間與極端混語的回退待定。以 T1 行級切換為基本候選，T0 比較透明空態，原生 T2 和 T1+ 先沿相同的行級交接。若分頁需要行內時間，另評估資料來源及 T1 回退。各頁對應原行與來源範圍。

## 鏡位、換句與播放狀態

鏡位固定，歌詞只在原欄淡化或直接切換，背景及人物由 OBS 場景定位。左、右人物佔位先維持中央。人物居中時，比較整欄微移與固定偏側構圖。只有偏側版形成穩定且可獨立套用的取景時，才列為預設候選。

1. 進場。首句在當前 cue 開始時就位，可比較直接顯示和短淡入。
2. 定格。字保持靜止且完整可讀，上下界與直欄軸線固定。
3. 交接。下一句沿同一軸線替換，先比較直接切換，再比較無明顯疊字的短淡化。
4. 退場。無接續句時回到透明，間奏由 OBS 原場景承接。

快速換句優先直接落到可讀狀態。暫停保留當前句，seek、重連與隱藏恢復依當前 cue 落位，換曲、無資料或停用清除舊句。Reduced motion 可用直接切換。

## 可調邊界、可行性與驗收構想

候選調整為整欄位置、字級、字距、上下內距與可選對比補強。字級、字距及內距都會影響容量，需共同驗證。保持單欄與可讀上下界，精確值域待定。

先比較共用直書量測、標點與 Latin 排法可沿用的範圍，以及單欄容量缺口。字型與缺字回退、散布條件待查。後續以同一背景比較短句、長句與混語的起讀點，用左中右人物佔位、快速切換、明暗底圖及透明合成確認單欄仍容易找。
