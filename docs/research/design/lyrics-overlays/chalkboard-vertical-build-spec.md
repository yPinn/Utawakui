# 黑板直書第一版 Build Spec

依[黑板直書 Proposal](chalkboard-vertical.md)及本次開始實作的確認。第一版以當前來源句、固定正面構圖、整組微移為範圍。

## 登錄與資料

`chalkboard-vertical` 屬於 lyrics slot，使用既有 1920×1080 Browser Source。最低 T1。T0 無行級資料時保持透明。換句沿用原 cue。分頁可採 T2／T1+ 提供的來源起點，無足夠精確起點時按容量加權。顯示批次保留來源範圍。歌詞來源及播放時間由既有播放器和 Projection Hub 持有。

## 構圖與動態

畫布橫向等分為左、中、右三區。預設在左區，可切到右區，中區留給人物。每頁一至三欄，每欄由上往下，欄序由右往左，同一上緣。先沿自然斷點分欄，超量交給共用分頁。字與右線同欄，白色字面帶粉筆顆粒與微暗輪廓，畫面底色透明。X ±12% 微調在所選區內依整組寬度限位，Y 可微調 ±25%。欄高上限為畫布高度 44%，在垂直位移端點仍留在畫布內。

文字與右線按畫面上的字形位置同步逐字揭示，先完成右欄再寫左欄。退場時，文字由下向上逐字收回，右線由上向下按對應的字距逐段收回。舊句在下、新句在上。分頁優先保留 800ms 閱讀時間，時間不足則重新分配整句時段。進場最多 720ms，並以本頁剩餘時間的 70% 為上限，剩餘少於 180ms 時直接顯字。快速換句只保留相鄰兩批，seek、重連、暫停和 reduced motion 直接就位。無接續句時退到透明。

## 預覽與驗證

Workbench 走正式 route。Gallery 使用既有合成歌詞做定格，實際欄寬與分鏡以 Browser Source 回放驗證。以短句、長句、混語、快速換句、seek、間奏和左中右佔位驗證，核對模板切換與設定保存。作品驗收結果以實際回放記錄為準。

OBS 32.2.2 以隔離場景回放正式 `/overlay/lyrics`。左、中、右人物框各取 21 張播放定格及一張跳轉定格，可見首句、長句的三頁、混語的兩頁及間奏清空。大字級與兩組 X／Y 位移端點的定格都留在畫布內。置中人物框在端點仍可能與欄位交疊，偏側構圖待比較。最後一輪從啟用來源到首次確認歌詞已繪出約 52 秒，回放計時在畫出首句後開始。這段等待含 CEF 載入與連線。淺色合成的定格確認字與右線的暗邊可見，Gallery 另擷取 1280×720 深色定格。人工作品驗收與跨環境檢查待執行。

## 置中 VTuber 構圖回放

以下為改用等寬三區前的對照紀錄。

2026-11-04，以隔離 OBS 32.2.2 的正式 `/overlay/lyrics` 比較五種構圖。Browser Source 固定 1920×1080、中字級、Y 0。人物框固定在畫布 X 36–64%、Y 18–96%。沿用首版同一段合成 T1 歌詞，包含三頁長日文句、兩頁中日英韓混語句、連續短句及間奏。每種構圖取 21 張播放定格和一張跳轉定格，共 110 張，涵蓋 1.4 秒、4.4 秒換句附近。

左右微移使用現行 X 設定端點。偏左／偏右候選把整個 OBS Browser Source 各平移約 24% 畫布寬，維持原尺寸與排版，模擬字幕組中心在 X 26%／74% 的位置。以同一張無字幕底圖比對，將 RGB 三通道各提高至少 24 視為字幕亮部，另用像素絕對差轉灰階、門檻 8 檢查細線和暗邊是否進入人物框。

| 構圖             | 字幕組中心 X | 明顯字幕與人物框交疊 | 亮部最小水平間距 |
| ---------------- | ------------ | -------------------- | ---------------- |
| 中央基準         | 50%          | 20／20               | 交疊             |
| 現行向左微移端點 | 38%          | 20／20               | 交疊             |
| 現行向右微移端點 | 62%          | 20／20               | 交疊             |
| 偏左候選         | 約 26%       | 0／20                | 34 px            |
| 偏右候選         | 約 74%       | 0／20                | 38 px            |

間距以 960×540 的定格像素計。兩個偏側候選在換句取樣也維持間距，較低門檻下仍未見細線或暗邊進入人物框。亮部距最近的畫布側邊分別至少 191、188 px。

現行左右微移不足以讓這個置中人物框和字幕完整分離。可保留中央／偏左／偏右為同一模板內的構圖預設候選，再用微移做場景校準。左右兩案都能避開本次人物框，選側要看場景兩側的其他元素。預設錨點與微移可用範圍待實際模型和大字級比較後決定。本輪是固定人物框與離散定格，結果僅涵蓋該框、中字級及本次換句取樣。

## 等寬三區與逐字回放

沿用同一個置中人物框、歌詞和 OBS Browser Source，回放右區、左區及兩側朝中區微移至端點，各取 21 張播放定格和一張跳轉定格。左右區均可見右欄先寫、再接左欄，混語與快速換句期間也維持選定分區。在 960×540 定格上，以無字幕底圖的像素差檢查字、線及暗邊，向中區微移至端點時，右側距中區邊界最少 6 px，左側最少 4 px。結果涵蓋本次中字級及固定人物框取樣。
