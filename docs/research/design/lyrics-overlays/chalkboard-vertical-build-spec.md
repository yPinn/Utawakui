# 黑板直書第一版 Build Spec

[Proposal](chalkboard-vertical.md)保存設計來源與待比較項目，[Output 契約](../../../contracts/output-appearance.md#模板清單)列模板入口與可調項。此頁記錄首版的構圖、同步規則和驗收證據。

## 構圖與資料

`chalkboard-vertical` 使用 1920×1080 Lyrics Browser Source。畫布橫向三等分，預設左區、可切右區，中區留給人物。每頁至多三欄，預留固定寬度。單欄、多欄均對齊同一頂線和右側起筆點，續欄只往左排。粉筆白字與每欄右側的細線屬歌詞層，舞台底色透明。右線從欄頂起，長度為欄高的 85%。

預設頂線在畫布高度 28%，欄高上限 44%。X ±12% 微調受選區邊界限制，Y ±25%。沿用 Open Huninn 與既有字級設定。T0 沒有行級時點時保持透明。

原文換行和判定為分句的中日文半形／全形空白各自起欄。長句沿自然斷點分欄，放得下的拉丁詞組及日文詞幹與縮約尾音保持同欄。超過容量時沿用共用分頁，優先保留每頁 800 ms，時間不足時重新分配整句時段。原文、來源範圍及 cue 時間保留。

## 逐欄同步與動態

同一句拆兩欄就有兩個起筆時間。首欄對準句首，後續欄優先使用欄首對應的 T2 或 T1+ 時間。沒有對應起點時，在鄰近錨點間按字量估算。只有 T1 時以當頁起訖為錨點。已寫出的欄保留在原位。

每欄的文字與右線一起由上往下按字寫入。每欄進場最多 720 ms，且不超過下一起筆或退場前可用時間的 70%。舊段於自己的時段末端退場，窗口最多占本頁時長的 30%。各欄由右往左錯開，通常相差 80 ms，短段按可用時間壓縮。欄內文字由下往上逐字收，右線在同一時段由上往下連續擦除。

換句或分頁先清掉舊段殘留，新段按時接手。同一畫面最多一組歌詞。暫停、跳轉、重連與 reduced motion 直接顯示已到起筆點的欄。間奏退回透明。

## OBS 驗收

- 構圖：置中人物框覆蓋畫面 X 36–64%。早期中央起點的 X 微移端點仍有交疊。改成三等分後，左、右區向中微調至端點的最小間距分別為 4、6 px，以 960×540、中字級的 OBS 取樣計。單至三欄共用固定頂線和右側起點。
- 同步與交接：正式 Browser Source 以 60 fps 回放〈Show〉1:31.160–1:49.890 的 8 句，保留原始 cue。1:46.830 的三欄依序起筆，後兩欄的右線約在句首後 0.7 秒及 1.35 秒可辨識。逐格確認右線上緣往下收。直線與 3 px 微偏差各七次換句均未偵測到新舊字形同幀。
- 待驗收：直線為目前預設，微偏差保留對照。實際作品的可讀性、擦除偏好及不同人物框與畫布配置仍需人工確認。
