# 黑板直書

Working ID 為 `chalkboard-vertical`。2026-11-04 依本次字幕風格討論收錄，源自使用者對ヨルシカ《盗作》系列的構想。此名稱與分鏡皆屬提案。參見[候選索引](README.md)、[共用格式](proposal-template.md)及[產品規格第 7.3 節](../../../spec.md#73-研究候選尚未接受為開發路線)。

首版選定的構圖、設定與實作範圍見[黑板直書第一版 Build Spec](chalkboard-vertical-build-spec.md)。

最新方向把畫面橫向等分成三區，黑板直書預設在左區，可切到右區。兩側都由右欄讀到左欄，欄內從上往下讀。文字與直線按字進出，退場方向維持相反。以下保留初期構圖與分鏡比較。

## 體驗與舞台參考

讓粉筆白字在畫面中央一欄一欄寫出，欄位由右往左排列。每欄右側的細直線與文字同步寫入，退場時分向擦除。相較現行和風直書以右側明朝字組揭示，本款的重點是中央多欄構圖與每欄各自的寫入、擦除。

《前世》約 [1:03:24](https://www.youtube.com/watch?v=Rl1xfaXlrxw&t=3804s) 可見一行文字落在室內插畫中、避開歌手剪影。借用文字和人物的取景關係。粉筆材質、欄序與擦除方向來自使用者描述。參考為已抽看定格的外部影片，未保存影片或截圖作為素材。

## 定格構圖與圖層關係

以 16:9 固定取景，先比較三欄定格。畫面由左至右為「第三欄與其右側細線｜第二欄與其右側細線｜第一欄與其右側細線」。三欄在中央安全框內共用上緣，第一欄先出現。候選做法是在每次換句前依實際欄數排好整組位置，揭示期間固定各欄錨點，避免舊欄因新欄加入而漂移。

| 群組 | 外觀與堆疊                                                                   | 附帶動效                                       |
| ---- | ---------------------------------------------------------------------------- | ---------------------------------------------- |
| 舞台 | OBS 底圖之上可比較透明與局部低反差暗底。中央框以外維持透明                   | 基本版固定，間奏可比較透明或保留暗底           |
| 歌詞 | 粉筆白正文及每欄右側細線。粉筆紋理附在字面，文字與線各有一份限制在本欄的遮罩 | 欄位逐一進場，每欄文字和線可在同一時段各自退場 |

文字與對應細線共用欄位錨點、出入時序與整組位置調整。粉筆紋理強弱及舞台暗底可獨立調整或停用，保留白字、細線與分向退場。基本定格只顯示當前句。舊句只在交接窗短暫保留於新句後方，若同位疊字影響閱讀，另比較縮短交接窗。曲名、讀音與聲部提示待評估。

## 長句、混語與同步

用「夜色亮起」檢查單欄中心與右線。「等到遠處的燈一盞一盞亮起，再把那封信慢慢讀給你聽」先沿語意分為多欄，由右往左讀。「夜が明けるまで，stay with me，陪我走過這條街」比較以完整 Latin 詞組為單位的直書排法。三案共用 16:9 畫布。長句先找自然欄界，再有限縮字，仍超量時比較分頁與可讀回退。最大欄數、最低字級與分頁時機待定。

以 T1 行級 cue 為基本候選，同一來源行拆出的欄位由模板依序揭示。T0 缺少行級時點時比較透明空態。原生 T2 和 T1+ 先沿相同行級構圖，細時間能否改善欄位出場另評估。各欄保有原句與來源範圍的對映。連續數個來源行是否能同時成為一組，保留為後續提案問題。

## 鏡位、換句與播放狀態

預設固定正面取景，換句由欄位揭示把視線從右帶到左。畫布及舞台暗底固定，只有歌詞組內的遮罩動。若中央人物佔位重疊，先比較整組微移與偏側構圖，欄序維持不變。

置中人物框的 OBS 回放已比較現行 X ±12% 與偏左／偏右候選。本次取樣中，兩個微移端點仍有交疊，兩個偏側候選均留有間距。先保留為同模板的構圖預設候選，錨點與微移範圍待定。[置中 VTuber 構圖回放](chalkboard-vertical-build-spec.md#置中-vtuber-構圖回放)

1. 進場。當前句開始，第一欄的字和線同時從上往下淡入，後續各欄依右到左順序做同樣動作。
2. 定格。揭示完成的欄可立即閱讀。句子進入穩定段後，整組固定。
3. 交接。每欄獨立退場，文字由下往上消失（下端先淡出），細線由上往下消失（上端先淡出）。新句由右欄接手。兩組重疊與各欄退場錯開的幅度待比較。
4. 退場。無下一句時完成舊欄退場，再回到透明或暗底候選畫面。

短句可縮短揭示，確保有完整可讀的一拍。暫停保留當前欄位狀態，seek、重連或從隱藏恢復時直接依當前 cue 落位。換曲、無資料及停用時清除舊欄。Reduced motion 可用直接切換或短淡化，保留欄序。

## 可調邊界、可行性與驗收構想

保留中央成組、右至左欄序、白字右線與分向擦除。候選調整為整組位置、字級、欄距、粉筆紋理及暗底。字級、欄距會改變可用容量，需重新量測。微調不可讓細線落到相鄰欄或侵入人物安全區。參數值域待定。

先核對共用直書量測能否沿用，再比較欄級時間軸及各自的文字、直線遮罩。粉筆紋理可先評估自製效果，字型來源、缺字回退及散布條件待查。後續以同一組自製歌詞比較欄位進退場、快速換句、混語、左中右人物佔位、明暗底圖、透明合成及 reduced motion。
