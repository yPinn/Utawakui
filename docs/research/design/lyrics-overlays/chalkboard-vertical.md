# 黑板直書

Working ID 為 `chalkboard-vertical`。構想來自使用者對ヨルシカ《盗作》系列的聯想，首版行為與 OBS 證據見[第一版 Build Spec](chalkboard-vertical-build-spec.md)。

粉筆白字與右側細線依欄寫出，字面保有粉筆顆粒。每欄共用上緣，從固定右上起筆點往左增加欄位。退場時，文字往上收，細線往下收。觀眾可從先寫出的右欄開始讀。

《前世》約 [1:03:24](https://www.youtube.com/watch?v=Rl1xfaXlrxw&t=3804s) 的室內插畫中，文字避開歌手剪影。參考的是文字與人物的取景關係。粉筆材質、欄序及擦除方向來自使用者描述。

| 群組 | 外觀與堆疊                         | 動態及可調方向                               |
| ---- | ---------------------------------- | -------------------------------------------- |
| 歌詞 | 白色粉筆字、每欄右線，位於底圖上方 | 逐欄起筆、分向擦除。可比較粉筆紋理與擦除前緣 |
| 舞台 | 固定正面取景，人物留中區，首版透明 | 局部暗底可獨立試驗                           |

短句看單欄起筆，長句看由右往左接讀，日英混語看完整拉丁詞組及上下邊界。保留直線與微偏差擦除對照，待用實際作品選擇。曲名、讀音、聲部提示與多個來源 cue 是否能組成一組留待評估。
