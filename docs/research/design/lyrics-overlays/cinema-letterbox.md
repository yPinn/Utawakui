## 定格構圖與取景

以原提案的 1920×1080 畫布與 2.39:1 中央透明視窗作比較基準，對稱遮幅各約 138px。這些尺寸用於構圖比較，實際擷取規格待定。字幕在下方黑邊中央，預留黑邊上下內距。上方黑邊留白，中央透明區保留演出主體。

| 定格區域   | 比較基準                                                             |
| ---------- | -------------------------------------------------------------------- |
| 上方黑邊   | 不透明純黑，保留留白                                                 |
| 中央透明區 | OBS 底圖透出，表演主體與重要構圖元素放在此區                         |
| 下方黑邊   | 當前歌詞置中。以「等最後一盞燈亮起」比較單行位置、兩行容量與黑邊內距 |

採固定鏡位作比較基準，遮幅以 Overlay 圖層覆蓋 OBS 底圖上下兩側。攝影機位置、縮放與取景仍由 OBS 場景決定。預覽可比較是否需要編輯專用的中央安全區提示。

## 歌詞與舞台群組

| 群組 | 外觀                                         | 附帶動效與堆疊                                                 |
| ---- | -------------------------------------------- | -------------------------------------------------------------- |
| 歌詞 | 下方黑邊上的當前句，候選為淺色正文、水平置中 | 換句輕微淡化，字的位置與黑邊高度保持穩定。正文在遮幅上方       |
| 舞台 | 上下成對的純黑遮幅及中央透明區               | 比較一開始便就位與開場短促收幅。收幅完成後定住，換句不帶動黑邊 |

由底到頂為 OBS 底圖、上下黑邊、下方歌詞。兩條黑邊成組，維持同一個中央視窗。歌詞可獨立進退場，版位與字區沿下方黑邊的可用範圍。遮幅淡出時，歌詞須先退出或與遮幅一起退出，以維持文字對比。可比較開場收幅的獨立開關，關閉時直接顯示穩定的遮幅。若要提供整組遮幅的開關，須先定義關閉後字幕的承載方式。

## 換句分鏡與播放狀態

| 分鏡       | 觸發點                 | 歌詞組                                                     | 舞台組                                         |
| ---------- | ---------------------- | ---------------------------------------------------------- | ---------------------------------------------- |
| 進場       | 開始演出或首句到達     | 當前句於既定位置出現。若採開場收幅，保留足以閱讀的黑邊空間 | 比較直接就位與短促收幅                         |
| 定格       | 當前句可讀             | 一至兩行置中，文字停穩                                     | 黑邊維持同一高度，中央保留演出影像             |
| 交接       | 下一句開始             | 輕微淡化交接，以一個可讀句子為主                           | 遮幅維持構圖                                   |
| 空段與退場 | 字幕區間結束且無接續句 | 清空歌詞                                                   | 比較整首歌維持遮幅與在明確段落邊界退去兩種方向 |

間奏比較先沿同一套字幕節奏。保留遮幅能讓電影構圖延續，段落退幅則把空間交還給演出畫面。退幅的觸發資料、短空白與長間奏的判準待定。短句優先落在可讀定格，暫停保留當前句。Seek、換曲與重連依當前資料落位。Reduced motion 可採直接就位與靜態交接。

## 屬性與獨立預設候選

比較用預設先看 2.39:1、固定遮幅與當前句淡化交接。字型、字級、文字配色、黑邊內距、開場收幅及間奏是否保留遮幅均待評估。原討論曾提出 2.00:1 作具名變體。相同 1920×1080 畫布下，2.00:1 的對稱遮幅各約 60px，需重新驗證字幕容量。若比例或退幅策略改變整體取景與觀看節奏，可比較獨立預設。相同取景下的淡化幅度優先評估為可調項。

## 待補充與驗收構想

- 比較黑邊一開始便就位與開場短促收幅，再確認空段落是否維持電影構圖。
- 以相同底圖確認中央安全區、遮幅邊緣及人物取景，並比較歌詞與遮幅各自退場的畫面。
- 驗兩行長句、多語字型與 fallback 的閱讀容量。若比較 2.00:1，另記錄可容納的字級與行數。
- 用短句、間奏、seek、快速換曲及 reduced motion 對照分鏡，記錄歌詞可讀的時機與舞台狀態。
