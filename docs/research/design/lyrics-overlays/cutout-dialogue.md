# 剪報對白

Working ID 為 `cutout-dialogue`。2026-11-04 依新版格式整理第二款候選。以下是供比較的構圖與演出方向，等待使用者補充。參見[候選索引](README.md)、[共用格式](proposal-template.md)及[產品規格第 7.3 節](../../../spec.md#73-研究候選尚未接受為開發路線)。

## 意圖與參考

2026-10-12 08:03（Asia/Taipei），使用者提出 Persona 5 視覺對話框與圖片參考。原附件目前無可讀副本，構圖沿聊天的文字描述發展。參見原提案的[字型介紹一](https://goodfreefonts.com/9457/)及[字型介紹二](https://goodfreefonts.com/10384/)。

當時核心描述是讓當前歌詞像被選中的回答切入畫面。相對既有 `manga-frame` 的直式漫畫對話框，本候選偏橫向回覆卡與平面圖形衝擊。

## 定格構圖與取景

以 16:9 作比較畫布。紅黑白平塗、斜切紙面與偏移黑邊構成橫向回覆卡，文字基線維持水平。定格先以「今晚，就從這裡開始」比較字形、卡面邊緣與人物留白。當前句是唯一可讀的回覆。肖像區留給直播主體，或以原創斬切圖形承接視線。原創輪廓與構圖取自剪貼、斜切及黑白反轉等手法。

| 定格區域           | 比較基準                                                   |
| ------------------ | ---------------------------------------------------------- |
| 畫面中央與上方     | 直播主體安全區，OBS 底圖透出                               |
| 下方偏一側         | 橫向斜切回覆卡。字區留在紙面較寬的位置，避開兩端斜角       |
| 卡片外緣及畫面角落 | 卡片以偏移黑邊形成層次。遠離主體的角落可留給獨立舞台斬切面 |

以固定鏡位作比較基準。回覆卡可比較下方偏一側與下方橫跨兩種版位，使用同一組歌詞和 OBS 底圖。前者讓回覆像從舞台一側切入，後者提供更多正文寬度。實際左右側、紙面寬度及主體安全區待定。進場移動由卡片群組承擔，OBS 攝影機與底圖由場景控制。

## 歌詞與舞台群組

| 群組 | 外觀                                         | 附帶動效與堆疊                                                                   |
| ---- | -------------------------------------------- | -------------------------------------------------------------------------------- |
| 歌詞 | 當前句、斜切紙面、偏移黑邊及卡片上的紅色標記 | 紙面、文字和黑邊隨同一張卡進退場。斜切揭示的遮罩作用於整張卡，主字形位於紙面上方 |
| 舞台 | 透明留白與候選抽象紅黑斬切面                 | 可比較靜態斬切面與一次短促的側邊掃過。圖形位於卡片後方並避開主體安全區           |

由底到頂的比較順序為 OBS 底圖、可選舞台斬切面、偏移黑邊、卡片紙面與主字形。貼著卡片移動的紅色標記歸歌詞組。獨立於卡片、沿畫面邊角掃過的紅色圖形歸舞台組。若比較前景斬切，先留出當前句的可讀區。

舞台斬切面及其動效可各自評估獨立開關。關閉後保留同一張可讀卡片與換句時機。卡片、文字及進場遮罩則成組保留。間奏可比較全透明與保留靜態舞台斬切面兩種畫面。

## 換句分鏡與播放狀態

先用相同定格比較兩種交接。`paper-snap` 讓整張卡短促切入並落位，重點是紙片的重量感。`slash-in` 用斜切遮罩迅速揭示新卡，重點是視線沿斜線進入。兩版都把黑白反轉限制在卡片範圍內作候選，並比較字何時完整可讀。是否獨立為預設，取決於兩版是否形成不同的閱讀節奏與完整演出。

| 分鏡 | 觸發點                 | 歌詞組                                                     | 舞台組                               |
| ---- | ---------------------- | ---------------------------------------------------------- | ------------------------------------ |
| 進場 | 首句開始               | 新卡短促切入或斜切揭示，正文在進場早段完整可讀             | 留出主體空間，舞台斬切面作可選陪襯   |
| 定格 | 進場落定               | 卡片保持靜止，正文停在水平閱讀線                           | 舞台保持低顯著度                     |
| 交接 | 下一句開始             | 舊卡交棒，新卡接手閱讀焦點。比較整卡切換與斜切揭示的連續性 | 舞台可保持靜止，或用一次邊側動效帶過 |
| 退場 | 字幕區間結束且無接續句 | 卡片及其附帶效果一起收回                                   | 比較間奏全透明或保留靜態舞台形狀     |

短句優先落在可讀定格。暫停保留當前句，seek、換曲、重連或恢復時依當前資料落位。Reduced motion 以靜態卡片交接，保留斜切輪廓與色彩關係。確切時長、進場角度及色彩反轉幅度待比較。

## 長句、混語與同步

| 自製歌詞                                 | 比較目標                                                             |
| ---------------------------------------- | -------------------------------------------------------------------- |
| 今晚，就從這裡開始                       | 比較單行卡片的構圖，以及短句是否適合剪貼字形                         |
| 即使燈光熄滅，我們也要沿著這條街走到天亮 | 沿標點比較兩行。量出斜角吃掉的可用寬度，確認末字與描邊留在紙面安全區 |
| まだ間に合う，turn it up，讓這一夜繼續   | 保留 Latin 詞組與閱讀順序，比較字型 fallback 後的字寬和基線          |

先以完整歌詞可讀為準，超出容量時比較斷行、有限縮字與分頁。剪貼字形可先用在短句或一小段強調，長句正文採清楚的字型候選。以行級換句作分鏡比較假設，T0 的空態或靜態呈現，以及 T2／T1+、聲部、讀音的用途均待確認。分行與分頁保留原文及來源時間。

## 印刷色帶定格

2026-11-12 的 IMG_1833 提供另一種焦點做法。借用平直曲名帶的起線和黑白反相，與上方原有的斜切回覆卡並排比較。沿用 16:9 舞台及同一組自製歌詞，底圖、人物位置和字幕字高一致。 [演出印刷物風格提案](../performance-ephemera-proposal.md#5-output-歌詞印刷色帶)

- 首版固定於舞台下方一側，當前句用墨黑帶和暖白字，帶尾留一小截朱紅。紙帶寬度隨字區變化，端點可輕微錯位，文字保持同一水平起線。外圍透明。
- 先放一行，長句沿自然語意折成兩行。兩行可各用一條紙帶，起線對齊，末端各自收齊。日文與英文混排優先保留完整詞組。可用寬度及兩行仍放不下時的分頁門檻待定。
- 換句先比靜態交接與整帶短促揭示。文字和色帶同步，短句一開始即可讀。先以 T1 行級定格比較，時間資料與播放狀態沿用本案前述假設。
- 先比較固定左下與固定右下，再看明、暗和細節多的 OBS 場景。帶尾色可作獨立開關候選，關閉時保留完整正文、紙帶和換句行為。

## 待補充與驗收構想

- 比較偏一側與橫跨下方的版位，確認希望保留的人物空間。
- 比較整卡切入與斜切揭示，確認哪個瞬間最像「被選中的回答」。
- 決定舞台斬切面是固定裝飾、獨立換句動效，或保持透明。驗證關閉舞台後的卡片可讀性。
- 以長句、混語、缺字、明暗與複雜背景比較排版及透明邊緣。連同快速換句、seek、黑白反轉與 reduced motion 一起驗收。
