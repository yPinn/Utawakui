# 圓角視窗直書

Working ID 為 `framed-vertical`。2026-11-25 依使用者附圖與[《青100色》片頭](https://www.youtube.com/watch?v=XzpONOLtpr8)提出。與[寬銀幕字幕](cinema-letterbox.md)同屬以遮罩構圖的候選。影格時間以該連結的播放器位置為準。影片與附圖僅作分析來源。

開發版可從 Output 的「電影畫幅」選取「圓角視窗」，擷取尺寸為 1920×1080。試作採固定透窗、左側留黑、右側一至兩欄整組換句。次欄靠近下緣，兩欄共享行級 cue。字型、字級和文字色沿用工作臺控制，超長字幕依共用擬合分頁。正式版採用狀態見[產品規格](../../../spec.md)。

## 關鍵影格

| 播放位置           | 畫面和文字                                                                                                                                         |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 約 5.00–5.40 秒    | 畫面維持上下黑邊。片名先以黑色直書出現在教室的窗戶一側，切近景時局部文字隨畫面失焦。                                                               |
| 約 6.15、6.95 秒   | 白色畫面內，橫排片名字形先呈淡黃、橘紅光色，之後穩定為深色。主字略有粗細落差、短收筆及不均勻的斜擦紋。部分漢字上有小讀音，下面是字距寬的英文副標。 |
| 約 8.28、8.32 秒   | 前一個取樣仍是白底橫排字卡，下一個取樣已是圓角視窗與兩側完整文字。視窗直接就位，側邊字幕以整組出現。                                               |
| 約 8.55、15.07 秒  | 視窗內畫面和前景持續動作，右側兩欄仍在固定位置。正文筆畫偏細而有手寫節奏，先讀右欄，左欄起點下移約四成畫高。                                       |
| 約 16.13、16.22 秒 | 翻頁時側欄先清空，再整組出現下一句和下一組左側資訊。中央窗在過場中維持形狀。                                                                       |

右側白色直書是歌詞的主要參考。橫排片名的黑色斜擦紋與光色顯影屬片頭字卡做法，適合另行比較，與側欄的整組交接有不同節奏。影片只取關鍵段落與切換附近的相鄰畫格。

## 構圖與欄位

以 1920×1080 畫布起稿。依附圖估算，中央透窗最大寬約 70%、高約 94%，中心約 4:3。四條邊微弧，四角平順收圓。窗外為不透明黑色，窗內用透明度透出 OBS 場景。中央 60% 寬作為工作臺人物安全區的比較起點。OBS 決定人物圖層、鏡位與縮放。

| 區域 | 提案                                                                                           |
| ---- | ---------------------------------------------------------------------------------------------- |
| 中央 | 用靜態向量路徑定義開窗，畫面切換時維持取景。底層來源在開口處顯示原本的比例和位置。             |
| 右側 | 一到兩欄直書，由右至左閱讀，第二欄依片語另起。先比較兩欄錯高與同頂起筆，長句優先守住安全邊界。 |
| 左側 | 預設留黑。可選擇小字顯示曲名或演唱者，版位與歌詞各自固定。                                     |

文字用帶手寫筆勢的淺色正體，日文先比較 Klee One SemiBold，繁中先比較辰宇落雁體與清楚的備援字型。純英文或連續拉丁詞組比較緊湊的橫排欄位，標點與 grapheme 沿用共用斷行。測試「把那封信留在窗邊」與「夜が明けるまで，stay with me，沿著窗邊等最後一盞燈亮起」。先在標點或片語邊界分欄，兩欄超量時使用有限縮字與分頁，保留來源文字和時間。字級下限、韓文用字與左欄容量待定。

## 歌詞與遮罩動態

| 狀態             | 歌詞                                                      | 遮罩                                         |
| ---------------- | --------------------------------------------------------- | -------------------------------------------- |
| 首個有效 cue     | 整組到位。比較硬切和至多 80 ms 的淡入。                   | 直接顯示固定圓角窗。                         |
| 停留與換句       | 左右位置固定。相鄰 cue 以原邊界交接，同幀只顯示一組。     | 保持固定形狀和黑邊對比。                     |
| 字幕清空         | 整組清除。遇到連續短句優先直接替換。                      | 間奏保留取景。未選曲、停用與斷線時回到透明。 |
| 暫停、跳轉、重連 | 按目前 cue 直接顯示相應狀態；減少動態時用相同的靜態狀態。 | 直接恢復當前畫幅。                           |

行級 T1 即可呈現。T2 與 T1+ 可用來源時間對齊分頁，首版比較整組換句。T0 保留播放中的取景並清空同步字幕。換曲重新取得當前狀態。

## 接入建議和驗收

與寬銀幕共用「電影畫幅」的 Gallery 入口、固定遮罩及字幕生命週期。圓角視窗使用自己的側欄擬合與整句切換，預設為這個模板的第一種畫幅。

靜態 SVG 偶奇填滿路徑由最大畫布外框減去中央開口，DOM/CSS 負責歌詞排版。GSAP 僅在採用淡化時控制整組透明度，從 host 播放時間取樣並於換曲或換模板時清理。以按需模板接入，Workbench 和正式 Browser Source 用同一套幾何。參照[動態與渲染契約](../../../contracts/output-motion-rendering.md)及[動畫交付規格](../../../contracts/output-animation-handoff.md)。

以淺色、深色與複雜場景確認圓角邊緣的 alpha、人物安全區、兩欄起筆點、字幕清空和遮罩留存。在正式 Browser Source 檢查短句、長句、混語、跳轉、重連及減少動態。展開動效和字卡顯影保留為後續比較項。
