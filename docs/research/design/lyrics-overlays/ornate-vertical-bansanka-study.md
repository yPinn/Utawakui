# 〈晩餐歌〉MV 斷句與漢字標註

2026-11-22。以 tuki. [官方音樂錄影帶](https://www.youtube.com/watch?v=oZpYEEcvu5I)（3:40）內嵌字幕為畫面來源。[官方頁面](https://tuki-official.net/movies/95869)收錄同一支影片。逐段暫停核對 42 個有詞切片，另記片頭、間奏與片尾。表中時間是可回看的 MV 取樣點，精度約一秒。曲庫現有逐行歌詞只用於找段落和跑模板分欄，起點與畫面上字可能有落差。

「卡」指同一構圖中共同保留的一組字幕。「欄」由右至左計；所有欄一起位於畫面左側時，仍按組內右至左計。欄長只計可讀文字，不計來源分隔空白。漢字欄記錄可辨認的放大、筆鋒、描邊、疊影和上字順序。歌詞畫格中未辨識到持續與個別漢字對齊的假名讀音。片頭橫排歌名可見羅馬字，屬於標題設計。

### 斷句、構圖與上字

1. 保留作者分隔或已對時的片語邊界。句內短呼告、前置成分及「受詞＋動作」允許以短欄呈現，後續再按詞界和可用欄高分配。寬度不足時避免拆散數量詞、連續漢字詞、片假名借詞與緊接的語尾。
2. 以「顯示在哪張卡」和「卡內在哪一欄」記錄切片。切片 35、37 的文字切點相同，前欄去留不同。播放器曲目時間、來源字元範圍與版面分欄仍各有用途。
3. 卡內允許沿同一側排列或在構圖有保留區時跨左右。現版每欄下移 1.25 em 適合一般雙欄。三欄在 00:50 和 00:59 的中欄反而最低，逐欄累加的位移只適合作為預設值。
4. 以語意片段的入場點讓續欄出現，前欄保留原位。00:10–00:13、00:15–00:17 有「焦點漢字先定位、假名補入」的證據，適合做單一字幕卡可選的進場方式。預設逐字仍以實際播放可讀性為準。
