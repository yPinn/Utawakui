2026-11-22。沿用已登錄的和風直書 `ornate-vertical`。使用者說明此款最初以 tuki.〈晩餐歌〉為參考，後來納入其他構圖相近的直書。這次先找回漢字與假名的大小節奏，再評估〈スピカ〉的逐字留欄能否沿用同一模板。現版行為見 [Output 外觀契約](../../../contracts/output-appearance.md#歌詞模板呈現)。

## 第一輪樣張

比較三種字形處理，固定 1920×1080、字族、整體字級設定、錨點、背景和同一句歌詞。先以現版預設字族 Hina Mincho 對照，確認比例後再用 GenEi Antique 和缺字回退覆蓋測試。

第一輪[比較原型](../../../../prototypes/ornate-vertical/index.html)沿用正式和風直書渲染。執行 `node prototypes/ornate-vertical/build.mjs` 可產生離線比較頁，並切換樣本、背景或放大單張。

| 樣張       | 比較內容                               | 試排起點                                         |
| ---------- | -------------------------------------- | ------------------------------------------------ |
| A 現版     | 同字級直書，保留現有分欄及強調         | 現版設定                                         |
| B 漢字強調 | 漢字較大、假名較小，沿同一欄軸排列     | 漢字約基準字級的 125%，假名約 80%                |
| C 焦點拉長 | 沿用 B，在一個焦點漢字的字面加縱向延展 | 先試焦點字額外拉高約 18%，按實際字面高度預留字位 |

比例是樣張起點。發布倍率、字級下限、焦點字的選取頻率與是否採用 C，在看過短句與長句後決定。第一輪使用事先標記的樣張焦點字；正式版再用現有關鍵字候選評估能否穩定自動選取。若需求指向單筆延長，須另驗少數自製字形與原字缺失時的回退。

B 的大小字可作為一種字體排列方式。字距在漢字相鄰處加基準字級的 8%，漢字與假名交界加 12%。連續假名、拉丁詞、標點周圍與欄尾沿用原有字距。比較頁的「微調字距」可切換效果，B、C 共用此規則。

## 第二輪動態候選

本輪採〈スピカ〉的逐字落位。49.57 秒可見右欄，50.15 秒左欄加入第一個漢字，50.35 秒左欄再加一字，右欄字位保持不動。作品沿用同頁的欄內及欄間順序。試作由右往左逐欄補字，使用自己的淡入時長及換頁規則。

字形定案後，以同一組樣張比較現版換句與「逐字留欄」。測試開始時為第一欄和後續欄保留固定字位，漢字與假名各自進場，標點依附相鄰可讀單位，拉丁詞以詞為入場單位。

| 階段 | 畫面                                                                     |
| ---- | ------------------------------------------------------------------------ |
| 進場 | 到第一句起點，右欄第一字可讀，後續字依時窗向下加入。                     |
| 接欄 | 下一片語有時間點時，在既定欄位向左開始。右側已顯示的字原位保留。         |
| 留欄 | 當前頁內的列按閱讀順序累積。長句依可用字區分欄，到頁面容量就交接。       |
| 退場 | 同頁留欄維持到交接。下一頁或段落開始時整組替換，遇到間奏依既有空態收起。 |

- T0 使用靜態呈現與既有空態。T1 依句內可用時間分配揭示，短句必要時以片語同時落位，保證換句前能讀完整句。
- 有來源對映的原生 T2 可採用其單位起點。已套用的 T1+ 依現有驗證與對映使用估計起點。只有片語時間時，片語內的逐字仍屬呈現節奏。
- 暫停應停在對應字位，跳播、重連或恢復可見直接重建當前頁狀態。減少動態時呈現完整當前片語。換曲清空前一曲留下的欄位。

## 可調邊界與驗收

正式模板已將第一輪 B 的字級與留白接進「字體排列」，可在「等大」和「大小字」間切換。既有設定預設等大。換句動態另以「逐句／逐字留欄」為候選，在樣張確認後再決定控制欄位和值域。

實作評估沿用既有分字、分欄、字型測量與 Output 渲染路徑。字級和字位在佈局時計算，焦點字可用內層 DOM transform 呈現。歌曲時鐘決定逐字狀態，GSAP 只負責短入場，動畫使用透明度或位移。參見[動態與渲染契約](../../../contracts/output-motion-rendering.md)。

樣張以 1920×1080 預覽和 OBS 驗深淺底／複雜底、左右人物、字級端點與長句安全區，動態補驗短句、空段、暫停、跳播與減少動態。右側人物的既有交疊案例見[人物佔位回看](production-vtuber-placement-review.md#和風直書的實際錨點與偏移)。

## 漢字單筆延伸候選

### 參考畫格與動畫樣張

〈晩餐歌〉在約 00:21.84 可見「人」的撇帶有向左的長弧。約 01:27.18 與 01:27.97 之間，「分」與「合」的長筆鋒已呈現，後方假名繼續加入。把固定長筆形和逐字入場搭配，可重現這段可見的字形效果。原片使用的字型與製作方法仍待製作資料確認。

比較頁的「文字動態」使用同一句「夜が明けるまで、帰り道を照らす灯」、Hina Mincho、大小字與雙欄 0.5 em 欄距。

| 樣張     | 做法                                                        | 比較重點                             |
| -------- | ----------------------------------------------------------- | ------------------------------------ |
| 逐字淡入 | 共用正式模板的逐字入場                                      | 檢查完整字形的可讀性與欄間交接       |
| 整字拉長 | 「灯」入場後，於固定字位把內層字面沿垂直方向拉到 118%       | 左右部件一起變形，筆畫比例也跟著改變 |
| 單筆延伸 | 「灯」入場後，修改同字型的 SVG 輪廓，按畫面留白延長右部豎鉤 | 左側火部保持原比例，留意尾鉤與字位   |

接近 MV 的做法是先用已延筆的字形逐字淡入。若需要更明顯的動態，焦點字入場後再短暫延展一筆。比較頁用 0.42 秒播放後一種，沿用既有 dev 試作的「灯」輪廓。逐字時間仍由既有揭示排程控制，筆鋒的字形資料對應到特定字型和字。

### 既有 dev 試作

開發工作臺已接入第一個樣字。選和風直書與華麗明朝（Hina Mincho），沒有載入歌曲時會循環播放「帰り道の灯」。實曲以欄尾第一個合格的「灯」為單筆焦點，依歌詞頁的播放位置推進。首版延伸最多 0.32 em，靠近畫面底部會縮短，餘量或句長不足則使用原字。此試作由 dev 工作臺開啟。

先以 Hina Mincho 的「灯」和「夜」做兩個樣字。「灯」試右部豎鉤，沿直段往下拉並帶著鉤尖移動。「夜」試末筆捺，順著筆畫方向斜向延長，保留筆鋒逐漸收尖的形狀。每句先挑一個焦點字，字先完成入場，再延展單筆並停在末幀，隨當句退場。

從實際字型輪廓對齊 SVG 覆層，為每個樣字記錄筆畫接點、延伸方向、最大長度和末端形狀。豎鉤保留起點，拉長中段並移動完整鉤尖。斜捺用對應的輪廓控制點延伸近筆鋒的區段。以零進度時與原字重合為驗收起點。替換所選筆畫時，基底保留其餘輪廓，兩部分合成後共用正文的字色與陰影，避免接縫或雙重筆畫。

以字形盒、下一字的留白、鄰欄和畫面安全區預先決定最大延伸量。留白不足時縮短，過短則保持原字。動畫只更新焦點字筆畫的 SVG 幾何，字位與欄高在入場前確定。使用 GSAP 驅動短動畫，段落重點色沿用同一字的墨色。原歌詞與無障礙標籤保留文字。其他字型或沒有對應筆畫資料的字維持正常顯示。

試作需在工作臺與 OBS 對照入場、延展、末幀三個時間點。驗收字形接點無縫、筆鋒形狀清楚、相鄰字位穩定。短句及緊密多欄需呈現完整可讀的字。暫停保留進度，跳播及重連按當前播放位置決定顯示狀態，減少動態時直接顯示原字。
