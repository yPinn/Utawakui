# 五款正式字幕的 VTuber 佔位回看

2026-11-04。回填五款正式字幕的構圖與位置限制，先比較歷史定格，再用正式 Browser Source 回放。錨點微調、構圖預設與 P5 配置皆為研究候選。現行設定與配置規劃分別由外觀契約與 ADR 持有。[Output 外觀契約](../../../contracts/output-appearance.md) · [ADR 0027](../../../adr/0027-output-template-elements-and-property-workspace.md#layout-modes)

## 比較方式與證據

使用 2026-10-20 F4 的五張 `showcase-t1-v1` 可見 Electron 定格。每款共用合成日文歌詞、預設外觀、暫停第 5 秒與 reduced motion。CSS 視窗為 1920×1080，擷取圖為 1440×810。以畫布比例在同一高度套用三個矩形，代表同一個人物放在不同位置。矩形是本輪的人物活動範圍假設，實際 OBS 佔位會依頭飾、手勢與取景而變。[F4 擷取方式](../../../operations/output-appearance-acceptance.md#f4-隔離-capture-重跑)

| 左       | 4–32%    | 18–96%   |
| 中       | 36–64%   | 18–96%   |

## 正式 OBS Browser Source 回放

使用 OBS 32.2.2 的隔離 portable 場景，Browser Source 載入當前工作樹 `4db3c0c0` 的正式 `/overlay/lyrics`。同一個本機 Output server 以既有契約發布合成 T1 歌詞與播放時鐘。OBS 場景只含底色、人物佔位框和字幕來源。來源與畫布均為 1920×1080，擷取為 960×540。每側另外擷取隱藏字幕的基準畫面，以 RGB 色道差 12 定位字幕及舞台元素在人物框上的合成差異。框與真人遮擋程度仍需用實際演出場景確認。

五模板各回放左、中、右，共 15 組。每組取 17 張播放畫面，再取一張跳至混語句的定格。合成歌詞包含首句、長日文句、中日英韓混語句、連續短句與空段。動態擷取保留每次截圖請求的起訖，以下時點為預定取樣時間。此輪用離散畫面核對交接與邊界，逐幀時序及效能仍待另驗。和風直書另以右側人物測 7 組錨點／偏移，每組取短句、長句、混語時段 3 張。

長混語句的若干取樣只顯示當下片段，因此另用短混語句「夜に go now 走吧」補拍 15 張定格。補拍時 HEAD 為 `6ab79ab3`，15 個已追蹤的 Output 來源檔 hash 與主回放一致。首輪補拍有一張來源就緒前的空白，以下採暖機後 15 張重拍。五款都看見三種文字在同一畫面。有效字幕與位置擷取共 306 張，另有各輪的人物框基準圖。

短混語定格中，經典字幕的當前句進入左與中框，預告句進入右框。躍動字幕以中央交疊最多，較寬的同一列也碰到左右框內緣。和風直書及分格對白這句落在右側。舞台字幕在左框內有正文，中央及右框的交疊來自曲名卡。這些定格確認混排的實際佔位。長混語句的全部片段及語種覆蓋仍需另行查核。

### 和風直書的實際錨點與偏移

右側人物框仍採 X 68–96%、Y 18–96%。七組為右上、右中、右下、右中 Y −25%、右中 Y +25%、右中 X −12% 與右中 X +12%。每組取 0.75、3.00、5.70 秒三張暫停定格。

- **局部微調**。右上或 Y −25% 能改變交疊的高度。X −12% 會把欄往內移，但在這個寬人物框仍有交疊。
- **完整右側佔位**。本次七組中沒有找到三個時點都完整可見且避開右框的配置。X +12% 的三張畫面沒有可見文字。右下及 Y +25% 在長句取樣也各有一張空白，混語取樣則觸及畫布下緣。這些取樣保留為位置驗收證據，空白不計為避讓成功。
- **下一個比較**。右側人物只碰到欄的一小段，可先試錨點與偏移並檢查可見範圍。這次右側框的尺寸適合先比較另一側直書的整套構圖。仍需改變欄高和分欄容量時才評估 P5。

## 各款構圖回填與調整方向

### 經典字幕

下方兩列呈左右錯位，第一列靠左、第二列靠右。當前與預告批次沿既定列位交替，倒數和掃色綁定各列。短句可在中央留空，長句可從兩側延伸向中央。換位時要一起檢查兩列、倒數、描邊與未唱／已唱色，不單獨拖動其中一列。正式版目前沒有公開位置欄位。[雙列樣式與掃色](../../../../overlay/lyrics/lyrics.css) · [KTV 批次與交接](../../../contracts/output-runtime.md#browser-source-頁面生命週期)

**構圖預設優先。** 中央人物可先沿用現有雙列，確認長句會不會伸進人物區。靠側人物可比較把完整雙列收進另一側的構圖，保留兩列的辨識順序及倒數。若縮窄後需要重算每列容量和批次分割，再評估 P5 的雙列群組框與容器量測。

### 躍動字幕

一列正文位於底部中央。字形與多層材質、描邊及位移共用視覺中心，較長內容或換句過場可能向左右外擴。現行字級與材質可選，位置與可用寬度未公開。評估位置時以整個文字與效果群組的外框為準。[躍動字幕呈現](../../../contracts/output-appearance.md#歌詞模板呈現) · [換句動效](../../../../overlay/lyrics/kineticPop.mjs)

**有界錨點候選。** 靠側人物搭配短句時，先保留底部置中。中央人物只碰到文字下緣，且上方有足夠空間時，可評估新增保留水平置中的垂直錨點與微調。若需將長句移到另一側並限制它的寬度，再比較側邊構圖預設。P5 要等側邊版確實需要容器內重排時再評估。

### 和風直書

預設右中，現行九宮格開放右上、右中、右下。另有 X ±12%、Y ±25% 微調。當前句可用至多兩欄，欄序與揭示分組固定。新舊句換句時同位交接，預留兩份畫面外框的聯集，並檢查兩欄時向內側增加的寬度。[外觀欄位](../../../contracts/output-appearance.md#欄位與分級) · [右側欄位配置](../../../../overlay/lyrics/ornateVertical.mjs)

**現有九宮格加微調適合局部避讓。** 左或中間人物可先沿用右欄。右側人物若只碰到欄的一小段，可在現有範圍內比較上移或下移，並檢查畫布邊界。人物長時間占滿右側時，優先比較左側直書的構圖變體，保留文字與欄序。若要調的是直欄可用高度及分欄容量，再考慮 P5。

### 舞台字幕

字幕固定在左下，開場曲名卡在右下，品牌及頻道標記各在上方。歌詞分行與分頁受字幕框寬度限制。曲名卡在播放 4 至 8 秒的時窗可見，進場從右側滑入。人物偏左先檢查長句及字幕換頁，偏右要看卡片完整進退場，置中則核對卡片內側與人物肩線。正式版目前無位置欄位。[舞台字幕樣式](../../../../overlay/lyrics/lyrics.css) · [開場卡動效](../../../../overlay/lyrics/liveStage.mjs)

**先比較整體構圖，再優先評估 P5 字幕框。** 若要為靠左人物把字幕移到右側，須一起安排開場曲名卡，保留上方標記的相對位置。若驗證後仍需要依場景調整字幕寬高，字幕框是五款中最清楚的 P5 候選。它要重算分行、分頁及溢位，並維持與開場卡的分工。

### 分格對白

對話框可出現在左右，框數、來源句與框型會影響落點。定格中的兩框分處兩側。長句、讀音和框尾共同占用空間，換句時舊框可在退場層短暫保留。正式版目前無位置欄位。以整套對話框舞台和新舊框聯集作比較。[對話框配置](../../../../shared/presentation/mangaFrameContract.mjs) · [換句退場層](../../../contracts/output-runtime.md#browser-source-頁面生命週期)

**構圖預設優先。** 中央人物可先驗現有雙側配置。人物長時間站在一側時，候選是將對話框重新編排到可用的另一側，並一起處理框尾指向、框序、讀音與長句容量。九宮格移動單個對話框難以維持整套分鏡。P5 先保留為可調整整組框域的後續選項。

## Workbench 與位置控制的候選邊界

Workbench 已有置中的人物示意與顯示開關。左、中、右比較可優先沿用這個輔助預覽。人物框記錄場景中的預估佔位，模板的安全區則約束畫面允許擺放字幕的位置。兩者可以在預覽中疊看。若要從佔位推導實際輸出版型，另選模板支援的構圖預設。[現行人物示意](../../../contracts/output-runtime.md#browser-source-頁面生命週期) · [示意圖樣式](../../../../overlay/lyrics/lyrics.css)

九宮格繼續表示模板允許的錨點。若既有外框可完整移入可用區，用錨點與有界偏移比較。若人物位置改變連帶影響多個圖層、閱讀順序或交接方向，先用構圖預設驗證。若需要改變字幕容器的寬高與排版結果，再進 P5 評估拖曳、數值欄位、容器量測與溢位規則。[ADR 0027 的配置模式與階段](../../../adr/0027-output-template-elements-and-property-workspace.md#phases)

依本輪回放先保留和風的局部微調方向，並比較右側人物的對側構圖。經典字幕與分格對白先比較成組預設，躍動字幕先驗垂直錨點能處理的局部避讓及長句需要的寬度，舞台字幕先以字幕與曲名卡的整套構圖驗證 P5 字幕框的必要性。各候選至少覆核長句、混語、快速交接及人物活動邊界，再決定開放的調整粒度。
