# 演出印刷物風格提案

2026-11-12。第一輪依序確認場次月曆、Folder 郵票與票根，再比較三個 Output 畫面。構圖、數值與選項都是樣張起始設定，採用狀態見[產品規格](../../spec.md)。

共用視覺以暖白紙、墨黑字、局部單色印墨為基底。郵票用連續齒孔，票根用半圓缺口與打孔線，收據用窄幅紙與橫向虛線。文字維持水平起線，錯位、撕邊和陰影集中在物件外緣。樣張先用紙白 `#F3EFE5`、墨黑 `#211F1B`、鈷藍 `#2449D8`。朱紅作為對照色，實際配色待比稿。

## 1. 場次月曆

### 入口與閱讀順序

從曲庫的「場次紀錄」進入月曆。月曆負責找日期，日期下的場次列負責排序。點選時，有連結歌單就開啟歌單，無連結就展開場次紀錄。歌單 Folder 保留「本場演出」便條，作為開啟該場明細的捷徑。 [現行封存與入口](../../contracts/performance-session-preparation.md#紀錄頁封存與雙匯出)

- 曲庫側欄固定保留「場次紀錄」。已確認收錄所有封存場次，包含已連結歌單、只含手動項目或標記的紀錄。月曆選定日期後可展開單場，清單和場名搜尋可跨月份查閱。 [採用行為](../../contracts/performance-session-preparation.md#紀錄頁封存與雙匯出)
- 依本機日期取首筆紀錄時間，跨午夜的單場放在首筆日期。舊場缺首筆時間時用保存日期，列表以「保存」標出時間來源。同日由早到晚，以場次識別穩定打破時間並列。進入明細後沿用該場原有曲目與標記順序。
- 月曆用七欄，初次開啟定位最新有紀錄的月份與日期。日期格顯示日期及場次拼貼，有多場再加場數。切月時先選該月最新有場次的日期，空月份顯示空態並保留切月。清單跨月份按日期由近到遠分組，同日排序共用月曆規則。
- 場次列顯示場名、首筆紀錄或保存時間、完成首數。有封面時取既有摘要可提供的一張代表封面，否則用單色郵票圖案。返回月曆時恢復原月份、日期和焦點。

### 第一輪樣張

使用合成場次比較同一個月的兩個版面。寬版保留整月，窄版用日期標頭接場次列。先看 1280 × 850 與 960 × 650 桌面視窗下，日期、場次名稱、時間與明細入口是否清楚。

| 日期或情況  | 樣張內容                                                                                 |
| ----------- | ---------------------------------------------------------------------------------------- |
| 11 月 2 日  | 一場「週一練唱」，有封面並連結歌單。                                                     |
| 11 月 6 日  | 「午後練唱」14:00、「深夜歌回」23:30。後者隔日收場，兩場仍在同一天，郵票旁顯示「2 場」。 |
| 11 月 12 日 | 一場無歌單的舊紀錄，缺首筆時間，顯示「保存 21:10」。                                     |
| 切到空月份  | 保留月曆與月份導覽，場次區顯示空態。                                                     |

第一輪樣張用實際長度的中日英場名比較月曆與清單查閱。驗證涵蓋同時刻、缺封面、無歌單與只含標記的情況。

### 修訂樣張

月曆以 IMG_1834 的深色底、薄格線和左側大月份數字為主。場次日期格使用照片、郵票、票根或手記的不同組合，同日兩場以疊放照片與場數呈現。日期分組版保留相片縮圖，讓兩版共用同一套印刷物語言。樣張載入正式 CSS tokens 和 Folder／UI 元件，預先選中 11 月 6 日以檢視同日兩場。 [開啟樣張](../../../prototypes/performance-calendar/README.md)

## 2. Folder 郵票與票根

郵票可以是場次封面，也可以只是照片旁的裝飾。兩者共用齒孔輪廓。場次識別、日期與開啟明細由場次卡承載。裝飾留在照片或便條邊緣，跟隨物件位置和旋轉。第一輪沿用現有照片、膠帶及便條做版面比較。 [現有頁面物件](../../contracts/folder-page-objects.md)

| 素材     | 首批規格                                                     | 放置                                               |
| -------- | ------------------------------------------------------------ | -------------------------------------------------- |
| 郵票框   | 4:5 直式，四邊連續齒孔，裁切輪廓與月曆共用。                 | Folder 用印墨圖案，月曆可保留封面裁圖。            |
| 圖案郵票 | 麥克風、唱片、星星各一款，單色圖案配暖白紙，保留透明外圍。   | 一張照片或便條先比較一枚，預設貼在外側角落。       |
| 日期郵戳 | 空白圓環和兩三筆短線。日期由場次卡排版，字保持水平。         | 疊在大郵票一角，月曆小格用單獨郵票。               |
| 空白票根 | 3:1 橫式，兩側各一處半圓缺口和一條打孔虛線。紙形與紙紋分檔。 | 可從便條後方露出一截，或配合照片構成一組場次收藏。 |
| 索引名牌 | 短色帶和色頭加空白欄各一款。先試墨黑與鈷藍，朱紅用於對照。   | 貼在照片或便條一角，名字由畫面排版。               |

先做一張 Folder 樣張，主紙面保留曲目可讀範圍，側邊或底部放現有照片、郵票、票根各一件。另做只有照片與郵票的對照，確認齒孔在實際顯示大小仍辨得出來，明暗主題下紙邊都清楚。裝飾是否可獨立放置及保存，等物件樣張定案後再評估。素材使用原創圖案、獨立輪廓和可替換的低對比紙紋。

首批素材可在共用元件實驗室查看。歌單 Folder 的「本場演出」便條用唱片郵票、圓形日期郵戳與 3:1 空白票根組合，郵戳取實際場次日期。 [開啟素材樣張](../../../prototypes/ui-component-lab/README.md#folder-裝飾素材)

## 3. Output 票根式 Now Playing

首張樣張沿用 Now Playing 橫式 480 × 270 畫布。暖白票身放在畫布下方，票外透明。票身左側是方形封面，右側先讀曲名再讀藝人，最右邊用打孔線切出短票根。票根先比較素面與單一鈷藍索引線，曲名空間不足時縮窄票根。封面缺失沿用現有曲名首字概念。 [現有 Now Playing 模板](../../contracts/output-appearance.md#模板清單)

首版以素面副券呈現，已加入 Output 的 Now Playing 模板，名稱為「演出票根」。獨立樣張可切換亮、暗、棋盤背景，另有長曲名與缺封面案例。 [開啟樣張](../../../prototypes/now-playing-ticket/README.md)

- 同一張樣圖比較一行曲名和兩行長曲名，保留完整字高，第二行不足時省略。曲名、藝人與封面跟隨目前播放投影。
- 第一輪比較有無進度線。若放進度線，貼齊資訊區底部。換曲先比較同一輪廓內的內容交接，讓票身定位穩定。
- OBS 構圖比較人物左置與右置，放在對側下方。用明亮、暗色與細節多的場景核對透明缺口及曲名可讀性，另看縮小後是否仍像票根。

## 4. Output 收據歌單焦點

現有 `receipt-setlist` 作為對照。紙面、送紙方向及回顧照既有行為，第一輪只比較「目前演唱」一區的墨黑反白底帶與原紙底兩版。反白區固定於目前曲目，等寬數字及虛線維持收據的欄位節奏。比較長曲名換行、較小的 OBS 顯示尺寸，以及上下出紙時視線是否仍能回到目前曲目。 [收據歌單契約](../../contracts/output-appearance.md#收據歌單)

### 打字機歌單

取 IMG_1830 的暖白紙、墨字和霧藍機身。沿用 480 × 810 歌單畫布，外圍透明。目前曲目與已唱曲目共用同一欄，曲名最多兩行，右側 NP 夾對準最新的目前曲目。底部露出滾筒與一排按鍵。

完唱後該列保留在紙面，下一首自下方滾筒旁進紙，按實際列高往上推。等待下一首時保留已唱紀錄並收起 NP 夾。樣張採現有 Output 歌單公開範圍。 [打字機歌單樣張](../../../prototypes/typewriter-setlist/README.md)

縮小外觀的對照稿只保留一條滾筒、細壓紙桿與短旋鈕。紙邊收緊，曲名優先保留可讀字級與長曲名換行。鉛筆圈號、紅色墨帶和魚尾夾在同一列對照，三款仍沿用向上送紙的單欄順序。

## 5. Output 歌詞印刷色帶

IMG_1833 的反相曲名帶收進既有「剪報對白」候選，作為平直紙帶的對照版。構圖、字區與換句的比較設定以該案為準。 [印刷色帶定格](lyrics-overlays/cutout-dialogue.md#印刷色帶定格)

## 提案順序與待決事項

先定月曆入口與排序，再選郵票、郵戳、票根的第一組樣式。之後用同一套紙邊和墨色做票根式 Now Playing，最後用既有收據及剪報對白當對照。場次卡放大成開場或收播畫面保留為延伸構想，另決定公開欄位與展示時機。

參考來源為 2026-11-12 討論中的 13 張圖片。月曆構圖取 IMG_1834，郵票與檔案照取 IMG_1828，票根取 IMG_1826、IMG_1827，紙材取 IMG_1829，收據及色帶取 IMG_1825、IMG_1832、IMG_1833，索引名牌取 IMG_1835。構圖參考與製作素材各自記錄來源。
