# 歌詞音訊對齊：研究結論

整理日期：2026-10-22。本頁集中跨批次研究的選型與未決項；產品可用狀態以[規格](../../spec.md#3-功能現況)為準，實作邊界以[聲學估計契約](../../contracts/lyrics-acoustic-estimate-contract.md)為準。

## 目前結論

Basic 維持既有 T1 顯示與 T2 優先，不增加必備模型。研究優先使用原 HubertFA 對齊、Whisper small 獨立檢查內容，繁簡只用於比對，漏詞先警示。已提供本機研究試用；App 正式模型準備、歌曲詞塊產生與預設下載仍未開放。

[細部時間與時鐘對照](lyrics-fine-timing-clock-2026-10-22.md)是實作前的研究：確認上游可擷取詞／音素起訖，並找出本地採樣與 Output 發布時間配對問題；當輪未實作掃字。後續已修正時鐘、保存中日支援案例的細時間與文字映射，讓本地及 Output Focus 在合法細區間內連續填色，保留分段起點即時提示，不新增平滑等待。人工唱完時間真值仍缺，不能把畫面連續性當作自然歌聲逐字準確率；完整交付與限制見[歌詞階段整理](../../operations/lyrics-milestone-2026-10-22.md)。

實驗入口另已提供手動準備環境、伴奏後自動產生及歌詞頁手動套用／停用；正式 catalog 不變。後續完成[純英文驗證與進度](lyrics-english-validation-2026-10-20.md)及[混語長句顯示第一階段](lyrics-mixed-phrases-2026-10-21.md)：英文仍有正常誤拒與漏詞漏檢，混語只在既有可靠起點切換，未新增混語模型推論。下列中日歷史分母不與這兩輪合併；人工時間及混語語意仍 pending。

使用者已決定目前 CPU 足夠，HubertFA＋small 維持現有 CPU 路徑；新的歌詞 GPU 路徑、共用 GPU 偏好、small Vulkan／CUDA 下載／建置／實測及節拍／段落 GPU 擴展均暫緩。既有伴奏分離 DirectML 不變。這是投入方向的收斂，不代表整曲效能或人工品質已全面驗收。

GPU 評估已完成兩部分：[HubertFA 同權重對照](../audio/lyrics-hubertfa-directml-2026-10-21.md)的固定四案整體省 7.56%，未接產品；[small 成本評估](../audio/whisper-small-gpu-cost-2026-10-21.md)確認官方 CUDA 包容量及 Vulkan 自建投入，但沒有 small GPU 實測。兩者保留為研究證據，不再列為當前待執行計畫。

第一階段逐句中／日／英分流已完成，沿用現有 CPU 模型與內容門檻，主要語言提示不再鎖死每句。[句內混語有界研究](lyrics-mixed-cpu-bounded-2026-10-21.md)完成日英／中英各 2 個自然片段及 4 個負控制：聯合音素可解碼，但正常 0／4 取得雙語內容支持。使用者已決定句內混語不接入產品，保留逐句分流與 T1 回退；研究 adapter 不隨產品發布。

本頁統一維護研究決策與未決項；操作只見[試用手冊](../../operations/lyrics-alignment-research.md)，逐句方法與驗證見[第一階段紀錄](lyrics-mixed-cpu-feasibility-2026-10-21.md)，固定數據與限制保留在日期報告。GPU 與混語研究均已階段結案，以下未做項目不是待自動執行的清單。

零下載配對實驗顯示，base 在固定16案保留相同主要構造攔截與正常輸出，但漏詞警示1／3少於small的2／3；完整推論支援檔集合約1.328／1.668GB，不能只比較權重。兩首可確認的既有guide供HubertFA有時間改善跡象，ASR仍用原混音較穩；guide同送ASR本批增加回退／漏擋，暫不採用。人工標記仍pending，詳見[配對與完整成本](lyrics-model-pairing-2026-10-19.md)。

人工品質與特定權重／字典的使用範圍仍待確認，兩者分開驗收。研究輸出不寫入 canonical T2，也不因時間合法或模型一致就自動套用。

LyricFloat 的 Demucs＋faster-whisper base／stable-ts 保留為環境成本候選：固定資產 metadata 去重合計約 0.514 GB，安裝後／RAM／同條件品質尚未測，不取代目前選型。本次收斂不另排消融、安裝或模型替換；歷史評估見[效果與完整環境重評](lyricfloat-cost-2026-10-19.md)。

## offset 與內容證據

本輪只完成既有快取盤點、固定六句選定、前段兩句的離線身分／配方／內容重判及 O1 原因診斷。整曲 offset 建議尚未實作，沒有補跑模型、計算候選或修改人工 offset；來源 T2、原歌詞與人工時間 pending 均保留。下列研究不屬於已交付的顯示時鐘／細填色功能。

快取盤點沒有找到同錄音前／中／後各兩句的完整聯合證據：四份短裁片雖有 25 句原始首詞，全部在原曲前段；另四首全曲保有 33 窗 small 轉錄，但缺 HubertFA 原始首詞。發布詞塊的首塊沿用 T1，不能代替獨立起音；不足保留缺測，不以 provider 或模型一致當人工真值。

《雪 Distance》的六句固定後不換句，實際只檢查前段：O1 為 insufficient、O2 為 supported，另外四句未執行，依原規則停止。O1 的固定內容比對是 10／14；後續唯讀診斷確認前三字已被 ASR 辨出，因 token 起點在句框容許範圍外被排除，另有一字替換。整段文字層可匹配 13／14，正規化沒有造成差距；這是原因拆解，不是新方法已通過、歌詞對錯判定或人工時間準確率，原停止結果不回改。

下一個保留提案是把「文字內容」「唯一出現位置」「HubertFA 聲學時間」分開判斷。固定 ASR 完整片段與來源句須按順序一對一且無歧義；維持原支持／矛盾門檻及錯版本、漏詞、重複句防護，不能用高文字分數救回原明確拒絕，unknown 也不當成已排除漏詞。文字支持不等於可校時，ASR token 時間只作獨立診斷，不平均或代替原始聲學起音。

尚未做的是新判定實作、固定負例的離線對照、中後四句補測與六點 offset 一致性／人工驗收。此提案可能只改善原因說明，未必能解除停止；數值門檻不變也不等於誤接受風險已驗證。後續若繼續，先另行決定有界離線驗證，沒有自動恢復補測、接產品或更改 offset 的排程。完整規則與驗證矩陣見[內容／時間分離方案](lyrics-content-time-separation-plan-2026-10-22.md)，日期證據見下方追溯入口。

## 同條件證據

最新配對組是中日各兩首、每首正常／片語錯配／漏詞／整句靜音，共16案。正常片段共要求140個內部切點，只有兩首日文35點有外部provider參考；中文不能報時間準確率，provider也不是人工真值。

| 正常日文、固定35點 | T1均分 | Qwen | 原HubertFA | HubertFA＋small繁簡內容檢查 |
| ------------------ | ------ | ---- | ---------- | --------------------------- |
| 誤差≤100ms         | 15     | 12   | 22         | 22                          |
| 誤差>500ms         | 2      | 5    | 1          | 1                           |
| 缺界               | 0      | 6    | 5          | 5                           |

HubertFA單獨仍接受3／3片語錯配與3／3整句靜音目標；加內容檢查後兩者均0／3輸出。每種構造另有1個英文不支援目標，保留在原4案分母，不算成功攔截。漏詞警示2／3、正常新增警示0；這些是構造案例的代理結果，不能報成人工誤接受／誤拒率。

原HubertFA與Qwen使用不同frontend／採樣率／decoder約束，數字比較整套可用配方。舊確認組的百分比與新35點不混算；內容檢查只篩選，沒有改正起點。原53列人工標記仍pending，聽查入口選其中15優先＋4漏詞對照，不是假隨機盲測。

## 環境、權重與開放條件

本機研究流程不需要Qwen、Torch或GPU。9個固定資產下載合計778,532,833 bytes（約0.779GB）；這不含既有Node依賴、FFmpeg、解壓／安裝峰值或研究音訊，不能當完整環境容量。下載完成與資產驗證也不等於模型已載入；可執行步驟見[研究試用手冊](../../operations/lyrics-alignment-research.md)。

原HubertFA repo的Apache-2.0與small的既有授權證據分開記錄；特定HubertFA release權重及附帶字典的適用範圍仍未充分確認。這是證據未決，不是已證明禁止或侵權；原HubertFA也不能直接套用另一份GTSinger checkpoint的NC條款。開源、非商用或官方直下載不會自行補足未知範圍，詳見[權重查核](lyrics-hubertfa-fresh-2026-10-19.md#開源專案的非商用手動選配)。

早期試用已有4案實跑及取消／失敗清理證據，保留一次未重現、根因未知的worker失敗。後續英文與混語兩輪已完成隔離 profile 的可見 Electron／Browser Source 功能及回退驗證，詳見上述日期報告；這不等於人工時間通過，也不抹除早期失敗。正常誤拒／漏擋／長尾、人工聽查與權重範圍仍影響正式手動選配決策；目前 gate 和預設下載不變。
