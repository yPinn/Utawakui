# 歌詞詞塊：新歌實測與簡明選型

本文保留當輪研究與分母；目前跨批次選型及未決項集中在[研究結論](lyrics-alignment-summary.md)。

日期：2026-10-19。正式 gate、預設下載與 Basic 不變。本輪只增加私有研究程式、受控案例與人工抽查流程；沒有正式啟用模型、提交 commit 或散布歌曲／歌詞。

後續的[失敗根因、低成本修法與開源使用澄清](lyrics-root-causes-and-noncommercial-2026-10-19.md)另記繁簡比較救援、日文 span 診斷與純成效排序。以下排除是當時一般產品選配的範圍，不是說明文 NC 禁止所有開源或非商用使用／分享。

目前決定：Qwen 繼續作可撤回詞塊草稿的研究候選；small 有攔截錯內容的收益，但沒有本輪時間精度收益，尚不足以轉成正式手動選配，也不讓所有使用者多載 0.51 GB。Basic 繼續提供既有 T1／T2。先完成下述人工抽查，確認正常句被拒的原因與時間長尾，再作產品決策。

## 本輪實測

使用未參加前輪的本機中文、日文各兩首，每首同一 30 秒片段做正常、同歌後續片語替換、輸入漏一詞、整句靜音，共 16 案。選取與門檻先固定；推論不讀細時間參考。歌曲與歌詞留在 ignored 研究目錄，公開證據只有匿名結果。

片語替換是合成內容錯配，不是真實 live／cover；整句靜音不是從混音只拿掉人聲。第一首日文的目標句是純英文，既有中日研究 tokenizer 回退，保留為跨 script 負例；有效目標只有另外三組，不把這次回退當成內容辨識成功。兩首日文的其他句仍參加正常詞塊與外部細時間比較。

結果以機器收據為準：自動數字是構造案例輸出或外部 provider 一致性，人工誤接受／誤拒仍待聽查；不回報虛構的 0%。

| 相同案例／分母                 | Qwen 單獨                              | 加 small 內容檢查            | 解讀                                                                         |
| ------------------------------ | -------------------------------------- | ---------------------------- | ---------------------------------------------------------------------------- |
| 三個可分析片語錯配目標仍出詞塊 | 3／3                                   | 0／3                         | 攔下三個合成錯配；另有一個英文目標始終 unsupported，未當作成功攔截           |
| 三個可分析整句靜音目標仍出詞塊 | 0／3                                   | 0／3                         | 原本就回退，沒有額外收益；不代表有伴奏無主唱也能判對                         |
| 三個可分析輸入漏詞目標         | 仍出詞塊 3／3                          | 仍出詞塊 3／3；缺詞警示 0／3 | 沒抓到缺詞；剩餘詞時間是否正確仍分開看                                       |
| 四首正常片段，29 句            | 出詞塊 25 句                           | 24 句                        | 多移除一個中文非目標句；這是待人工確認的誤拒風險，不能報成零誤拒             |
| 正常日文外部參考，固定 35 切點 | ≤100ms 12；>500ms 5；>1000ms 0；缺界 6 | 完全相同                     | small 只篩內容，未減少這輪時間長尾；兩者量到 29 點，不能改用 29 當正確率分母 |

同分母原 T1 均分為 ≤100ms 15／35、>500ms 2、>1000ms 1、缺界 0；Qwen 此輪沒有穩定勝過它。兩首日文分別由 8→2、7→10 個 ≤100ms 切點，顯示曲目差異，不能只挑改善的那首。這 35 點是外部 provider 的內部切點，不含 T1 第一錨點，不是人工準確率；前版「含第一錨點」文字已更正，凍結 scorer 與數字均未改。新中文沒有可用細時間參考，不能推算中文時間改善。

本機 16 案 Qwen 模型逐案載入合計 268.41 秒、small 186.44 秒；單案時間 median 約 16.78／10.63 秒（30 秒片段）。包含各案模型載入與保存，非暖機整曲或無其他負載的效能基準；small native working set 本輪未另量測，不以 0 當 RAM 用量。逐案 raw、模型與音訊綁定；兩方法都完成 16 案並清空 owned workers。[匿名數據](data/lyrics-fresh-decision-2026-10-19.json)保留固定分母與來源雜湊。

## 環境與漸進配置

| 配置        | 完成後新增環境                   | 適合角色                                           |
| ----------- | -------------------------------- | -------------------------------------------------- |
| Basic       | 0 GB 新模型                      | 既有 T1、匯入／人工 T2、文字結構檢查、回退         |
| Qwen 單獨   | 2.903 GB；含本輪 FFmpeg 3.125 GB | 中日詞塊研究，先檢視草稿                           |
| Qwen＋small | 3.411 GB；含本輪 FFmpeg 3.633 GB | 多付 0.508 GB 做內容檢查，是否值得由收益與誤拒決定 |

十進位 GB、固定 CPU 配方邏輯落盤，含目前 Python caches；排除 app／OS、歌曲／輸出／UV／job cache。這是完成後 payload，下載暫存、修復並存峰值尚未量完。Qwen 是獨立 CPython 3.12／Torch CPU 環境，不能直接套用目前 Audio Python 3.14。Whisper.cpp 為 native CPU，不另需推論 Python。

目前只驗 64 GB Windows 主機；Qwen 工作集約 6.10 GB。8 GB 不承諾；16 GB 加 Electron／OBS 的共用負載仍待驗，GPU／量化也沒有本輪證據。模型應串列分階段載入，容量及 RAM 不能混算。

## 人工抽查與採用條件

本機入口 `.tmp/lyrics-new-eval/human-review/README.md`：53 列，正常案例的 29 句全部納入，確保非目標誤拒與長尾不被漏掉；另外 24 列為衍生案例目標／控制句。先獨立聽內容及標詞塊起音，再揭盲看 A／B 時間。所有列初始 pending；沒有代簽人工標註。音檔、候選結果、來源、UTF-16 詞塊、揭盲表都有身分驗證，竄換音訊或交換方法映射會拒絕匯入。操作與命令見[研究工具說明](../../../scripts/research/lyricsFreshEvaluation/README.md)。

人工內容相符但原 Qwen 詞塊被 small 移除才計誤拒；唱了不同詞或未唱卻仍出詞塊才計誤接受。漏詞另算完整性。人工可判讀的起點用固定分母比較 ≤100ms、>500ms、>1000ms 與缺界，pending／uncertain 不進分母。來源 provider 的逐字時間不能代替人工真值。

正式手動選配需先有可接受的獨立聽查結果與誤拒預算，再補完整 artifacts／notices、managed runtime 的 prepare／probe／cancel／repair／remove、空間峰值與低 RAM／OBS 驗收。此輪不放寬 gate、不加入預設下載。

## 驗證紀錄

23 個相關測試檔、162 tests 通過，涵蓋新語料／內容／人工輸入、既有候選取消與故障、sidecar、T1／T2 回退及 packaging。初次沙箱測試有一項 junction 權限 EPERM，正常 Windows 權限重跑全過。Qwen 與加 small 各 16 案的實際結果均通過 `verifyResults`，每方法檢查 232 個前進／倒退時鐘樣本、8 個重複 occurrence、原文與 stale、T2 優先及 workers 清理。正式 catalog／loader 等 11 個來源 SHA 與前輪一致。

全庫 ESLint、Vite build、範圍內 Markdown／格式與相對連結通過；build 僅有既有 chunk-size warning。程式 review 發現的音訊 receipt 綁定、揭盲映射、來源 offset 與 stale inventory 已修正並複查。small 首次 raw evidence 路徑被既有邊界檢查擋下，保留失敗紀錄，改到允許的研究根目錄後 16 案重跑完成；未放寬邊界。此輪沒有重做全庫 Vitest、完整 installer、低 RAM 或可見 Electron／OBS 驗收。
