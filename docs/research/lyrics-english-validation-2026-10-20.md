# 純英文 T1+ 與內容檢查實測

日期：2026-10-20。這輪可提供實驗性純英文詞塊候選；內容檢查較保守，不能視為逐字時間已驗收。正式 gate、預設下載與手動套用政策不變。

## 方法與容量

沿用已安裝的 HubertFA ONNX、multilingual Whisper small 與模型包內既有的 CMU 英文字典；本輪新增模型下載為 0 bytes。字典原有 3,402,616 bytes，現在列入明確完整性驗證，沒有新增權重或 Python 套件。英文 helper 納入安裝包白名單；完整環境容量仍依原試用環境計算，沒有另測 RAM 峰值。

英文以原文詞語範圍查字典，保留大小寫、標點與縮寫原文；比較內容時才展開常見縮寫。僅處理明確的 0–20 基數，未知發音、含糊數字或混語回退 T1。自動辨識採保守英文內容線索，短英文或未標明的來源可手動指定本次分析語言，不改來源標籤或既有校時；其他拉丁語言不自動視為英文。

初始 30 秒 ASR 片段的粗略 token 時間會把正確英文前綴排除。改為每句附前後各 500 ms 的盲轉寫，不提供預期歌詞；只改內容驗證範圍，不移動來源 offset 或 HubertFA 起點。英文須同時有足夠內容證據與可用模型詞塊才提供 T1+，證據不足仍保留 T1。

疑似漏詞以唯一的前後雙詞錨點尋找句內插入，僅警告，不補詞、不自動改時間、不自動套用。重複錨點保持未知；近數位靜音另行擋下，這不是完整的人聲活動模型。

## 實測分母與結果

使用本機既有 demxntia 的 tonight, pt. II 與 obsession 原混音，固定模型與 CPU 路徑。最終主批次為 7 個案例、8 個句子出現位置；保留初始失敗與中間消融紀錄，不能把多次重跑累加為獨立樣本。原檔、歌詞、模型逐 byte 核對未變更，工作子程序均已清理。

| 案例               | 最終結果                       | 判讀限制                                   |
| ------------------ | ------------------------------ | ------------------------------------------ |
| 清楚正常句         | 7 個候選詞塊，內容支持         | 起點仍待人工時間驗收                       |
| 困難正常句         | 內容不足，回退 T1              | small 仍可能漏聽正常內容                   |
| 含縮寫正常句       | 10 個候選詞塊，內容支持        | 原文縮寫保持不變                           |
| 人為刪除一詞       | 9 個候選詞塊，顯示疑似漏詞警告 | 警告不等於確認漏詞，須自行核對再套用       |
| 同曲錯段／錯序構造 | 內容矛盾，回退 T1              | 不是另一個已發行錄音版本的實測             |
| 同一句兩次出現     | 兩次皆證據不足，分別回退 T1    | 沒有借用另一段證據，也未證明重複句時間準確 |
| 數位靜音控制       | 回退 T1，即使 ASR 幻覺文字相符 | 不代表已驗證純伴奏、和聲或低音量人聲       |

原先固定的兩句正常英文在長片段方案皆因證據不足回退；逐句盲轉寫後其中一句可用，另一句仍回退。新增較清楚的正常句可用。這是少量案例的行為改善，不能換算一般準確率。

最終另補 2 個單句控制：重驗先前未警告的另一個刪詞構造，仍有候選而沒有漏詞警告；同一音訊加入 3 秒前奏、保留原 T1 時間，則證據不足回退 T1。連同主批次共 9 案、10 個出現位置；漏詞兩案只有一案警告，不能宣稱漏詞偵測完整。前奏控制補足內容相同但時鐘不同的情境，仍不能代替不同正式發行版本的大樣本驗證。

主批次單句約 15–19 秒、重複兩句約 24 秒、靜音控制約 7 秒，包含當次載入成本，僅代表這台機器與這組短案例。逐句 small 呼叫增加長曲耗時，尚未以整曲或大樣本驗證長尾。

## App、Output 與回退

使用隔離 profile、既有環境的唯讀硬連結與可見 Electron 視窗完成實際載入、取消、英文分析與詞塊預覽。歌詞 modal 保留一句主要狀態及手動操作，分析說明預設收合；準備／驗證／載入階段顯示不定進度，對齊及內容檢查顯示實際完成片段數，不假造整曲百分比或剩餘時間。

可見 App／Browser Source 已驗證手動套用與停用同步影響既有 T2 樣式、來源 T2 優先、切換來源、校時變更後估計失效，以及受控安裝完整性失敗時保留 T1。漏詞警告在重新讀取估計後仍保留，產生候選不等於已套用。原始來源／音訊／模型雜湊未變更，沒有新模型下載。
