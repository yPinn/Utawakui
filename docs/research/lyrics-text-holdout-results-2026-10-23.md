# 來源多句合塊：C／E 合成留出診斷

本輪對「空白或無標點的多句合塊」得到局部正面訊號，但全體未優於標點對照；分類也出現和聲誤標與混合塊風險。固定 120 次排程在第 111 次因單請求超時停止，留下九次缺測，沒有補跑。這是代理編寫／評分的合成留出診斷，母語獨立審查為零，不是歌詞平台實際準確率或產品採用證據。

## 執行範圍與保真

依[驗證計畫](lyrics-text-blind-validation-plan-2026-10-23.md)，使用者另核准在可及範圍完成合成診斷，不冒稱母語盲審。C 完整左右預覽、E 獨立分類、候選產生器、schema 與驗證器均沿用[前輪版本](lyrics-text-qwen-ablation-2026-10-23.md)，沒有調 prompt 或新加 few-shot。

先鎖介面，再編寫五語系各 20 個新 occurrence：12 個拆句、8 個分類，共 100 個。輸入、答案及時間對照分離，答案在查看候選前寫入 SHA；之後凍結 14 份推論來源與其相依快照、runtime binary hash 及完整排程。主測 C60／E40，共同來源塊另補 C10／E10，總計 C70／E50。模型 payload 沒有題型、家族、隱藏用途、參考拆法、不可切標註或時間。

每語系六個拆句輸入有多組完整參考；符合任一完整分組才算命中，不將不同答案的斷點取聯集。三個 M1 空白版本只算一個內容家族，每語系拆句共有十個家族。五組同字用途配對，加上英文／韓文 M1a、M1c 的同字重複，令 100 occurrence 共 93 個不同字串。這些重複全部保留，不充作獨立語意樣本。

候選檢查共 750 個主拆句候選，60／60 案都至少能達成一組凍結參考；沒有看覆蓋後改答案或補候選。分類、拆句都只提供研究建議；即使製作資訊候選，也完整保留。沒有來源、sidecar、offset、原起訖或產品寫入。

不切對照為 15／60、固定標點優先對照為 40／60；C 為 36／60。若只看 C 實際執行的同一批 54 案並仍計超時失敗，標點對照與 C 都為 36／54，不切為 13／54。完整回覆 53 案的條件比例不是主分母，不能刪掉缺測／超時來宣稱全體改善。

M1 沒有句間標點時，兩種零模型對照都為 0／15；C 的 14／15 是本批最值得保留的局部訊號。空白改變後，四個語系選中的語意邊界集合不完全相同，但多數仍落在不同可接受分組中；不能把分組不同直接當錯。英文三版選點一致，其中 a／c 本來同字；韓文 a／c 也是同字，仍須按重複對照看待。

重要失敗及標註限制，以下 `｜` 只用來解釋，沒有寫回來源：

- 日文 M1c 選成「坂のパン屋が窓を開けた向かいの猫が｜あくびをした僕は昨日の手紙をポケットにしまった」。所有參考切點都在候選中，仍沒有分出預定三個意思。依附專題通過不代表未標點來源整體已解決。
- 繁中 H1 選成「我把空椅留在身旁｜（和聲：等你啊等你），｜等門鈴喚醒安靜的走廊。」和聲完整，但被獨立成子段；簡中與韓文也有和聲接到後句的情況。這不能因為沒有刪詞就算語意成功。
- 英文 N1 在 sweater／that 之間切開，日文 N1 在連體修飾與名詞片語之間切開；凍結參考希望不切，因此未符合，但還需母語與實際閱讀情境判斷。
- M2 的三組參考都要求至少兩刀，也未列全三組的其他合理組合。日文在分號分成兩個完整意群，韓文將「신발 끈을 묶는 동안」與後面的主句相連，繁中將紙船與晚餐句留在同組，都有合理讀法的可能。此限制在整批評分前已另存備註。原主分數不回改，也沒有將事後看來合理的結果偷偷加入答案。

因此 36／60 不是一般語意準確率，也不能與前輪單答案 C 的 6／15 直接比較。多答案、題型、對照與缺測均已不同。本批沒有語系達預定 10／12 參考符合線，且人工審查為零，未通過正式研究或產品採用 gate。

## 分類：和聲與混合塊仍有風險

主分類共 40 案，其中 39 案完整回覆、一案日文和聲缺測。25 案可辨識組包括十個 apparent 署名及十五個實唱負例；五個混合塊、十個同字用途 occurrence 各自另報。

| 類別                         | 原排程   | 實際結果                                                             |
| ---------------------------- | -------- | -------------------------------------------------------------------- |
| 明確／括號製作署名           | 10       | 10 個 credit-candidate，均保留                                       |
| 可辨識實唱／對唱／和聲／引用 | 15       | 已回覆 14：11 lyric、1 ambiguous、2 credit-candidate；另 1 缺測      |
| 署名＋實唱混合塊             | 5        | 4 credit-candidate、1 lyric、0 ambiguous，未符合預設 mixed→ambiguous |
| 同字不同用途                 | 10／5 對 | 10 個都 credit-candidate；五對一致、零棄權；無法據此辨識隱藏用途     |

兩個已知實唱負例誤標為：繁中「和聲：啊啊（一起唱，別停下）」、韓文「화음: 아아아 (함께 다시 불러)」。英文「Backing vocals: oh oh (all together now)」棄權；日文和聲未執行。可辨識組已觀察候選 precision 為 10／12、署名 recall 10／10，另列一個缺測，不能聲稱全部實唱均無誤標。

對唱及引用製作詞的負例均已回覆並為 lyric。對唱標籤沒有被當成可刪 cast，但和聲前綴仍會誤判。四個 mixed 整塊被標候選，說明整行三分類不能可靠表示「同塊部分為署名、部分為唱詞」。C 分段也沒有授權逐片刪除；共同子集不追加逐片分類或自動省略。

五對同字用途都一致，只反映文字判斷一致；其中隱藏用途為實唱的一側仍全部得到候選，正是不能自動刪除的風險。這組不混入可辨識 precision／recall，也不要求模型猜中從未提供的作者意圖。

## 成本與停止規則

既有 Ryzen 7 7700、4B Q4_K_M、pinned b11669 CPU runtime；四 inference／prefill threads、一模型一 slot、無 GPU／thinking／prompt cache。零下載、零新環境，模型與 runtime archive 開跑前以串流 SHA 驗證，展開 binary 與推論來源另有 hash。

| -------- | ------------------ | ----------- | ----------- | ----------------------------------------------- |
| C 主拆句 | 53／1／6           | 10.677      | 20.006      | 54 個 wall 值含 30.015 秒超時；usage 只有 53 份 |
| E 主分類 | 39／0／1           | 4.606       | 8.537       | 缺測不填零                                      |
| C 補充   | 10／0／0           | 8.033       | 10.737      | 不加入主品質分母                                |
| E 補充   | 8／0／2            | 4.475       | 5.653       | 兩個缺測                                        |

全輪從啟動至停止 983.108 秒，約 16.385 分鐘，啟動就緒 2.468 秒。最慢完整回覆 23.033 秒；超時 timer 為 30 秒、觀測回退完成為 30.015 秒。server 累積 3426 CPU 秒，sampler 約 156.391 CPU 秒，runner 約 8.733 CPU 秒。逐請求 CPU 括住採樣可能有邊界重疊，不當作互斥 CPU 區間加總。

共享 server peak working set 約 4.330 GiB、採樣 private 峰值約 2.203 GiB；server private／working set 取大，再加 runner RSS 及 sampler private／working set 取大的保守合計峰值約 4.507 GiB。全程 7434 筆樣本，最大間距 237ms。這些是單一共享程序的採樣證據，不是各任務獨立 RAM 成本或逐瞬間峰值保證。

原 4096 context 含 512 output 預留、全局 45 分鐘、30 秒單請求、8 GiB、10 GiB 磁碟 reserve 與原資產限制均沿用；停止後不續跑。110 份完整 usage 的實際 context 最多 1477、output 最多 34 tokens，111 次 preflight 均符合預留；超時回覆缺少最終 usage，沒有補造 token 數。啟動與收尾磁碟 reserve 均足夠，收尾約 39.16 GiB 可用，原始收據與驗證資料小於預留 256 MiB；不宣稱連續監測全磁碟或 OBS 共用表現。

## 判斷

值得繼續研究的範圍是空白／無標點多句合塊的文字分組，還需要修正後重新獨立凍結的多答案標註與母語審查。整體目前沒有優於簡單標點對照的證據，和聲依附、短句零切分、混合塊分類及單次可靠性都有缺口。

本輪依停止規則結束；不把未完成排程補齊、不換 prompt 或答案湊成功，也不接產品。即使將來文字分組較好，仍只輔助判斷來源內的意思，不證明演唱時間、換氣、間奏或主副歌，也不授權刪除實唱、對唱與和聲。
