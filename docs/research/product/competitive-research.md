## 4. 本輪主要變化

### Setlista

0.27.0 加入與 JOYSOUND for STREAMER 的連動。仍是 Browser Dock／Source 的文字歌單工具，沒有擴張成本機媒體播放器。

### 聲嶼 Elitesand Pro

- **練唱（1.2.0 起）。** 分析原唱音高，即時顯示音準、逐句評等與總分；1.2.1 加 Mic 增益、回音消除試用、裝置別延遲校準、A–B 循環、批次建立練唱音軌；1.2.2 加寬鬆／嚴格評分。OBS 另有練唱疊加層。
- **自動對時。** 1.2.0 用分離人聲比對歌詞算整首偏移；1.3.0 加中文歌逐句校正（實驗性）。
- **匯入後自動處理。** 可設定匯入後依序製作伴奏、對時、建立練唱音軌。
- **歌詞來源。** 1.3.0 改抓 QQ 音樂／網易雲逐字版，加 AMLL 社群逐字歌詞庫備援、WebVTT 匯入、譯文分開保存、逐句批次升級逐字。
- **直播互動。** Twitch 訂閱／贈訂／揪團 43 種全畫面演出、點歌明信片、觀眾挑戰分數；演出排到歌曲結束後並自動壓低 BGM。
- **其他。** 逐曲記住音量、快捷模板槽（Ctrl+Alt+數字）、極簡歌單、跟唱視圖置頂與私人歌曲筆記、Spout 指定顯示卡。
- **資料傳送。** 匿名統計（含練唱分數區間）與社群時間偏移預設開啟、可關閉，每次擴充都要求重新同意 EULA。仍為未簽章 installer。

### 歌回救星

- **音量。** 2.2.1.0 加歌曲音量平衡與逐曲增益；2.2.1.2 加手動增益滑桿，音高與速度共用逐曲設定。
- **影片。** 2.2.1.0 支援 MP4／MOV 合唱影片與主播放器同步，含色度鍵與透明 MOV。
- **OBS 主題。** 新增 Frequency Orbit、Bubble Drift 等動態主題，主題可分語系設定字型，可顯示點播者。
- **音訊路由與診斷。** 持續修 ASIO buffer 相容、監聽輸出選單、路由啟動失敗提示、異常取樣攔截、手動音訊診斷的事故分組。
- **UVR 分離。** GPU 偏好跨批次保留、CPU 回退後下批重試 GPU。

### KAREOKIE

- **練習模式（0.3.4）。** 獨立於點歌，選首尾句練一段，每遍顯示偏差並可回聽；不計入排行。
- **錄音工作室。** 自動對齊人聲、0.3.6 加修音（可比較）、只匯出人聲、15 秒精華；即時修音為 Beta。
- **社群化。** 好友 ID、首頁聊天室（唱完一首才可發言）、「大家的歌詞」共享修正版歌詞／時間軸／讀音／翻譯、同曲多影片共用排行榜、Discord 月度榜。
- **歌詞與翻譯。** 一次搜尋所有歌詞站並標來源、可貼網址或匯入 .lrc／.txt；缺譯文時背景用 Google 翻譯補上。
- **其他。** 手機遙控、喇叭模式收音改善、Mic 降噪、匯入佇列排序；改用自有 API 網域。帳號與雲端依賴比前輪更深。

## 5. 對 Utawakui 的產品含義

### 5.1 BGM lane 與無伴奏項目已形成重複需求訊號

BGM 與手動項目已實作，比較集中在入口、真實擷取、交接與故障復原。歌回救星本輪的逐曲增益與音量平衡、聲嶼的「演出時壓低 BGM」顯示**場間與歌曲間的音量一致性**是共同痛點；本案的「場間音樂響度」目前列在 spec 6.3 等待條件，可考慮提前評估。差異與程式依據見[順序規劃補正](player-practice-planning-2026-10-26.md#目前實作核對與分類補正)。

### 5.2 原生 OBS 音訊仍是高成本候選，不是追趕項目

歌回救星本輪大部分修正集中在 ASIO、監聽輸出與路由失敗提示，正好說明原生路由的維護成本。尚未證明本案現有輸出不足前，維持需求驅動的待決策項目。

### 5.3 練唱評分已成為兩家競品的主線

聲嶼與 KAREOKIE 都把「原唱音高 + Mic 即時音準 + 逐句回饋」做成主要功能，並支援 A–B 段落、裝置別延遲校準與 OBS 疊加層。本案已有導唱音高、Mic 電平原型、A–B 練習，評分與競賽在 spec 7.3 暫緩。建議：

- 不追評分與排行，但可把既有能力收斂成「區段練習 + 音準曲線回看」，這是無需雲端、符合 local-first 的差異點。
- 先完成實體 Mic 量測（延遲、串音、校準），這是兩家競品都花大量版本修正的部分。

### 5.4 自動化準備流程是明顯的體驗落差

聲嶼「匯入後自動伴奏 → 對時 → 練唱音軌」與歌回救星的批次處理，都把準備工作變成一次設定。本案已有分離佇列、歌詞背景補抓與 MV 自動對時，但入口分散。spec 6.3 的「曲目準備與首次操作引導」值得優先恢復。

### 5.5 逐字歌詞與社群資料走向分歧

聲嶼擴充逐字來源與社群偏移，KAREOKIE 做社群共享歌詞。本案的本機校訂、逐句打點與 LRC／SRT 匯出偏「個人可控」。不建議跟進社群上傳；可評估 AMLL 等逐字來源與 WebVTT 匯入，前提是先核對授權與 [外部服務請求政策](../../contracts/external-service-request-policy.md)。

### 5.6 本機處理、帳號依賴與資料傳送分開比較

- 聲嶼的匿名統計與社群偏移預設開啟、可停用，並隨功能擴充反覆修改 EULA。
- 歌回救星核心可離線，線上點歌另需開通。
- KAREOKIE 已有帳號、聊天、好友、排行榜與自有 API，本機處理不代表沒有雲端依賴。

以上是官方揭露，不是封包稽核。本案預設不連網、五個 gate 各自同意，這點是可對外說明的差異。

### 5.7 產品邊界維持不變

直播觀眾互動（訂閱演出、點歌、挑戰）仍不納入；手機遙控已在 spec 6.2。外觀 Pack 的取得／付款不隨模板能力一併啟動。
