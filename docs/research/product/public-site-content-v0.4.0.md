## 一、開場

### 01 MV：主視覺

主標：為歌回與翻唱準備，把歌曲、歌詞與播放整理在一起。

內文：Utawakui 是 Windows 桌面工具，協助你整理自己的音訊、安排歌單與播放，並將曲目與歌詞資訊呈現在 OBS。

平台行：Windows x64・v0.4.0 公開測試版。

主要入口：下載 Windows 版。

次要入口：看看怎麼使用，導向第 02 節；版本說明保留在下載資訊旁。

素材配置：

- A01：正式 App icon／品名字樣；沿用正式資產，不在內容階段另設 Logo。
- A02：v0.4.0 主畫面截圖，包含曲庫與目前播放資訊；畫面只承擔產品辨識，不塞入全部功能。
- 不在此處使用目前 main 的 Folder／Settings 重建畫面，避免公開版本下載後不一致。

核對：E1、E2、E3。可採用；不承諾內建歌曲、跨平台或網站直接播放本機 App 功能。

### 02 Intro：整體使用流程

主標：從自己的第一首歌開始。

內文：匯入歌曲、整理歌單、準備歌詞，再將需要的演出資訊加入 OBS 畫面。

影片字幕依序：匯入歌曲 → 整理與播放 → 準備歌詞 → 加入 OBS。

補充短句：歌詞來源與對外輸出需依需求另行啟用。

主要動作：播放操作示範；網站不預設自動發聲。

素材配置：A03 工作流短片，建議 20–30 秒。使用 A04 的同一組示範曲目，前段從已有權使用的本機檔案開始，後段呈現已完成的 OBS 設定。若中間剪接，字幕明示步驟，不假裝整段只需一鍵完成。

核對：E2、E3、E4。可採用；影片長度為製作建議，不是產品完成操作的時間保證。

### 03 POWER UP：四個能力、六個既有素材群

章標：把準備工作，放進同一個流程。

不增加新 section，也不為填滿原站六個素材群而發明六種功能。分配如下：

| 素材群        | 對外標題             | 短文案                                             | 畫面內容                           | 素材 |
| ------------- | -------------------- | -------------------------------------------------- | ---------------------------------- | ---- |
| 01 曲庫       | 整理自己的歌曲       | 匯入本機音訊，整理曲名、歌手與封面。               | 曲庫全貌＋一首歌的資訊編輯局部     | A04  |
| 02 歌單       | 把想唱的歌排在一起   | 建立歌單，整理順序，再加入待播佇列。               | 保存歌單與待播佇列的關係           | A05  |
| 03 播放主畫面 | 播放與切歌，集中操作 | 控制進度、音量與循環，接著播放下一首。             | 目前曲目、seek、音量及下一首       | A06  |
| 04 排練細節   | 照自己的節奏練習     | 調整音高與播放速度，反覆練習同一段。               | 同曲不同設定的控制局部／帶字幕示範 | A07  |
| 05 歌詞主畫面 | 準備要唱的每一句     | 匯入與編輯歌詞，讓已有同步時間的歌詞跟著播放前進。 | 本機歌詞與播放同步                 | A08  |
| 06 閱讀細節   | 看清楚接下來的歌詞   | 使用演出者視窗；需要時，為支援的歌詞準備讀音輔助。 | 演出者視窗＋一組已驗證讀音示例     | A09  |

條件文案放在能力群 04–06 附近，不能只藏在 footer：

- 歌詞同步依資料中的時間資訊呈現；不保證每首歌都有逐字同步。
- 外部歌詞查詢需另行啟用；本機歌詞匯入與編輯可獨立使用。
- 讀音錄影完成前，不宣稱涵蓋所有語言、讀法或歌曲。

核對：E2、E3、E4、E7。功能已有發布來源證據，實際畫面仍需以 v0.4.0 重錄；可選依賴的下載與準備不得以剪接隱藏成零成本動作。

## 三、核心變化

### 04 Before：操作端

主標：你在這裡播放。

內文：在 Utawakui 操作歌曲，查看目前曲目、進度與同步歌詞。

畫面註記：操作端・Utawakui v0.4.0。

素材配置：A10-A。錄製一首已準備好歌詞的歌曲，保留 10–15 秒連續播放。需記下歌曲時間起點、切歌事件及影片同步點，讓第 05 節能準確對照。

核對：E2、E3、E7。Before 表示操作視角，不表示產品使用前的缺點，也不使用「原本做不到」的比較說法。

### 05 After：OBS 中的觀眾畫面

主標：觀眾在這裡看見。

內文：透過 OBS 瀏覽器來源，將目前曲目、歌詞與已播放紀錄放進你的演出畫面。

必要註記：示範場景由使用者在 OBS 配置；Utawakui 提供資訊輸出，不會自動建立或控制場景。

素材配置：A10-B。與 A10-A 同時錄製或嚴格對齊的 OBS 成果，使用相同歌曲與時間範圍。至少示範目前曲目及同步歌詞；已播放紀錄可在曲目切換後出現。不偽造尚未發生的播放歷史。

核對：E1、E4、E5、E6。修正前輪「播放清單輸出」的泛稱：v0.4.0 的 Setlist 投影是目前曲目與已播放曲目，不是整份未唱安排。不要把 Before／After 寫成「一鍵變成專業直播」或音質改善保證。

## 四、延伸內容

### 06 Montage：成果與本機視角

主標：把需要的資訊，放在適合的位置。

內文：依演出需要選擇曲目、歌詞與歌單畫面；演出者視窗則留在自己的螢幕上。

拼貼中各畫面短標：

| 畫面                 | 短標             | 範圍                                            | 素材  |
| -------------------- | ---------------- | ----------------------------------------------- | ----- |
| Now Playing 基本樣式 | 目前曲目         | 曲名與歌手等播放資訊                            | A11-1 |
| Now Playing 封面樣式 | 封面呈現         | 屬於 Now Playing，不是第四個輸出類型            | A11-2 |
| Lyrics 主樣式        | 同步歌詞         | 以該示範檔實際同步精度為準                      | A11-3 |
| Lyrics 第二種樣式    | 歌詞的另一種呈現 | 只選 E5 列有且已實際錄製的樣式                  | A11-4 |
| Setlist              | 目前與已播放曲目 | 不含完整未唱安排                                | A11-5 |
| Performer Self-View  | 演出者視窗・本機 | 清楚標示為操作者閱讀，不是第四類 Browser Source | A09   |

沿用原站拼貼的內容角色與不同長寬比，不在這份內容稿決定新的外觀或加入自動輪播。

核對：E2、E3、E5、E6。素材拍攝時才選定具體模板，選定後把 template id 寫入素材紀錄；不要先宣稱所有樣式都在全部狀態下完成實機驗收。

### 07 Feature：接入方式、選用能力與資料邊界

全寬主單元標題：接到 OBS，用你熟悉的瀏覽器來源。

內文：在 Utawakui 啟用對外輸出、選擇畫面並複製網址，再到 OBS 新增瀏覽器來源。

步驟字幕：啟用輸出 → 複製對應網址 → 在 OBS 新增瀏覽器來源。

附註：這條輸出流程不需要另外啟用 OBS WebSocket 連線；唯讀 OBS 連線用於讀取直播／錄影狀態與場次時間。

素材配置：A12。一段完整設定錄影；保留啟用步驟，複製與貼上對應同一個實際網址。示範資料不要帶入私人檔案路徑、密碼或診斷內容。

雙欄 A 標題：需要時，再準備音訊處理。

內文：在本機產生人聲分離結果，搭配導唱輔助練習。部分功能需要先下載工具或模型，處理時間與效果會依音源及電腦而異。

素材配置：A13。公開版實際支援的 quick 或 general 流程，明示已先準備依賴；保留工作完成狀態，再展示對應結果。不要使用 Refined、pre-render 或 backing-vocals 作已提供功能。

雙欄 B 標題：需要時，再使用外部來源。

內文：啟用後，可查詢外部歌詞或搜尋候選音訊來源。使用前請確認來源規範與素材使用範圍。

附註：歌曲與歌詞來源是分開啟用的選用流程；服務是否提供結果仍依來源與當時連線狀態而定。

素材配置：A14。拍攝各自的啟用入口與實際查詢結果；用自己的合法示範素材。外部服務當下可用性尚未重測，在完成素材驗證前不寫指定平台成功率、全面支援或官方整合宣稱。

下方全寬分組標題：以本機資料為核心，依需求開啟連線。

分組 A：音訊、歌詞、歌單與處理結果主要保存在你的電腦；音訊處理在本機執行。

分組 B：外部來源、歌詞查詢與更新檢查會連線至對應服務。啟動後會檢查更新，下載與安裝仍由你決定。

支援短句：遇到問題，可從設定找到支援入口，或到 Discord 回饋。

核對：E1–E5。不使用「完全離線」「永不連網」或「資料絕不離開電腦」等跨越所有選用流程的承諾。不宣稱已驗證自動更新的所有升級路徑。
