# 原唱音高預覽原型

開發版的「演出工具 → 調整」將原唱音高預覽與升降 Key、音分微調及變速放在一起。先啟用音訊處理、準備 FFmpeg，並為曲目準備分離導唱。開啟「調整」或在該頁換曲時，自動載入已有的預覽，缺少有效快取時才分析。播放、暫停及跳轉使用主播放器，導唱監聽與輸出音量使用「導唱」頁。

量測結果及預覽規則的採用範圍見[原唱音高研究收斂](../../docs/research/audio/reference-pitch-note-boundary-summary-2026-11-06.md)。

將 SwiftF0 0.3.0 官方 wheel 內的 model.onnx 放在本目錄。原型只接受 135,090 位元組且 SHA-256 為 `6385e8c2ebc3872e82c9ff5946228de44cd3be77a750ea53698b7dbfe94b0a22` 的權重。這個開發資產由本機準備，發行封裝排除。

主程序從曲庫的已選分離結果讀取導唱 L/R，最多 12 分鐘。背景工作在現有 ONNX Runtime 以 CPU 分析原調，播放器的媒體時間決定曲線位置。分離採用 Inst HQ 4 且能配對原曲時，背景工作可用原曲、導唱週期和前後音高補回符合條件的第四諧波誤判。其他未確認的幀留白。

曲線顯示播放器實際套用的音高，並跟著原曲時間移動。放大鏡循環切換 8、16、4 秒，三檔的主刻度分別為 2、4、1 秒。預設顯示 8 秒。

首次分析會在分離結果旁保存原調音高。已符合音源及分析版本的快取會自動載入。手動音分、Key 和速度可由「保存本曲」另行保存，套用後直接更新曲線。

Inst HQ 4 的預覽提供手動反相 A/B。開啟預覽或換曲後顯示「A · 現有曲線」，按一次才準備「B · 反相遮罩」，再按回到 A。B 使用同一份 CPU 音高，在同一分離檔中找到持續至少八幀的反相旁證時，才在畫面留白。A/B 共用播放時間與平滑規則，快取保存 A。其他分離配置沿用 A。

日語研究可在 PowerShell 以 `$env:UTAWAKUI_REFERENCE_JA_REST = '1'` 設定後啟動開發版，再選日語曲目測試。規則只支援使用 Inst HQ 4 的 `general` 分離配置。它以 10 毫秒的間隔量測諧波強度，當伴奏連續佔優至少 120 毫秒，才將符合條件的既有音高留白。預覽仍使用原有的 16 毫秒音高時間軸。未設定開關時使用一般預覽；測試結束後可用 `Remove-Item Env:UTAWAKUI_REFERENCE_JA_REST` 清除該工作階段的設定。
