# 打字機歌單樣張

以 480 × 810 畫布呈現暖白紙頁與霧藍打字機。頁首顯示歌單名稱。目前曲目與已唱紀錄在同一欄連續排印，早唱的在上，最新一列貼近下方滾筒。紙邊的 NP 夾對準目前曲目。

曲名依欄寬換行，最多兩行，藝人列在曲名下方。完唱後原列保留，下一首出現在滾筒上方，依新列的實際高度向上送紙。進紙結束後夾子定位在新曲。只更換目前曲目時原位更新。等待下一首時，已唱紙面保留，夾子收起。減少動態時直接更新版面。

畫布外圍預設透明，紙、墨、霧藍及檢視背景由現有 Output tokens 配色。沿用共用歌單投影的目前曲目、完成筆數與已唱順序。機身是樣張內的原創造型，參考 IMG_1830 的取景。樣張的曲名和藝人為虛構資料。

從專案根目錄啟動預覽：

```sh
npm exec -- vite --config prototypes/typewriter-setlist/vite.config.js --host 127.0.0.1
```

- `?backdrop=dark`、`?backdrop=light`、`?backdrop=checker` 可檢視不同背景。
- `?sample=feed` 開啟後模擬一次完唱與送紙；`?sample=after` 顯示送紙後的版面。
- `?sample=long` 顯示長曲名；`?sample=waiting` 顯示唱完後等待；`?sample=first` 只有第一首目前曲目；`?sample=empty` 為完全透明的空場。參數可與背景一起使用。
