# Site Output template previews

The animated WebP files under `motion/` were recorded from the desktop Output Gallery's
`ObsTemplateMockup.vue` and its corresponding template preview components.
They use the shared synthetic Output scene with sample lyric changes, playback
progress, or a setlist update where needed. Each preview is 480 × 270 at 18 fps
with a five-second loop. Subtitle clips with small or edge-aligned
text were reframed for the gallery cards.

The still WebP posters in this directory were rendered from the desktop Output Gallery's
`ObsTemplateMockup.vue` and the matching production preview components on
2026-11-25. They use the shared synthetic Output preview scene, the dark
preview backdrop and system font fallbacks. Each file is 1280 × 720. The four
sparser lyric previews were reframed to keep their content legible on the
promotional gallery cards. Portrait widgets retain their original aspect ratio.

The five desktop captures reused by the site remain documented in the
[desktop provenance catalog](../../../../src/assets/output-template-thumbnails/provenance.json).
