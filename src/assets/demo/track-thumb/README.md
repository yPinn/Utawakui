# Track artwork review fixtures

These development-only crop fixtures support the Token v2 Track Thumb and
Collage Thumb specimens. The default fallback pool has moved to the production
asset boundary at `src/assets/track-artwork/`; the crop sources let review
specimens compare the same custom covers.

The production fallback pool is not ordinary song-cover sample content.
`TrackArtworkContent` owns its stable track-identity selection and custom → default →
initial failure ladder; demo components import that production resolver directly
rather than maintaining a second implementation.

## Crop artwork

| File                          | Source size | Review purpose                                      |
| ----------------------------- | ----------- | --------------------------------------------------- |
| `track-thumb-crop-wide.jpg`   | 1199 × 675  | Real centered square crop from a wide composition   |
| `track-thumb-crop-square.jpg` | 1080 × 1080 | Square scene baseline with no ratio-driven cropping |

The wide source should keep its subject recognizable after `object-fit: cover`.
The square scene is the control case: it should retain its full composition apart
from the component's rounded clipping boundary.

The crop sources remain real `thumbnailUrl` inputs and must never enter the
fallback pool. Missing artwork, a failed image request, and the no-track state are
generated by the specimen so those paths remain deterministic. These crop files
are bundled only with the development component catalogue and do not add a
runtime file picker or media path.
